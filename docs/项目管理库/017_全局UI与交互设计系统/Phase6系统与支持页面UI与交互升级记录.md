## 实施结果

### 快捷键

- 删除未使用的 `ShortcutMetricBadge` 和 `ShortcutStatusRow` 历史组件。
- 成功注册不再逐行显示文字；只有触发反馈和注册失败使用语义状态图标。
- 录入与恢复改用共享紧凑按钮组，恢复默认在全局默认状态下保持稳定槽位但不可用。
- 开关继续使用全局系统 Switch，行尾几何在录入、成功和失败状态间保持稳定。

### 权限

- 已授权行只展示权限名称与状态，不重复显示“权限已授予”说明。
- “我已完成”改为明确的“刷新权限状态”。
- Finder、拖入系统设置和技术诊断合并到单个“授权帮助”折叠层；默认不占据主任务界面。
- 删除恢复卡片与诊断卡片内部重复的 section 表面，继续保留实际恢复入口和可复制的诊断内容。

### 剪贴板隐私

- App 列表改为惰性构建；普通行只显示图标、名称和当前策略，Bundle ID 仅在身份异常或重复确认时出现。
- 完整路径降为 Tooltip 和无障碍信息，不再占据每行第三层文字。
- 刷新与策略菜单使用紧凑命中区；保存、失败和重试状态在对应行的固定槽位反馈。
- 删除长期常驻的“策略变更状态”分区，初始状态不再制造“待处理”假任务。

### 数据、菜单栏与通知

- 审计空态改为紧凑设置行；用户文案改为“AI 服务活动”和“本机数据”。
- 审计 ID 与确认级别进入按需技术详情，主行只保留服务、结果和时间。
- 剪贴板存储说明删除 `V1` 与 `payload` 等实现词汇。
- 菜单栏维持系统原生 `MenuBarExtra` 菜单结构；没有引入自绘菜单或多余转场。
- 全局通知继续使用唯一 `BlocksNotification` 路径；自动关闭、悬浮暂停、优先级、去重与减少动态效果已有定向测试覆盖。
