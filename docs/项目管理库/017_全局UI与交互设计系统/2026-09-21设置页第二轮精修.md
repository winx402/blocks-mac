# 设置页第二轮精修

## 变更范围

- 设置侧栏保留原有栏目顺序，取消组标题，使用30pt行高、10pt组间隔、20pt色块与12pt符号。颜色及简化符号仅用于设置，不改变浮窗图标。
- 侧栏材质延伸到标题栏的原生内边距，不覆盖系统窗口按钮；内容保留系统工具栏背景和滚动边缘，并在内容边界裁切。
- 工具栏统一后退、前进和当前页面标题；正文不再重复返回入口。只有通用、截图、剪贴板、翻译根页面保留概览。
- 窗口历史仅存栏目及路由标识；去重、新分支清除前进记录、失效插件过滤。滚动、焦点及已有非敏感草稿单独保留，模态表单和业务操作不纳入历史。
- 插件安装完成后的异步导航需匹配开始时的导航代数，不能覆盖等待期间发生的后退、前进或新路径。
- 侧栏折叠移到“显示”菜单，使用窗口聚焦的可见性绑定和 Command-Option-S，菜单文字与真实状态一致。
