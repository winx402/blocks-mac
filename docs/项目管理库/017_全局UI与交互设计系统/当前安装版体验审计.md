## 代码事实

- `BlocksSurfaceRole` 直接使用约 42 处，共享 Foundation 之外仍有 103 处直接背景、描边、阴影或圆角原语。
- 共享 Foundation 之外存在 89 处字面圆角、14 处未收敛动效调用、1 处直接 Material 和 1 处显式绕过“减少动态效果”的路径。
- 功能模块仍有两个私有 `ButtonStyle`：截图图标按钮和剪贴板标签操作按钮。
- 翻译设置、截图 Store/View/Canvas、插件 Manager 等高复杂 UI 文件超过数千行。这不直接等于缺陷，但增加了规范漂移和状态互相影响的风险。
- 现有 `BlocksMotionRole` 只有三种粗粒度角色，翻译、插件、Provider、隐私和快捷键等模块使用率低。

## 设计推断

- “不干脆”不是单纯缺少动画，而是任务层级、稳定几何、反馈时机和状态所有权没有一致契约。
- 样式漂移的根因不只是 Token 少，更是功能模块可以绕过共享组件直接定义结构色、圆角和交互状态。
- 设置应先成为样板，因为它同时覆盖导航、表单、层级、错误、危险操作、长文案和窗口缩放。
