## 功能状态覆盖要求

后续每个模块都必须至少覆盖：

- 正常、空、加载、错误、部分失败、禁用和恢复。
- 鼠标、键盘、右键菜单、拖放和 VoiceOver。
- 冷启动、暖启动、连续操作、关闭/重开、重启持久化。
- 最小、默认、最大窗口以及多屏/混合 DPI。
- 系统语义色和强调色改变，禁止假定蓝色。

## 当前自动化

- `AppAppearanceTests`：Token、Surface、Interaction State、Motion、Gallery 矩阵。
- `script/test_ui_design_system.sh`：防止新增模块私有 ButtonStyle、直接 Material、字面圆角、结构色、无边界动效和 Reduce Motion 绕过。
- 门禁允许遗留数量只减不增，不代表这些遗留路径已通过设计验收。

## Phase 0 完成标准

- 所有现有功能已进入模块 TODO，不只覆盖主流路径。
- 设计原则、代码 Token、共享组件、Gallery、测试和门禁同步。
- 完整 App/Core/Screenshot 测试、Debug/Release、Analyze 和 `git diff --check` 通过。
- 没有数据库/偏好迁移，没有用户配置重置，没有批量功能页面改造。
- 对无真实证据的项目继续标记待验证，不宣布视觉收口完成。
