# 017_全局 UI 与交互设计系统

状态：phase-7-theme-accessibility-partial-complete
最后审阅：2026-08-02
来源级别：project control

## 目标

- 将 Blocks 的 UI 与交互方向收敛为“原生利落、快而克制、稳定几何”。
- 用一个分层的设计系统统一原则、Token、组件、功能组合和治理。
- 先建立可验证的基线，后续再按模块迁移，避免一次性视觉重写引入新的功能回归。

## 当前边界

Phase 1 设置升级、Phase 2 截图、Phase 3 剪贴板、Phase 4 翻译、Phase 5 插件／AI／自动化以及 Phase 6 系统与支持页面 UI 交互升级已完成代码、自动化、构建及当前可执行的安装版验收。下一阶段进入全 App 终验：

- 完成设置导航状态、自适应布局和共享设置组件实施。
- 迁移全部设置主页、已确定的二级页、Sheet 和危险操作。
- 已执行完整 App/Screenshot 自动化、Release、Analyze 和安装版最小／默认／宽窗口验收。
- 截图 Chrome 已迁入共享控件与表面系统，捕获、编辑器交接、状态切换、画布刷新和文字输入焦点已完成收口。
- 剪贴板已完成面板几何、焦点反馈、卡片与详情状态、动效、重绘边界及历史私有样式收口。
- 翻译已完成结果卡、空态、收藏反馈、滚动抗抖、直接操作动效和主题收口；物理鼠标拖放及外部 App／OCR 完整矩阵保留到 Phase 7。
- 插件、AI 服务和本地自动化已完成普通用户信息层级、渐进式技术信息、共享开关／反馈组件和历史无效参数收口。
- 通用、快捷键、权限、隐私、数据审计、菜单栏和全局通知的一致性、信息层级及恢复路径已完成收口。
- Phase 7 已完成设置、剪贴板和翻译共享表面的跟随系统深色、显式浅／深、窗口激活／失活、降低透明度、提高对比度和减少动态效果安装版矩阵。
- 设计系统历史兼容入口与私有结构样式门禁已清零，不再保留“数量不增长”的双轨口径。
- 下一子阶段执行键盘／VoiceOver、多语言布局、多屏／混合 DPI、性能和窗口生命周期矩阵，并补齐前序阶段保留的真实操作证据。
- 窗口生命周期矩阵已先完成剪贴板和翻译主面板：首帧正尺寸、用户关闭动效、程序交接立即关闭及普通窗口恢复均已闭合；其余浮层随对应模块继续迁移。
- 截图捕获实时主题矩阵被系统 Developer Tools Access 授权框阻断；英文／日文完整逐页截图与真实 VoiceOver 仍保留为平台证据项，不伪写成已通过。

未修改用户数据、数据库、偏好版本或功能业务语义。
