## 4. 门禁矩阵判断

### ScreenshotStore

矩阵方向基本合理：P11A + P3C/D/E/F + P7Q 能覆盖截图入口、结果页、AI route preview 和 window/fullscreen 回归。

缺口：

- P7Q 当前存在旧归档验收依赖，作为阻断项前必须迁移当前事实源。
- P3D/E/F 仍读取旧 `实施记录/stories`，作为 Step 4C 证据时应改为 current evidence 或 baseline_reference。
- P11A 必须补 screenshot store / AppState facade / target membership / no image upload / no provider call 的具体检查。

### ShortcutStore

矩阵覆盖快捷键配置、panel 交互、定制 polish、全局 modifier、panel exclusivity，方向合理。

缺口：

- P6A/B/C 读取旧故事记录，需迁移当前事实源或降级 baseline。
- P11C 必须检查动作闭包白名单和禁止任意自动化能力；否则 ShortcutStore 很容易扩大成通用 action dispatcher。
- 实物验收需明确“不会真实发送未声明快捷键动作”；如环境不适合注册全局热键，必须写成未覆盖。

### Settings Shell

矩阵方向合理，但当前 P8G/P7 系列多为旧 SettingsView 字符串检查，容易与 shell + pane 拆分目标冲突。

缺口：

- P11D 必须成为主证据，验证新 pane 文件 target membership、路由/setting key 保持、局部状态隔离。
- 旧 P8G 应更新为 shell/pane 当前事实源；否则可能强迫 `SettingsView.swift` 继续保留过多主体，或误判正确拆分。
- 多语言、窄宽度、长路径、VoiceOver label 需要最低实物抽查，不应只靠静态字符串。

### Clipboard Hardening

当前矩阵不足以单独支撑 sensitive read model 接受。

缺口：

- P8 clipboard product polish 和 P9A/B/C 主要证明既有产品/存储/fixture/reset 回归，不足以证明默认列表 metadata-first。
- `p8_clipboard_product_polish_checks.py` 存在旧归档候选事实源，不能直接作为当前阻断证据。
- P11E 必须检查 readPayload / payload dictionary / full text preview 的调用边界，并输出 allowlist。

建议：4C-4 作为 Step 4C 内 stop/go 子批次；若 P11E 和安全复审不能先闭合，拆到 Step 4D。

## 5. 最低实物证据建议

Screenshot：

- Region / window / fullscreen 三入口至少各有低敏步骤记录。
- Screen Recording 缺权路径如果当前环境无法撤权，必须写成未覆盖，不能写成通过。
- Result copy/save/retake/close 要有文字或低敏截图证据。
- AI route preview 证据必须包含 provider not called / image not uploaded。

Shortcut：

- 注册、禁用、失败、自定义绑定、恢复默认至少覆盖可安全触达路径。
- 全局快捷键如受环境限制，记录未覆盖范围。
- Recorder 一次只录一个命令需有实物或可检查状态证据。
- 每个 action 只触发声明动作；不得验证为“无异常”后泛化通过。

Settings：

- 每个 mode 可打开，`clipboardPrivacy` 返回 Clipboard 设置。
- Provider / Translation / Permission / Shortcut / Clipboard pane 局部状态隔离。
- 窄宽度、长文本、长路径、中文/英文/日文、VoiceOver label 抽查必须列入验收模板。
- 不要求视觉重设计，但不得出现控件丢失、文本不可理解截断或状态串扰。

Clipboard hardening：

- repository unavailable 有用户可理解降级。
- 默认列表、普通面板渲染、Settings summary 不读取完整 payload。
- paste/copy/hover detail/translation preview 是完整 payload allowlist。
- 验收记录只允许写枚举、record id 类低敏标识和 read model 结果，不写剪贴板正文。
