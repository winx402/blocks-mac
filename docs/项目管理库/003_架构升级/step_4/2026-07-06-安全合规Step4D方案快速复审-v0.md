## P1

### P1-1：`summary` 敏感级别必须改成默认敏感

当前 PRD 已指出 `record.summary` 可能来自正文短摘要，不应默认视为低敏；但需要回写成更硬的规则：

- 所有历史 `record.summary` 和未标记 summary 默认视为 sensitive。
- redacted list / Settings / DataAudit / CLI 默认输出不得直接展示 `record.summary`。
- 只有新增明确字段或类型能证明 summary 为 low-sensitive metadata 时，才可进入默认展示；字段名和生成规则必须写入 PRD、开发记录和 P11E。
- P11E 必须 fail closed：默认 builder、searchable text、row/card/list/tray、Settings、DataAudit、CLI 默认路径中出现直接 `record.summary` 展示或搜索拼接时失败，除非命中明确 low-sensitive marker。

### P1-2：并行开发例外必须写清，避免绕过方案复审

PRD 现写明“四方复审完成、P0/P1 清零并回写本文后，主 agent 提交 PRD 阶段文档；提交完成前不得启动 Step 4D-1 开发”。当前协调要求开发线程并行按草案启动实现。两者存在流程冲突，需要回写例外口径：

- 允许并行的范围仅限 `P11E-first`：新增 P11E、低敏 fixture、read model skeleton、explicit purpose API 的静态红绿灯开发。
- 在 PRD P1 回写和主会确认前，不得接受或合并会改变真实用户 clipboard 行为的实现。
- 不得提前启动 4D-2 UI / hover / Settings 实物路径验收。
- 并行开发产生的实现必须在 PRD 回写后复核，若与回写边界不一致，以回写后的 PRD 和安全复审为准。

### P1-3：搜索 / 过滤 query 本身也应列为敏感输出

PRD 已要求 repository FTS 不输出匹配正文片段，但还应明确用户输入的搜索 query / filter text 也可能包含敏感内容：

- verification JSON、audit、开发记录、验收记录和 logs 不得记录真实 search query。
- P11E 的 `read_model_denylist` / `sensitive_output_scan` 应扫描 raw query、matched snippet、highlight、FTS excerpt 等输出。
- 测试只能使用 synthetic query / fixture token；真实 query 证据只能记录 query length、hash-like id、filter kind 或 redacted marker。

## 必须回写的安全边界

建议主 agent 将以下内容回写到 PRD：

1. `summary`：默认敏感，未标记不得展示；P11E 对 `record.summary` 默认展示和搜索拼接 fail closed。

## P11E 最低安全门禁确认

PRD 草案中的 P11E 方向可执行，但回写后应至少覆盖：

- 脚本缺失、预期文件缺失、target membership 解析失败、旧事实源参与 `ok`、只输出 PASS/FAIL 时失败。
- 输出 `read_model_allowlist`、`read_model_denylist`、`explicit_read_sites`、`denied_default_sites`、`repository_state_summary`、`sensitive_output_scan`。
- 默认 load / reload 不调用 `loadPayloads` 或批量 `repository.readPayload(recordID:)`。
- 默认 list/card/row/tray、Settings、DataAudit、CLI 默认输出不传入或显示 `ClipboardRecorderPayload`。
- `clipboardPayload(for:)` 不再作为无 purpose 的通用 View facade。
- 完整 payload 读取只在 paste、copy plain text、hover detail、translation preview，并带 explicit purpose。
- Hover detail 不为所有 filtered records 预读 payload。
- helper 生产写库、App Group、CLI 默认完整 payload、OCR、provider call、网络外发、Keychain 和自动化能力未开启。
- verification / 文档输出不含剪贴板正文、search query、URL 全文、file path 全文、图片/base64、OCR 文本、窗口标题、屏幕文本、真实用户主目录、真实凭据、Authorization header、request body 或 provider raw response。
