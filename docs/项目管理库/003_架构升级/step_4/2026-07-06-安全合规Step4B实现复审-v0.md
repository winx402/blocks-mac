## 3. 事实依据

- `PermissionStore` 是 `@MainActor final class PermissionStore: ObservableObject`，发布 `@Published private(set) var permissionSnapshot`，通过 `PermissionSnapshotProviding`、`PermissionAccessRequesting`、`PermissionAssistPresenting`、`PermissionSystemActioning` 窄协议协作。
- `PermissionStore` 初始化只读取 snapshot；未在 init、objectWillChange、timer、background refresh 中请求权限、打开系统设置、Show in Finder 或 restart。
- `PermissionSystemActions.swift` 是新增系统动作 adapter，集中包含 `NSWorkspace.shared.open`、`NSWorkspace.shared.activateFileViewerSelecting`、`NSWorkspace.shared.openApplication` 和 `NSApp.terminate`。
- `AppState.permissionSnapshot` 已是 computed facade，`AppState.refreshPermissionState()` 先刷新 `permissionStore`，再调用 `retryPendingClipboardPasteIfPossible()`；Clipboard retry 未迁入 `PermissionStore`。
- Settings 权限请求、restart、Show in Finder 均挂在 `Button` action 中；Screenshot Home 的 Screen Recording Settings 入口也挂在 `Button` action 中。
- 截图缺权限弹窗只有在用户选择第一按钮后才调用 `requestScreenRecordingPermissionAssist()`。
