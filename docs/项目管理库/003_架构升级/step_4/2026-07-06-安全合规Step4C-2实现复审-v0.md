## 5. 安全边界复核

### 动作 allowlist

- `ShortcutCommand` 只有三项：`screenshotRegion`、`clipboardHistory`、`translationPanel`。
- `ShortcutActionHandlers` 只有三个闭包字段：`screenshotRegion`、`clipboardHistory`、`translationPanel`。
- `ShortcutStore.registeredActions` 只映射：
  - `.screenshotRegion: actions.screenshotRegion`
  - `.clipboardHistory: actions.clipboardHistory`
  - `.translationPanel: actions.translationPanel`
- 未见 `rawValue` / `String` 驱动的动态 action dispatch。

### AppState action injection

AppState 注入的动作仍是窄入口：

- `screenshotRegion`：`await self?.startScreenshot(mode: .region)`
- `clipboardHistory`：`self?.showClipboardFloatingPanel()`
- `translationPanel`：`self?.showTranslationFloatingPanel()`

未见新增 provider call、剪贴板正文读取、shell / CLI 执行或未声明自动化入口。

### Store 边界与持久化

- `ShortcutStore` 不持有完整 `AppState`。
- `AppState.shortcutRegistrationResults` 已变为 computed facade；`AppState` 不再直接 `@Published` 持有 shortcut facts。
- `AppState` 持有 `ShortcutStore` 并桥接 `objectWillChange`。
- `ShortcutStore` 继续通过既有 `ShortcutBindingStore` 读取 / 保存 / restore / global modifier，不改变持久化 key、迁移策略或 UserDefaults 存储策略。
- `ShortcutStore` 不读取或输出真实用户内容、剪贴板正文、选中文本、屏幕文本、窗口标题或 provider raw response。

### Verification 与低敏输出

- P11C 输出使用当前 Step 4C PRD、当前 4C-2 开发记录和当前代码事实源；旧 story/archive/acceptance 标记为 `baseline_reference`，不参与 `ok`。
- P6A/P6B/P6C/P7C 已迁移到当前事实源，并对 subprocess stdout/stderr 使用 shared sanitizer。
- P7D 无 subprocess，输出 checked files 为相对路径，并声明 current evidence / baseline reference。
- 本轮未发现 P11C/P6/P7 输出中包含真实用户主目录、邮箱、Authorization/Bearer、剪贴板正文、窗口标题、屏幕文本或 provider raw response。
