## 低敏证据格式

验收记录和 verifier JSON 只应记录：

- `read_purpose`：paste / copyPlainText / hoverDetail / translationPreview。
- `record_ref`：synthetic id、fixture id 或 hash-like id。
- `display_state`：normal / degraded / unavailable / empty / filtered / redacted。
- `content_shape`：kind、length、byte count、file count、url count、timestamp bucket、source synthetic/bundle marker。
- `path`：相对路径或 `<ROOT>` / `<TMP>` 占位。
- `result`：PASS/FAIL、failure code、sanitized command。

不得记录：剪贴板正文、URL 全文、file path 全文、图片/base64、OCR 原文、窗口标题、屏幕文本、真实用户主目录、完整本地路径、真实凭据、Authorization header、request body、provider raw response。
