## 4. 修复复核

### sanitizer 覆盖

`verification_sanitizer.py` 的关键覆盖：

- `_replace_known_roots`：将项目 ROOT 替换为 `<ROOT>`，用户 HOME 替换为 `<HOME>`。
- `EMAIL_RE`：邮箱替换为 `<EMAIL>`。
- `ABSOLUTE_PATH_RE`：常见本地绝对路径替换为 `<PATH>`。
- `LONG_HEX_RE`：长 hex 替换为 `<REDACTED_HEX>`。
- `TCC_ROW_RE` 与 `CSREQ_RE`：TCC row / csreq / requirement 类 payload 替换为 `<REDACTED_TCC_REQUIREMENT>`。
- `sanitize_payload`：支持 dict/list/tuple/string 的递归低敏处理，供后续结构化输出复用。

### verifier 接入

静态复核显示：

- P3C：`run()` 返回的 command、stdout tail、stderr tail 走 `sanitize_text`；helper missing detail 也走 `sanitize_text`。
- P3D / P3E / P3F：`run()` 返回的 stdout 和 stderr tail 走 `sanitize_text`；嵌套回归失败 detail 使用的 stdout/stderr 已先低敏。
- P5M：`run()` 返回的 stdout 和 stderr tail 走 `sanitize_text`；compile/run runner 的 stdout/stderr 继承低敏结果。
- P7Q：command 走 `sanitize_command`，stdout/stderr tail 走 `sanitize_text`。

### P11A fail-closed 门禁

P11A 已加入：

- `SANITIZER_REQUIRED_SYMBOLS`：要求 `sanitize_text`、`sanitize_command`、`sanitize_payload`、`sanitizer_self_check` 存在。
- `SANITIZED_OUTPUT_GATES`：要求 P3C/P3D/P3E/P3F/P5M/P7Q 均引用共享 sanitizer。
- `run_sanitizer_self_check()`：导入 sanitizer 并运行自检，失败即 P11A 失败。
- `sanitized_failure_output` observations：输出 sanitizer 路径、gate 列表、缺失项和 self-check 结果。

本轮轻量运行 `python3 tools/verification/p11a_screenshot_store_boundary_checks.py` 返回 PASS，`sanitized_failure_output` 无缺失。
