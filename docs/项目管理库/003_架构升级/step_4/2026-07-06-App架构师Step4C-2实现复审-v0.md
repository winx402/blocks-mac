## 4. 重点复审结论

### ShortcutStore 边界

边界合理。

`ShortcutStore` 承担快捷键注册状态、绑定配置、诊断计数和快捷键 public facade；它不持有完整 `AppState`、Provider、Screenshot、Clipboard 或 Settings 状态，也没有扩大为通用自动化执行器。

### AppState facade

符合 AppShell / coordinator 方向。

`AppState` 保留 computed facade 和 status banner coordination，并通过 `shortcutStore.objectWillChange` 转发 UI 更新。快捷键业务事实源已从 `AppState` 移入 `ShortcutStore`。

### 动作注入

动作注入符合 PRD allowlist。

`ShortcutActionHandlers` 只有三个闭包：`screenshotRegion`、`clipboardHistory`、`translationPanel`。`AppState` 注入的实现分别调用既有截图、剪贴板面板、翻译面板入口；没有动态字符串派发、shell、AppleScript、CGEvent、外部 CLI 或 Accessibility 前台 UI 自动化入口。

### ShortcutBindingStore / ShortcutController

保持职责稳定。

`ShortcutBindingStore` 仍负责既有 UserDefaults 持久化策略；`ShortcutController` 仍是注册 / 注销 hotkey 的底层 adapter。业务状态和诊断计数不再由 `ShortcutController` 或 `AppState` 直接承担。

### P11C 与旧事实源

P11C 对本子批次架构边界足够。

本次运行输出确认 P6A / P6B / P6C / P7C / P7D 的旧 story / archive / acceptance 只作为 `baseline_reference`，不参与 `ok`；阻断检查使用当前 Step 4C PRD、4C-2 开发记录和当前代码事实源。
