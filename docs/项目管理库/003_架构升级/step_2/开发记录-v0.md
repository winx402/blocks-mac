# Step 2 第一阶段开发记录 v0

状态：accepted
日期：2026-07-05
来源级别：implementation record

## 开发范围

- 新增 `ClipboardStore`，作为剪贴板 feature 的状态和用例边界。
- `AppState` 保留现有公开属性和方法作为兼容 facade，内部转发到 `ClipboardStore`。
- `ClipboardStore` 接管 repository load、live capture ingest、preview、payload lookup、filter、pin / move / rename / delete、policy prune、clear unpinned。
- 更新 Xcode project，使 `ClipboardStore.swift` 进入 Blocks app target。
- 更新 P4 / P5 / P8 / P9 验证脚本，使门禁检查当前项目视图和 `ClipboardStore` 边界，而不是旧的平铺文档或旧 `AppState` 实现细节。

## 未做事项

- 未修 Provider route/runtime 的 `.llmBacked` 契约问题；P9B 继续输出该风险，列为 Step 3 前置项。
- 未迁移 Translation、Screenshot、Settings / Permission 的 feature store。
- 未改 helper 生产写库、App Group、CLI 读取完整剪贴板或云同步。
- 未移除 `AppState` facade；这是后续阶段的兼容层。

## 行为保全

- App 启动加载剪贴板状态仍走 `ClipboardRepository`。
- repository 不可用时 `ClipboardStore` 保留内存 fallback，但会标记 `repositoryUnavailable`，不承诺生产持久化。
- 搜索、筛选、Pinboard、预览、payload lookup 由 `ClipboardStore` 统一提供。
- 固定、移动分组、重命名、删除、清空未固定、策略裁剪继续通过已有 repository API。
- copy plain text、paste / auto-paste、内部写入抑制仍保留在既有 AppState / service 编排路径。
- bottom / side 面板、hover detail、card width、bottom height、item font 设置通过 P8 门禁回归。
