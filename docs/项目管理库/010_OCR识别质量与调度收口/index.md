# 010 OCR 识别质量与调度收口

状态：complete
最后审阅：2026-07-21
来源级别：project index

## 目标

- 以真实 Vision 像素识别结果校准中英繁日、数字、标点、URL、代码、深浅色、透明背景、4K 与长图质量，不再只依赖 mock 和状态测试。
- 让截图编辑器、钉图、显式重试、普通剪贴板图片、截图历史和启动恢复共用一个 OCR 调度入口。
- 保证交互式 OCR 优先，后台 OCR 在空闲期串行执行，并在低电量或严重热状态暂停启动新任务。
- 收敛 OCR 数据库状态、取消、重试和低敏性能观测，避免重复计数、迟到覆盖和不必要的全量 UI 刷新。

## 边界

- 继续使用 macOS 14+ `VNRecognizeTextRequest`，不接入云端 OCR，也不引入仅 macOS 26 可用的第二套引擎。
- 语言范围为简体中文、繁体中文、英文和日文；主要优化 UI 截图、数字、标点、URL 与代码。
- 已成功识别的历史内容不批量重跑；用户编辑并锁定的 OCR 永不覆盖。
- 不读取、记录或提交真实剪贴板正文、真实截图文字或用户文件路径。质量语料全部是代码生成的低敏合成内容。
