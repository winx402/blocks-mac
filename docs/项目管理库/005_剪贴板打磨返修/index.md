## 当前反馈范围

- 剪贴板面板内容展示仍存在问题：新旧记录显示不一致、部分旧记录仍显示字符数、部分记录的信息结构不合适。
- 筛选组 hover 收起容错没有达到预期，鼠标离开后仍容易自动收缩。
- 收藏功能名称、右键菜单位置和筛选名称展示存在问题。
- 剪贴板隐私页面仍有英文文案，需要接入多语言汉化。
- 剪贴板面板条目上下边框或内边距仍偏大，核心内容区域没有明显扩大。
- 编辑条目内容不应打开独立窗口，应在条目详情或当前面板内完成。
- 条目详情元数据组织仍未达到“一行两个、长内容独占一行”的预期。
- 部分场景复制内容后，剪贴板历史面板没有出现对应记录。
- 复制系统截图或截图工具截图后，剪贴板历史也必须出现对应图片记录；不能只覆盖普通图片文件复制。
- 点击剪贴板条目后的自动复制/自动填入输入框链路在部分场景下不稳定，具体失败点需要继续澄清和实测。
- 选中历史条目并再次复制后，该条目应提升到最近复制的第一条。
- 复制内容需要与历史记录去重；重复内容不应生成多条重复历史，而应合并并提升到第一条。
- 文本默认纳入剪贴板历史捕获范围；“低敏”只限定验收样本和证据留存。
- 默认支持 `Cmd+1` 到 `Cmd+9` 粘贴历史前 9 条；面板未打开时也可用。该快捷粘贴不置顶、不改变历史顺序；面板打开并按住 `Cmd` 时，对应条目展示数字提示。
- UI 优化方向为稳定专业感优先，其次视觉质感，最后信息密度；卡片保留多彩类型识别。
- 收藏和标签筛选从普通筛选组独立出来，放在筛选区域最后；收藏固定第一并使用星星图标，普通标签只使用颜色圆点，直接点击筛选。
- 设置页标签管理需要调整：标签图标或色块放在标签名前方；标签管理按钮视觉统一、语义清楚；`Cmd+数字` 数字提示和收藏星标不能重叠或混淆。
- PRD 确认后实施阶段优先修信任链路，再做 UI 打磨；内容较多部分允许按 PRD 子包进一步拆分。

- 当前自动化门禁、核心真实 UI 证据、本地化证据和无 Accessibility 权限降级证据均已采集；后续只做最终复核、必要修正和收口提交。
