# 005A 信任链路 PRD

状态：confirmation-ready-awaiting-user
日期：2026-07-08
负责人：项目负责人
来源级别：PRD draft

## 1. 目标

修复剪贴板历史的基础信任链路：用户复制文本等内容后，历史面板必须能看到；重复复制不能生成重复记录；从历史中再次复制、双击粘贴或通过 `Cmd+数字` 快捷粘贴，均必须把该条目提升为最近第一条。按住 `Cmd` 期间前 9 条映射使用稳定快照，避免一次提升改变同一轮连续快捷操作的数字含义。

该阶段优先实施，先于 UI 打磨。

## 2. 范围

- 符合隐私策略和系统读取限制的文本、富文本、URL、file URL、PNG/TIFF 图片复制后进入历史；图片必须覆盖系统截图或截图工具复制到剪贴板的屏幕截图。
- 历史条目双击时，先写入系统剪贴板，再粘贴到当前活跃输入框。
- 支持 `Cmd+1` 到 `Cmd+9` 粘贴最近历史前 9 条；面板打开和未打开时都应可用。
- 历史条目执行复制、复制纯文本或双击粘贴时，更新最近复制时间并置顶。
- `Cmd+1` 到 `Cmd+9` 与双击、回车共用复制提交语义：更新最近复制时间并置顶；按住 `Cmd` 期间继续使用动作前的前 9 条快照。
- 按原始 payload 去重；重复 payload 合并到已有条目，不新增重复历史。
- 成功、失败、权限不足、不可恢复内容需要有用户可感知反馈。

## 3. 行为规则

### 3.1 捕获与可见性

- 系统剪贴板出现新的文本、富文本、URL、file URL 或图片 payload 后，应在符合隐私策略和系统读取限制的前提下进入历史列表并置顶。
- macOS 系统截图、截图工具、预览或浏览器复制到剪贴板的图片 payload 应作为图片捕获主路径验收；不能只用 fixture 或本地文件拖拽替代截图复制路径。
- 文本默认纳入捕获范围；“低敏”只用于验收样本和证据留存，不表示只捕获低敏文本，也不表示可以绕过隐私页 App capture policy、用户排除规则或系统不可读限制。
- 捕获失败、入库失败、策略排除、筛选隐藏、UI 刷新失败必须能在调试或低敏验收中区分。
- 如果内容被隐私策略排除，面板应显示明确的排除状态，而不是让用户误以为复制丢失。

### 3.2 点击与粘贴

- 单击历史条目：只选中条目并展示预览/详情，不写入系统剪贴板，不执行粘贴。
- 双击历史条目：写入系统剪贴板，并向当前活跃输入框执行粘贴。
- 键盘回车行为应与双击一致，前提是当前面板焦点位于历史条目。
- `Cmd+1` 到 `Cmd+9` 对稳定排序快照中的前 9 条执行快捷粘贴；面板打开时按当前可见列表编号，面板未打开时按全局最近历史列表编号。
- 面板打开且搜索、筛选、标签或收藏过滤已生效时，`Cmd+1` 到 `Cmd+9` 对过滤后的当前可见列表前 9 条生效；面板未打开时不使用任何临时筛选状态。
- 面板打开时，即使搜索框获得焦点，`Cmd+1` 到 `Cmd+9` 仍由剪贴板面板处理为快捷粘贴；普通数字输入不受影响。
- 顶部数字键和数字小键盘的 `1` 到 `9` 都应映射到同一套快捷粘贴。
- 快捷粘贴动作写入系统剪贴板后立即更新最近复制时间并置顶，再尝试向冻结目标发送一次粘贴快捷键；同一次按住 `Cmd` 期间的数字映射不随重排改变。
- 面板打开且用户按住 `Cmd` 时，前 9 条历史应展示对应数字提示；提示只用于快捷键识别，不改变选中、排序或筛选。
- 用户按住 `Cmd` 期间形成前 9 条映射快照；连续按多个数字时，映射不得因为前一次快捷粘贴而变化，保证可以快速粘贴多个内容。
- 若当前列表不足 9 条，只显示和响应已有条目的数字。
- 快捷粘贴写入系统剪贴板时，live capture 应通过已登记的内部操作 ID 识别本次写入，不得重复新增记录或产生延迟二次置顶。
- 若缺少 Accessibility 权限，双击应至少完成复制到系统剪贴板，并显示“无法自动粘贴，需要开启辅助功能权限”的明确提示。

### 3.3 去重与排序

- 去重键采用原始 payload。
- 原始 payload 相同：合并到既有条目，更新最近复制时间，置顶，不新增重复条目。
- 原始 payload 不同但可见摘要相同：不得自动合并，避免误合并不同富文本、URL、文件或图片。
- 最近排序以最近复制时间为主；详情中如需要展示，应区分创建时间与最近复制时间。
- `Cmd+数字` 不是排序例外：复制提交后正常更新最近复制时间并置顶；排序稳定性只由按键期间的前 9 条快照保证。

### 3.4 反馈

- 复制/粘贴成功后，应给出轻量反馈，且反馈不能因为面板关闭或焦点变化而完全不可见。
- 复制成功但自动粘贴失败时，应明确区分“已复制”和“未粘贴”。
- 内容不可恢复、payload 不可读或被隐私策略排除时，应禁用双击粘贴或给出失败说明。

### 3.5 面板与粘贴目标

- 普通剪贴板面板使用非激活面板；打开前冻结当时的外部目标 App、窗口和焦点诊断快照。面板内搜索、筛选、详情和点击不得改变目标。
- 固定面板只在用户明确激活新的、具有可见普通窗口的外部 App 时更新目标；Blocks 自身、系统设置和无普通窗口进程不作为目标。
- 双击、回车和快捷粘贴固定执行“解析 → 写系统剪贴板 → 去重/更新时间 → 置顶 → 释放面板焦点 → 尝试一次全局 `Cmd-V`”。
- 目标仍在前台时才派发 `Cmd-V`；不重新激活目标，不遍历 AX 控件树恢复第一响应者，也不向 PID 定向投递事件。
- 普通面板在复制提交后立即关闭；固定面板保持可见但主动放弃 Key 状态。自动粘贴失败不回滚剪贴板和历史排序，只提示用户手动 `Cmd-V`。
- 从 Blocks 主窗口打开且没有有效外部目标时，只完成复制和置顶，不向 Blocks 自身粘贴。

## 4. 验收标准

- 符合隐私策略和系统读取限制的文本、富文本、URL、file URL、PNG/TIFF 图片复制后进入历史并置顶。
- 系统截图或截图工具复制到剪贴板的图片进入历史并置顶，且卡片能显示缩略图或类型化图片摘要。
- 重复复制相同原始 payload 不生成重复记录，原条目置顶。
- 历史条目单击只选中，不复制、不粘贴。
- 历史条目双击复制并粘贴到当前输入框。
- 面板打开时，按住 `Cmd` 能看到前 9 条数字提示；按 `Cmd+1` 到 `Cmd+9` 能粘贴对应条目。
- 面板打开且搜索/筛选生效时，数字提示与当前可见列表前 9 条一致。
- 面板未打开时，`Cmd+1` 到 `Cmd+9` 也能粘贴最近历史前 9 条对应内容。
- 连续按住 `Cmd` 使用数字粘贴多个条目时，数字到记录的映射保持稳定；松开 `Cmd` 后列表按最新复制时间展示。
- 历史条目再次复制后显示为最近第一条。
- 无 Accessibility 权限时，系统剪贴板复制成功，自动粘贴降级提示清晰。
- 被隐私策略排除的内容不会假装成功粘贴。

## 5. 验收证据

- 文本、URL、file URL、图片复制录屏或等价截图证据；证据样本必须使用合成或非隐私内容。
- 系统截图或截图工具复制到剪贴板后出现在历史中的录屏或等价低敏证据；截图内容应为合成低敏画面。
- 重复复制前后历史条目数量和排序证据。
- 单击与双击对比录屏。
- 面板打开后按住 `Cmd` 显示数字提示，并使用 `Cmd+数字` 粘贴对应条目的录屏。
- 面板未打开时使用 `Cmd+数字` 粘贴对应条目的录屏或等价低敏证据。
- 连续按住 `Cmd` 执行 `Cmd+1`、`Cmd+2`、`Cmd+3` 后，三次解析仍使用同一记录快照，列表最终按最新复制时间重排的自动化证据。
- 权限不足降级提示截图。
- 自动化或 CLI 低敏检查，证明不会输出真实隐私内容。

## 6. 代码扫描确认的实施范围

本节只定义实施范围，当前 PRD 确认前不进入代码修改。

### 6.1 捕获与去重

- `ClipboardLiveCaptureService.swift`
  - 当前问题：`makeSnapshot` 在 service 层用 `lastAcceptedSignature` 丢弃连续相同 payload，导致 repository 无法得知重复复制事件，也就无法按“重复复制置顶”处理。
  - 实施范围：删除 service 层“相同签名直接丢弃”的运行时去重语义；仅保留同一 changeCount 防抖或必要的自写入忽略。重复 payload 必须进入 repository insert/update 路径。
  - 验收重点：连续复制相同文本、URL、图片时，不新增重复记录，但已有记录最近复制时间更新并置顶。

- `ClipboardRepository.swift`
  - 当前问题：`insert` 命中相同 `signature_sha256` 时直接返回 duplicate，不更新任何排序字段。
  - 实施范围：新增统一 upsert 语义。原始 payload 相同则合并到已有记录，更新最近复制时间、必要 summary/search preview 和 load 排序；原始 payload 不同但摘要相同不得合并。
  - 验收重点：相同 payload 合并置顶，不同 payload 不误合并。

### 6.2 最近复制时间和排序

- `AppDatabase.swift`
  - 当前问题：`clipboard_items` 只有 `created_at/updated_at/content_updated_at`，无最近复制时间。
  - 实施范围：新增 schema migration，加入 `last_copied_at`；旧历史一次性回填为 `created_at` 或当前可推断的最近时间。该迁移是允许的一次性归一化，不属于运行时兼容双路径。
  - 验收重点：`loadRecent` 和搜索结果默认按最近复制时间排序；详情中能区分创建时间与最近复制时间。

- `ClipboardStore.swift`
  - 当前问题：repository reload 后只按 `loadRecent` 的结果展示。
  - 实施范围：保持 Store 不复制排序事实，排序事实由 repository 提供；普通复制/双击粘贴后 reload 或局部刷新应能看到置顶结果。

### 6.3 粘贴与降级

- `ClipboardAutoPasteCoordinator.swift`
  - 当前问题：无 target app 时在写 pasteboard 前抛错；Accessibility 未授权时会走系统 prompt/permission panel 路径。
  - 实施范围：拆出“只写系统剪贴板”和“写后自动 paste command”两阶段；无 target、target 失效或 Accessibility 不足时，必须至少完成系统剪贴板写入，并返回明确的 pasteboard-only/partial failure 结果。
  - 验收重点：无输入框、无 Accessibility、target 激活失败时，都能区分“已复制”和“未自动粘贴”。

- `AppModel.swift`
  - 当前问题：只使用打开面板前捕获的 target app，且所有 paste 都会走同一置顶语义。
  - 实施范围：双击、回车和 `Cmd+数字` 共用复制提交与目标派发路径；成功写系统剪贴板后更新最近复制时间并置顶。按住 `Cmd` 时由面板快照维持数字映射稳定。
  - 验收重点：三种入口均置顶；连续数字快捷操作不会因第一次置顶而改变本轮映射。

### 6.4 `Cmd+1..9` 快捷粘贴

- `ShortcutController.swift` / `ShortcutStore.swift`
  - 当前问题：只注册截图、剪贴板面板、翻译三个命令。
  - 实施范围：新增全局 `Cmd+1..9` 快捷路由，默认启用；不新增关闭选项。
  - 验收重点：面板未打开时可粘贴全局最近前 9 条。

- `ClipboardHistoryPanelPresenter.swift` / `ClipboardFloatingPanelView.swift`
  - 当前问题：面板 keyDown 只处理 Return/Escape，面板内无 Cmd 数字状态和列表快照。
  - 实施范围：面板打开时捕获 Cmd 按下状态，前 9 条按当前可见列表编号；按住 Cmd 时建立稳定快照，连续按多个数字不受前一次快捷粘贴影响。
  - 验收重点：筛选/搜索生效时编号对应当前可见列表；连续 `Cmd+1/2/3` 后列表不重排。

### 6.5 不进入 005A 的事项

- 不做卡片视觉重排、标签筛选平铺或详情卡布局，这些归 005B/005C。
- 不调用真实外部 provider，不使用用户真实隐私内容作为样本。
- 不保留旧单击粘贴配置或运行时兼容分支；旧设置只能通过一次性归一化退出。
