# 005_剪贴板打磨返修 总 PRD

状态：confirmation-ready-awaiting-user
日期：2026-07-08
负责人：项目负责人
来源级别：PRD draft

## 1. 背景

004_剪贴板打磨安装后，用户在真实 UI 使用中反馈多个核心体验仍未达到预期。005 项目承接这些返修点，并把后续工作从“零散修补”收敛为一组可确认、可拆分、可验收的 PRD。

本 PRD 包覆盖 `原始反馈记录-v0.md` 中的 F1-F12，以及 UI/交互只读审计提出的补充问题。PRD 经用户确认前，不进入开发实现。尤其 UI 相关代码改动，必须在用户确认本 PRD 包中 UI 口径后开始。

## 2. 输入来源

- 用户原始反馈 F1-F12：见 [原始反馈记录 v0](原始反馈记录-v0.md)。
- 004 偏差复盘和 005 纠偏原则：见 [项目负责人偏差复盘 v0](项目负责人-偏差复盘-v0.md)。
- 临时 UI/交互设计师子 agent 只读审计：见 [UI/交互子 agent 审计摘要 v0](UI交互子agent审计摘要-v0.md)。
- 用户在计划阶段锁定的产品决策：点击行为、去重规则、标签筛选、收藏独立、视觉方向、中英日三语、分阶段验收和信任链路优先。

## 3. 目标

- 修复剪贴板核心信任链路：复制后可见、重复复制去重置顶、历史条目双击复制并粘贴到输入框。
- 补齐 `Cmd+1` 到 `Cmd+9` 快捷粘贴前 9 条历史的交互和验收；面板未打开时也可用，且快捷粘贴不改变历史顺序。
- 重新定义剪贴板面板的信息结构，让新旧历史条目展示一致、可读、专业。
- 优化筛选、收藏、右键菜单、详情编辑和元数据布局，使交互路径符合用户预期。
- 优化设置页标签管理，让标签图标/色块与标签名关系清楚，动作按钮视觉统一，并避免数字快捷提示与收藏星标冲突。
- 完成 005 涉及界面文案的中英日三语覆盖，消除内部 key 和硬编码英文外露。
- 建立“真实 UI 证据 + 自动化门禁”的双轨验收，避免再次把静态 PASS 误判为体验达标。

## 4. 非目标

- 不在本 PRD 中定义新的剪贴板产品大功能，例如 Paste Stack、批量编辑、跨设备同步。
- 不引入新的 UI 框架或重写整个面板架构。
- 不调用真实外部 provider，不使用用户真实隐私剪贴板内容作为验收样本。
- 不修改 004 的历史验收结论；005 是独立返修项目。

## 5. 已锁定产品决策

- 点击行为：单击只选中和预览；双击复制该条目并粘贴到当前输入框。
- 快捷键行为：`Cmd+1` 到 `Cmd+9` 粘贴前 9 条历史；面板打开时按当前可见列表编号，面板未打开时按全局最近历史编号。面板打开并按住 `Cmd` 时显示对应数字提示。
- 排序行为：历史条目复制、复制纯文本、双击粘贴、重复外部复制会更新最近复制时间并置顶；`Cmd+数字` 快捷粘贴是例外，不更新最近复制时间、不置顶、不改变前 9 条映射。
- 去重规则：按原始 payload 去重；重复内容不新增历史条目，只合并并置顶。
- 卡片展示：采用混合智能摘要；新旧历史条目必须使用同一展示规则。能展示正文就展示正文摘要，不能展示正文时给类型化摘要或“内容不可预览”状态，不能把字符数作为主内容。
- 标签筛选：从普通筛选组中独立出来，和收藏筛选共同放在筛选区域最后；默认平铺展示 chip，不需要点击展开，直接点击筛选。普通标签只使用颜色圆点。
- 收藏：独立于标签。筛选区中收藏固定在标签组第一位，使用星星图标；右键一级显示收藏/取消收藏，位置在标签操作上方；不暴露底层标签模型。
- 设置页标签管理：标签列表使用“图标/色块 + 标签名”的顺序；标签管理按钮统一尺寸、间距、状态和语义；`Cmd+数字` 数字提示和收藏星标不得共用槽位或混淆样式。
- 详情编辑：保存和取消按钮位于正文编辑区内部的底部固定操作栏，按钮出现和状态变化不得导致组件变形或位置移动。
- 视觉方向：保留多彩类型识别，但统一层级、边距、选中态和 hover 态。优先级为稳定专业感 > 视觉质感 > 信息密度。
- 本地化：005 涉及面板、菜单、详情、隐私页、状态、错误、确认弹窗，中英日三语同步。

## 7. 阶段拆分

### Phase 1：信任链路

先修复制捕获、原始 payload 去重、重复复制置顶、双击复制粘贴、权限降级提示。该阶段优先于 UI 打磨，因为用户必须先信任剪贴板历史“复制了就能看到、点了就能用、重复不会乱”。

### Phase 2：UI 基础返修

修卡片展示、历史条目展示、字符数主内容问题、选中/hover/focus 分层、视觉噪声和信息密度。该阶段必须以用户确认后的 UI PRD 为准。

### Phase 3：筛选和菜单

修标签筛选平铺、收藏独立、右键菜单层级、设置页标签管理、数字提示与收藏星标冲突、内部 key 外露、筛选 hover 安全区。

### Phase 4：详情和本地化

修上方详情卡内编辑、metadata 布局、中英日三语文案覆盖。

### Phase 5：分阶段验收

每阶段都必须提供低敏真实路径证据；最终再做 005 总体验验收。无法真实验证的项不能写成完成。

## 10. 当前阶段边界

当前仍处于 PRD 更新和确认阶段，尚未进入 App 代码实施。项目负责人只允许更新 005 PRD、范围矩阵、验收口径和后续实施说明；未经用户确认本 PRD 包，不得修改 `apps/Blocks` 生产代码、`tools/verification` 门禁代码或启动真实 App 验收。

本轮代码扫描仅用于确认实施范围，不代表已开始实现。已确认的实施口径如下：

- 旧历史必须与新条目使用同一规则展示，因此允许一次性迁移、回填或重建旧数据；迁移后运行时不得保留旧行为分支、旧单击模式、旧 pinned displayName 标题路径或旧 preview fallback 双路径。
- 自定义标题对所有历史条目开放；默认标题仍为本地化类型，用户设置自定义标题后由自定义标题覆盖。
- `Cmd+1` 到 `Cmd+9` 默认全局生效，即使会覆盖其他 App 的标签页快捷键。
- 验收证据只使用合成或非隐私样本，不调用外部 provider。

## 11. 代码扫描确认的实施范围

### 11.1 005A 信任链路

- 捕获入口：`ClipboardLiveCaptureService.swift` 当前会在 service 层丢弃连续相同签名，需改为交由 repository 做统一去重和置顶。
- 存储入口：`AppDatabase.swift` 当前 schema version 为 5，无 `last_copied_at` 和 record 级自定义标题字段；需要新增 schema migration，并一次性回填旧历史。
- Repository：`ClipboardRepository.swift` 当前 `loadRecent` 按 `created_at DESC` 排序，`insert` 命中重复签名时直接返回 duplicate，不更新排序；需要改为按最近复制时间排序，并支持普通复制置顶和 `Cmd+数字` preserve-order 两套写剪贴板语义。
- 粘贴链路：`ClipboardAutoPasteCoordinator.swift` 当前无 target app 时直接失败且不写系统剪贴板；需改为先写剪贴板，再按目标和 Accessibility 状态决定是否发送 paste command。
- App 协调：`AppModel.swift` 当前只使用打开面板前捕获的 target app；需要补当前可编辑目标优先、无目标降级、权限降级提示和快捷粘贴不置顶路径。
- 快捷键：现有 `ShortcutCommand` 只有截图、剪贴板面板、翻译；需要新增全局 `Cmd+1..9` 快捷粘贴路由，并扩展面板内 key handling。

### 11.2 005B 面板 UI 与交互

- 预览模型：`ClipboardRecordPreview.swift` 和 `ClipboardSearchDocumentBuilder.swift` 当前会把正文、URL host、文件名写入标题，并把字符数/字节数作为 body fallback；需改为“自定义标题优先，否则本地化类型”，主内容走混合智能摘要。
- 列表和卡片：`ClipboardRecordViews.swift` 当前底部卡片有内嵌正文背景、标题旁收藏星标、底部 badge/tag/OCR 多信息；需按 005B 重建层级、固定数字提示槽、收藏动作槽和底部时间区。
- 面板交互：`ClipboardFloatingPanelView.swift` 当前仍有 `pasteActivationMode` 和顶部单击/双击切换；需移除旧开关，固定单击选中、双击粘贴。
- 筛选：`ClipboardFilterBarView.swift` 当前标签仍作为普通展开筛选组；需拆出收藏+标签平铺区域，收藏固定第一，普通标签使用颜色圆点。
- 菜单：`ClipboardRecordViews.swift` 当前收藏在 `ClipboardTagMenu` 内，且存在硬编码 `Edit details`、`New Tag`；需把收藏上移为右键一级动作，并完成本地化。
- 设置页：`ClipboardSettingsPane.swift` 当前标签行的星标/色块在右侧动作区；需改为“图标/色块 + 标签名”在左侧主识别区，动作按钮统一尺寸和状态。

### 11.3 005C 详情编辑与元数据

- 当前详情为 `ClipboardFloatingPanelView.swift` 中的 overlay + `ClipboardDetailEditorView.swift`，不是上方详情卡；需改为面板内详情卡并避免遮挡历史列表。
- `ClipboardDetailEditorView.swift` 当前保存/取消在底部外层 action bar，出现和状态变化会影响按钮组布局；需移入正文编辑区内部固定 44pt 操作栏。
- `ClipboardRepository+DetailEdit.swift` 已有保存原 record 的基础路径，但 metadata 仍偏少且多处英文硬编码；需增加最近复制时间、自定义标题、隐私状态、长字段显式展开等读模型。
- 自定义标题需新增 record 级持久字段或等价窄表，不再依赖 `clipboard_pinned_metadata.display_name`，且所有条目均可设置。

### 11.4 005D 本地化与验收

- `Localizable.xcstrings` 已有大量剪贴板 key，但详情、菜单、捕获策略、搜索 builder、隐私页和标签管理仍有硬编码英文；需统一补中英日三语。
- 旧 P13C 仍以 single-click/double-click 模式作为通过条件；005 实施时需更新或新增门禁，避免旧门禁反向阻挡新 PRD。
- 005 最终验收必须组合静态/自动化门禁和真实低敏 UI 证据；只有自动化 PASS 不足以关闭 005。
