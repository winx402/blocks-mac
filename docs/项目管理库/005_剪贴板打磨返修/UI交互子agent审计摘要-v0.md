## 2. 事实摘录

- 截图 `001-内容展示问题.png` 证明底部剪贴板卡片存在新旧记录展示不一致、正文区域显示字符数、部分卡片信息结构不符合预期。
- 截图 `002-筛选收藏右键问题.png` 证明筛选条显示内部 key，收藏入口被放在“标签”子菜单里，右键菜单存在英文 `Edit details`。
- 截图 `003-隐私页汉化问题.png` 证明隐私页大量英文可见。
- 截图 `005-详情内编辑问题.png` 证明用户期望直接在详情区域编辑内容，而不是通过右键打开独立编辑路径。
- 代码静态观察显示，卡片正文存在 fallback 到字符数/字节数的路径；筛选 hover 收起是固定延迟和固定安全区；详情编辑当前是 overlay 卡片且存在英文状态文案。

## 3. 推断

- 内容展示不是单纯样式问题，而是 preview/read model 规则未定义清楚：payload、新旧数据、文本/URL/图片/文件、redacted/fallback 的展示策略混在一起。
- 当前视觉“不稳”的主要来源可能是多彩卡片 tint、玻璃层、选中/hover/focus 边框、标签/星标/状态徽标同时抢层级。
- 复制反馈即使已有 AppStatus，也未从截图证明在浮动面板内足够即时、可感知、不被面板关闭吞掉。
- 键盘支持有部分路径，但截图不能证明 VoiceOver、焦点读法、右键菜单键盘可达性已经达标。

## 4. 问题清单

### P0

- 内容预览规则不清且可见不一致。必须定义文本、富文本、URL、文件、图片、旧数据缺 payload、隐私保护记录分别在标题、正文和底部 metadata 中显示什么。
- 用户可见内部 key 与英文硬编码。`clipboard.filter.tags`、隐私页英文、`Edit details`、详情编辑状态英文都会阻塞“打磨完成”。
- 捕获、点击粘贴、重复复制合并排序是核心信任链路，不能作为纯 UI polish 降级。

### P1

- 收藏入口信息架构错误。收藏应是一级动作，放在标签入口上方；底层模型可以继续复用标签，但 UI 不应暴露该实现。
- 详情编辑路径不符合预期。应在当前面板/详情区域内编辑，并定义保存、取消、未保存离开、保存成功/失败状态。
- 详情元数据布局未达预期。短字段两列，长字段单列；长类型字符串、hash、source path 不能挤压正文。
- 筛选 hover 容错仍有风险。固定短延迟和固定安全区不足以证明真实手感达标。
- 选中、hover、keyboard focus 需要重新分层，避免三者都像主状态。
- 条目密度与正文区域比例不足，顶部标题和底部 metadata 占比偏高。

### P2

- 空状态/错误状态需要真实截图覆盖：无历史、筛选无结果、仓库不可用、payload 不可读、隐私排除。
- 可访问性需要补验收：VoiceOver 标签、菜单层级、键盘打开筛选/菜单/详情、动态状态播报、长文本缩放。

## 5. 子 agent 提出的设计方向

- 信息层级稳定版：卡片固定为顶行来源/标题/收藏，中区正文或类型专属摘要，底行时间/类型/标签/OCR/排除状态。
- 低噪声专业版：降低类型背景色存在感，统一选中/hover/focus 层级，增加正文区域稳定性。
- 详情内联工作流版：单击/键盘选择只选中，双击执行复制/粘贴；详情在面板内展示和编辑，右键菜单一级包含粘贴、复制纯文本、收藏、编辑详情、标签、删除。

## 6. 子 agent 提问与用户澄清结果

| 子 agent 提问 | 用户澄清 / PRD 结论 |
| --- | --- |
| 文本卡片主内容显示复制内容前几行，还是来源/标题摘要？ | 采用混合智能摘要；文本/富文本显示正文摘要，URL/文件/图片显示类型化摘要。历史条目也使用同一规则，字符数不得作为主内容。 |
| 点击条目默认选中、复制，还是自动粘贴到输入框？ | 单击只选中和预览；双击复制该条目并粘贴到当前输入框。 |
| 收藏命名是收藏/取消收藏还是星标？收藏是否仍作为标签筛选普通标签展示？ | 收藏独立于标签；右键一级显示收藏/取消收藏，放在标签上方；筛选中作为独立入口，不暴露底层标签模型。 |
| 详情编辑放在底部面板内、悬浮详情卡内，还是右侧详情区？ | 详情与编辑放在上方详情卡内完成。 |
| 去重排序中的“相同内容”如何判定？ | 按原始 payload 去重；重复内容不新增历史条目，只合并并置顶。 |

补充澄清：

- UI 优先级为稳定专业感 > 视觉质感 > 信息密度。
- 视觉方向保留多彩类型识别，但统一层级、边距、选中态和 hover 态。
- 标签筛选特殊处理：从普通筛选组独立出来，放最后，默认平铺展示标签 chip，直接点击筛选。
- 普通筛选保留 hover 展开，但必须扩大安全区并以真实鼠标路径验收。
- 本地化范围为中英日三语同步。
- 005 提到的点都要验收，但实施和验收可以分阶段。
- 实施阶段信任链路先于 UI 打磨。
