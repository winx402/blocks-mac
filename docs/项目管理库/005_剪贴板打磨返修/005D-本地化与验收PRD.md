# 005D 本地化与验收 PRD

状态：confirmation-ready-awaiting-user
日期：2026-07-08
负责人：项目负责人
来源级别：PRD draft

## 1. 目标

完成 005 涉及界面的中英日三语文案覆盖，并建立低敏真实路径验收标准，确保 005 不再只依赖静态门禁或自动化 PASS 宣称体验完成。

## 2. 本地化范围

必须覆盖以下可见文本：

- 剪贴板面板标题、搜索、格式/时间/来源筛选、标签筛选、收藏筛选。
- 历史卡片的类型、状态、OCR、隐私排除、内容不可预览等文本。
- 右键菜单：粘贴、复制纯文本、收藏/取消收藏、编辑详情、标签、删除。
- 详情卡：标题、编辑、保存、取消、未保存确认、保存成功、保存失败、完整值查看。
- 隐私页：标题、App capture policy、Search apps、Filters、Discovered Apps、Refresh、Policy 等当前截图可见英文。
- 设置页标签管理：标签名称、内置/普通标签说明、新建标签、创建、编辑/排序/合并/删除等可见动作和 tooltip。
- 复制/粘贴反馈：复制成功、粘贴成功、已复制但无法自动粘贴、权限不足、内容不可恢复。
- 空状态和错误状态：无历史、筛选无结果、仓库不可用、payload 不可读、策略排除。

## 3. 本地化要求

- 中英日三语同步。
- 不允许 UI 外露内部 key，例如 `clipboard.filter.tags`。
- 不允许 005 涉及路径继续硬编码英文。
- 中文文案应面向真实用户，不使用工程模型名。
- 日文和英文应保持同等语义，不只填占位翻译。
- 长文案必须考虑窄宽度和卡片空间，不能撑破布局。

## 4. 验收总原则

- 真实 UI 证据负责证明用户体验达标。
- 自动化门禁负责证明数据、索引、事务、本地化资源、输出边界和构建没有回归。
- 真实路径验收可以使用文本、URL、file URL、图片等合成或非隐私样本，不使用用户真实隐私内容。
- 无法真实验证的项只能标为未验收，不能写成完成。

## 5. 阶段验收矩阵

| 阶段 | 验收内容 | 证据 |
| --- | --- | --- |
| Phase 1 信任链路 | 捕获、去重、置顶、双击复制粘贴、`Cmd+1..9` 快捷粘贴且不重排、权限降级 | 低敏录屏或截图、自动化/日志证据 |
| Phase 2 UI 基础返修 | 卡片展示、历史条目一致、选中/hover/focus、视觉噪声 | 对照截图、焦点/hover 状态截图 |
| Phase 3 筛选、菜单和标签管理 | 标签平铺、收藏独立、右键菜单、设置页标签管理、数字提示与收藏星标冲突、hover 安全区 | 右键菜单截图、标签管理截图、筛选 hover 录屏 |
| Phase 4 详情和本地化 | 上方详情卡、metadata 布局、中英日文案 | 详情编辑截图、三语截图 |
| Phase 5 总体验 | F1-F12 全部回归 | 汇总验收记录 |

## 6. 必测场景

- 符合隐私策略和系统读取限制的文本、富文本、URL、file URL、PNG/TIFF 图片复制后进入历史并置顶；验收样本使用合成或非隐私内容。
- 系统截图或截图工具复制到剪贴板的图片进入历史并置顶；证据必须使用合成低敏截图内容。
- 重复复制相同原始 payload 不生成重复记录，原条目置顶。
- 单击历史条目只选中；双击复制并粘贴到当前输入框。
- 面板打开时按住 `Cmd` 显示前 9 条数字提示；`Cmd+1` 到 `Cmd+9` 粘贴对应条目，且不置顶、不改变前 9 条顺序。
- 搜索或筛选生效时，数字提示对应当前可见列表前 9 条。
- 面板未打开时，`Cmd+1` 到 `Cmd+9` 也能粘贴最近历史前 9 条对应内容。
- Accessibility 权限不足时，复制成功但自动粘贴降级提示清楚。
- 新旧历史条目卡片展示一致，无字符数占据主内容区域。
- 标签筛选默认平铺，直接点击生效，位于筛选区最后。
- 收藏入口在右键一级菜单，位于标签上方。
- 收藏条目按住 `Cmd` 显示数字提示时，数字提示与收藏星标同时可识别，不重叠、不共用同一槽位、不导致布局跳动。
- 设置页标签管理中，普通标签的颜色圆点或色块、收藏标签的星标展示在标签名前方；标签管理动作按钮视觉统一、语义清楚、状态完整。
- 详情编辑在上方详情卡内完成，保存/取消/未保存状态可见。
- 保存/取消按钮在编辑区内固定操作栏展示，按钮状态变化不导致组件变形或位置移动。
- 隐私页、面板、菜单、详情、状态文案中英日三语无 key 外露。
- 普通筛选 hover 在真实鼠标路径下不容易误收起。

## 7. 不可接受情况

- 符合隐私策略和系统读取限制的文本等内容复制后，历史面板看不到内容，且没有明确策略排除或失败提示。
- 系统截图或截图工具复制到剪贴板后，历史面板看不到图片记录，且没有明确策略排除或失败提示。
- 重复复制生成多条重复记录。
- 单击历史条目误触发粘贴。
- 双击后既没有粘贴也没有失败说明。
- `Cmd+数字` 粘贴错条目、无数字提示、面板关闭时不可用、粘贴后改变历史顺序，或失败后没有明确说明。
- 旧历史条目仍把字符数作为主内容。
- 收藏仍埋在标签子菜单中作为唯一入口。
- 标签筛选仍需要点击展开才能看到常用标签。
- 数字提示和收藏星标重叠、共用同一右上角槽位、使用容易混淆的样式，或数字提示出现后导致收藏状态不可见。
- 设置页标签管理仍把标签颜色/图标放在标签名之后或动作按钮附近，导致归属不清；标签管理按钮仍呈现为杂乱、尺寸不一或缺少可识别状态的小按钮组。
- 详情编辑仍必须通过独立窗口完成。
- 保存/取消按钮出现或状态变化导致详情卡、编辑区、元数据或历史列表跳动。
- UI 中出现内部 key、未本地化英文或工程模型名。
- 只有自动化 PASS，没有真实 UI 或低敏真实路径证据。

## 8. 门禁更新范围

本节只定义验收和门禁范围，当前 PRD 确认前不修改 `tools/verification`。

### 8.1 需要更新的既有门禁

- `p13c_clipboard_panel_interaction_layout_checks.py`
  - 当前问题：旧门禁仍把 single-click/double-click 粘贴模式和 paste activation toggle 当作通过条件。
  - 005 要求：改为断言旧模式开关已退出；单击只选中、双击粘贴；数字提示槽不引发布局跳动；标签平铺和收藏独立。

- `p13b_clipboard_tags_model_checks.py`
  - 当前事实：模型层 favorite tag 可继续存在。
  - 005 要求：补 UI 断言，确保收藏入口不暴露底层标签模型，收藏筛选固定第一，普通标签只用颜色圆点。

- `p13d_clipboard_detail_edit_checks.py`
  - 当前问题：已覆盖 overlay dirty guard 和保存命令，但未覆盖“上方详情卡内编辑”“编辑区内固定保存/取消操作栏”“所有条目自定义标题”。
  - 005 要求：新增详情卡布局、按钮稳定、自定义标题保存不置顶不写剪贴板的断言。

- `p11e_clipboard_hardening_checks.py`
  - 当前重点是 payload boundary。
  - 005 要求：继续防止默认 UI 直接读取 payload；新增确认旧 pinned displayName 不作为标题路径、旧 preview/search 不泄露历史命名语义。

- `p8_clipboard_product_polish_checks.py` / `p8i_settings_clipboard_system_checks.py`
  - 005 要求：更新为新卡片标题、标签平铺、设置页标签管理按钮、硬编码英文和内部 key 检查。

### 8.2 需要新增的 005 专项门禁

- 005A 信任链路门禁：
  - schema 含 `last_copied_at` 和 record 级自定义标题字段或窄表。
  - duplicate insert 更新最近复制时间但不新增记录。
  - `Cmd+数字` 路径不更新最近复制时间。
  - 无 target app 时仍写系统 pasteboard 的路径可被 fake/spy 验证。

- 005B UI 门禁：
  - 默认标题为本地化类型，自定义标题覆盖。
  - preview/search builder 不再把字符数/字节数作为主内容。
  - 数字提示槽和收藏星标槽不同，且存在稳定占位。
  - 标签平铺区域位于筛选区最后，收藏固定第一。

- 005C 详情门禁：
  - 详情不是 overlay 浮层，而是面板内布局节点。
  - 保存/取消位于编辑区内部固定操作栏。
  - 自定义标题保存不触发 pasteboard、不更新最近复制时间、不隐式收藏。

- 005D 本地化门禁：
  - 005 涉及 key 必须含 `zh-Hans`、`en`、`ja` 且状态为 translated。
  - 默认 UI 路径不得出现 `Edit details`、`New Tag`、`Clipboard capture skipped`、`Content is unavailable for this record.`、`Ready`、`Unsaved` 等硬编码英文。
  - 不得出现 `clipboard.filter.tags` 等内部 key 外露。

## 9. 代码扫描确认的本地化范围

- `ClipboardDetailEditorView.swift`：确认弹窗、状态、按钮、完整值查看、accessibility label 当前存在硬编码英文。
- `ClipboardDetailStore.swift`：repository unavailable、record unavailable、save failed、URL validation、dirty navigation 等错误文案当前存在硬编码英文。
- `ClipboardRepository+DetailEdit.swift`：metadata 标题、只读原因、source fallback 当前存在硬编码英文。
- `ClipboardSearchDocumentBuilder.swift` 和 `ClipboardRepository+SearchDocuments.swift`：redacted/unavailable、characters/bytes 等 preview 文案当前存在硬编码英文或旧语义。
- `ClipboardRecordViews.swift`：`Edit details`、`New Tag` 当前存在硬编码英文。
- `PrivacySettingsPane.swift` / `PrivacyAppRowView.swift`：截图提到的隐私页英文需要纳入 005D 验收。
- `ClipboardSettingsPane.swift`：标签管理 tooltip、动作、状态需确认中英日三语。

## 10. 分阶段验收输出

实施阶段每个 phase 必须产出一条验收记录，记录至少包含：

- 修改范围：列出实际改动文件和未改动边界。
- 自动化结果：列出运行命令、PASS/FAIL、失败原因或未运行原因。
- 真实低敏证据：截图、录屏或等价日志摘要，必须避免用户真实隐私内容。
- 未验收项：无法真实验证的项必须标明未验收，不得写成完成。
- 残余风险：只允许记录非核心诉求残余风险；F1-F12 核心项未通过不得关闭 005。
