# Blocks 全局主题与原生材质开发与验收记录

状态：verified
日期：2026-07-19

## 根因与实施前状态

- 历史浅色验收通过独立 Blocks 进程参数强制 Aqua；macOS 锁屏后清理未完成，该进程持续运行，造成 Blocks 一直显示浅色。
- 只读核验显示 macOS 全局外观仍为 Dark，App 偏好域也没有持久化 `AppleInterfaceStyle` 或 `NSRequiresAquaSystemAppearance`。
- 实施开始时已只退出带强制 Aqua 参数的 Blocks 进程，没有修改系统全局外观。

## 当前实现

- 新增三态 `AppAppearancePreference` 和 `AppAppearanceStore`，默认跟随系统并通过 `NSApplication.appearance` 即时应用。
- 通用设置新增三段式外观 Picker，并补齐中英日 String Catalog。
- 新增全局 `BlocksVisualTokens`、`BlocksSurfaceRole`、`blocksBackground` 和 `blocksSurface`。
- 重构 `GlassPanel` 复用统一表面，迁移设置、主侧栏、剪贴板、翻译、截图工具面板和 HUD 的结构性材质。
- 截图选区、画布和导出渲染未接入主题表面。

## 安装版真实验收

- “跟随系统 / 浅色 / 深色”均可在设置中即时切换；重新打开窗口后继续继承当前 App 外观。
- 将偏好恢复为“跟随系统”后重启，仍保持 `system`；macOS 全局 `AppleInterfaceStyle` 验收前后均为 Dark。
- 当前 Blocks 进程没有 `-AppleInterfaceStyle` 或 `-NSRequiresAquaSystemAppearance` 参数。
- 设置、剪贴板设置、翻译设置、截图设置、截图编辑工具栏和比例 Popover 已完成浅深色对照。
- 剪贴板实际面板使用 App 容器内新建的空白验收存储启动，未读取或记录用户剪贴板历史。
- 截图编辑器证据采用低敏合成内容；外观切换不改变画布和导出数据。

## 残余验证边界

- 当前机器为 macOS 26，已真实验收 Liquid Glass 路径；macOS 14–25 的 Material 回退完成编译和静态边界检查，但未在对应旧系统真机运行。
- “降低透明度”回退已由表面角色单元测试覆盖；为避免修改用户辅助功能设置，本轮没有切换系统级“降低透明度”开关做安装版截图。
- 翻译浮层默认可能读取当前剪贴板。基于隐私边界，本轮没有保存可能含真实内容的浮层截图，以翻译设置浅深色证据和窗口继承测试替代。
