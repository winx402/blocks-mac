# Blocks 全局外观与材质规范

状态：superseded-by-012
日期：2026-07-23

## 外观状态

| 偏好 | AppKit 映射 | 行为 |
| --- | --- | --- |
| 跟随系统 | `NSApp.appearance = nil` | 自动继承 macOS 当前外观及后续切换。 |
| 浅色 | `NSAppearance(named: .aqua)` | 只强制 Blocks 使用浅色。 |
| 深色 | `NSAppearance(named: .darkAqua)` | 只强制 Blocks 使用深色。 |

持久化键固定为 `app.appearance`。缺失或非法值一律回退到 `system`。禁止写入 `UserDefaults.globalDomain`、`AppleInterfaceStyle` 或 `NSRequiresAquaSystemAppearance`。

## 唯一视觉入口

- `BlocksVisualTokens`：维护共通间距、圆角、控件尺寸和描边等级。
- `BlocksSurfaceRole`：维护 `window`、`sidebar`、`content`、`settingsSection`、`floatingPanel`、`interactive`、`hud` 七类职责。
- `blocksBackground(_:)`：用于窗口、侧栏和内容区等结构性背景。
- `blocksSurface(_:)`：用于卡片、浮层、交互面板和 HUD。
- `GlassPanel`、`glassPanel`、`glassSurface` 等兼容入口已经删除；SwiftUI
  统一使用 `blocksSurface` / `blocksBackground`，AppKit 统一使用
  `BlocksAppKitGlassSurfaceView`。

## 平台材质

- macOS 26+：导航、浮层、交互表面和 HUD 使用系统 `glassEffect`；设置内容
  使用标准分组而不是每一张卡片单独套玻璃。
- macOS 14-25：按表面职责使用 `NSVisualEffectView.Material` 或 SwiftUI Material 回退。
- Sidebar 使用 `.sidebar`，浮层使用 `.popover`，HUD 使用 `.hudWindow`，内容区使用 `.contentBackground`。
- 开启“降低透明度”时，统一表面自动改用语义化系统实色，保证文字、焦点和边界可读。

## 允许与禁止

- 允许：状态色、选中态、图片预览底色、截图选区黑白对比、用户自定义标注颜色。
- 禁止：结构性 `.regularMaterial/.thinMaterial/.ultraThinMaterial` 绕过统一表面入口。
- 禁止：结构性固定白色、固定浅灰、重阴影或多层描边与系统玻璃叠加。
- 禁止：对截图画布、选区内部或最终导出像素应用主题、vibrancy 或玻璃效果。

## 实施说明

- Liquid Glass 以容器和表面职责为边界聚合，避免给每个小控件单独叠加玻璃。
- AppKit 自定义 Chrome 统一由 `BlocksAppKitGlassSurfaceView` 选择
  `NSGlassEffectView` / `NSGlassEffectContainerView` 或语义
  `NSVisualEffectView.Material`，避免 SwiftUI 与 AppKit 形成两套材质口径。
- 系统标准按钮、菜单和 Popover 保留原生绘制，只有结构性背景进入统一表面系统。
