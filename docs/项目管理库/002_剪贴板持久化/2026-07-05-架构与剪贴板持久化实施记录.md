# 2026-07-05 架构与剪贴板持久化实施记录

状态：implemented-v0
最后审阅：2026-07-05
来源级别：implementation record

本记录追踪“App 数据存储架构规范 + 剪贴板持久化首场景”的实施过程。主 agent 负责方向、范围、产出和最终验收；开发实现、质量策略和安全审查由子 agent 协同。

## 已确认方向

- 全 App 数据存储采用 `SQLite3 + Repository + sidecar blob files + Keychain + UserDefaults` 分层。
- `Application Support/Blocks/Data/Blocks.sqlite` 是首版业务数据库默认位置，`Blobs/` 保存大对象。
- JSON debug store 保留为 fixture/debug，不进入生产主路径。
- 剪贴板作为首个落地场景，生产事实源为 `ClipboardRepository`，不是 `AppState` 内存数组。
- `ClipboardCapturePolicy` 必须在保存前处理 paused、excluded、支持类型和大小限制，避免先保存 payload 再标记隐私排除。
