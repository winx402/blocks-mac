# 006_截图功能完善

状态：step-2-complete-step-3-implementation-in-progress
最后审阅：2026-07-20
来源级别：project control

本项目承接截图功能从现有基础采集能力向完整截图与编辑工具演进。参考清单只作为候选需求池，不代表其中每项均已确认；项目按阶段补充 PRD、确认交互并实施，避免一次性固化远期方案。

## 当前目标

- 同时服务通用用户和开发者，建立完整的截图采集、编辑、历史、OCR、长截图、AI 和自动化能力。
- 每个开发阶段同步定义 GUI 与 CLI/Action 能力，不维护两套核心逻辑。
- 第一阶段基础闭环已收敛为“采集 -> 编辑器前零剪贴板写入 -> 原屏统一编辑 -> 显式复制/完成，或保存到文件”。
- 第一阶段采集、输出和统一编辑器口径已经收敛并合入 `main`；Step 2 的截图历史、本地 OCR、系统标签、CLI 和专业编辑器返修已完成验收。Step 3 生产实现和 P16 自动化门禁已经完成，独立浏览器 12 帧 Page Down 序列与整页真值逐像素一致，58.5 MP final stitch、PNG/JPEG/TIFF 输出及截图历史提交 profile 已通过；物理滚轮/触控板闭环和真实 Vision OCR 资源证据仍待验收，因此阶段仍为实施中。

## 当前基线

当前工作树已切换到单一智能入口、松手即捕获区域手势、窗口/屏幕裁决、非激活 overlay、跨屏切片规划、`ScreenshotSceneDocument` 非破坏编辑、单一原屏编辑器、显式复制/完成输出终态、PNG/JPEG、单页设置工作台、智能快捷键和本地 Action Broker。进入编辑器前不写剪贴板，关闭、取消、重截和丢弃保持零输出；编辑器使用稳定属性栏和统一 36pt 工具按钮，类型化 preset 覆盖原工具及计数器、气泡、聚光、隐私遮盖、放大镜，对象命中优先于当前创建工具。

P14-A 至 P14-G、P15-A 至 P15-E、P13、P9、P11E、Core/AppTests 和 App/CLI/Broker 构建安装已通过。用户显式启用 Broker 后，最终安装版完成冷启动和历史/OCR/导出 CLI 闭环；专业工具、对象优先编辑、属性持久化和系统标签三布局已完成低敏真实 UI 验收。三屏、混合 DPI、完整 VoiceOver/Reduce Transparency/浅色矩阵仍是明确的平台残余证据。

## 已锁定边界

- 截图流程：智能入口 -> 窗口单击/区域拖拽松手/屏幕模式 -> 编辑器前零剪贴板写入 -> 原屏统一编辑器 -> 显式复制/完成或保存到文件。
- 交互式编辑必须具备可扩展冻结源上下文；构建失败时终止且不写剪贴板，并提供重新截图/取消。关闭、选择和状态条“尺寸”固定显示；水印等其余工具可在快捷、更多和隐藏三区配置。快捷工具超宽时只在快捷段横向滚动，“更多工具”只展示用户明确归入更多区的项目。
- 统一编辑器采用 breaking replacement，不保留 `ScreenshotEditorMode`、双 surface、双窗口 frame 或旧显隐字段兼容分支。
- 视觉采用功能层玻璃和统一 App token，第一阶段只应用截图及直接复用组件。
- 同时只维护一个活动编辑文档；编辑期间非破坏，完成后输出最终扁平图。
- PNG 为默认格式；JPEG 默认质量 90%，透明区域使用白底。
- 截图历史和本地 OCR 在第二阶段接入；历史开关默认关闭。
- 滚动长截图采用显式工具条模式、单屏固定区域、用户纵向向下手动滚动和应用自动采集拼接；Input Monitoring 是硬权限，不通过辅助功能代替用户滚动。
- 长截图失败只暂停并允许进程内恢复，不自动输出部分结果，也不提供崩溃后会话恢复；取消完全无输出。
- 长截图达到有效上限 90% 时预警；当前有效上限为 `16384 px` 边长与 `64 MP`，产品绝对边界不高于 `32768 px` 与 `120 MP`。
- 长图只有在统一编辑器完成后才写剪贴板，并按设置写历史和 OCR；保存成功只写指定文件，CLI 只提供 status/finish/cancel。
- GIF、视频和音频录制另建独立项目；自动上传和云分享链接不纳入当前路线图。
- Provider 截图外发默认关闭，后续按具体 Provider 授权。
