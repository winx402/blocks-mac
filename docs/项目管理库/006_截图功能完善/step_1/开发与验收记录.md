## 1. 已完成实现

- 新增独立 `BlocksScreenshotCore` framework 和 XCTest target；Core 不依赖 AppKit、SwiftUI、ScreenCaptureKit、UserDefaults 或 NSPasteboard。
- 用统一智能选择 reducer、会话 controller 和 ScreenCaptureKit adapter 替换旧区域/窗口 controller 与旧 capture service。
- 智能选择改为完整指针手势链：窗口单击捕获，按下拖动锁定区域，后续拖动持续更新终点，松手立即捕获；窗口 hover 不得抢回活动区域手势。
- 选择层拆分为会话控制器、非激活 overlay、会话级工具条和可取消倒计时；overlay 接受 first mouse，工具条使用独立事件面板并可在当前会话跨屏拖动。
- 完成比例/固定像素、边缘吸附、放大镜、窗口/屏幕裁决和跨屏切片规划；`F` 选择单屏，`Shift+F` 直接捕获全部屏幕。
- 窗口捕获与区域捕获共用跨显示器切片计划；冻结画面改为 overlay 展示后按需异步生成，指针或冻结状态变化会重建快照。
- 当前工作树以 `ScreenshotSceneDocument` 和 scene snapshot 替换旧 command 文档；Core Graphics/Core Image renderer、撤销重做、对象选择/移动/删除和画布缩放平移接入新 scene。
- 当前工作树只保留一个原屏 `ScreenshotEditorHostPanel` 和一套 `ScreenshotEditorStore`/scene/canvas；紧凑/展开仅切换同一工具条内容，不再切换窗口 frame、surface 或裁剪边界。
- 当前工作树接入实时 draft 事务；新建、移动、对象缩放、线端点和范围创建/移动/缩放均由 `begin/update/commit/cancelInteraction` 驱动，并绘制/命中控制柄。
- 窗口候选拆分内容范围与捕获范围；命中和实线高亮使用内容范围，启用阴影时另绘低透明虚线捕获范围，捕获规划使用外层捕获几何。
- 新增异步 `ScreenshotRenderPipeline`：交互预览使用不可变 scene snapshot、revision/generation 和取消机制，旧结果不得覆盖新状态；复制、保存和完成优先使用与当前 revision 对齐的缓存结果，未追平时异步等待。
- Core renderer 改为按当前 crop 计算工作区域、跳过无关元素并仅在模糊/像素化边界建立效果图；`ScreenshotSourceContext` 只长期持有单一合成源和轻量 tile descriptor。
- Quiet Pro 快速工具栏拆成固定命令区和可横向滚动的快捷工具区，补关闭、分层 Esc、真实尺寸定位和非占位状态反馈；完整编辑器只在命令层使用材质，画布和检查器使用稳定 surface。
- 工具默认样式与交互收口：箭头默认实心终点，选择 `none` 后渲染和命中均不保留隐式箭头；切换标注工具清除旧选中，返回选择工具保留刚创建对象以便立即调整端点。

- 当前工作树使用一份工具顺序、最多 6 个快捷工具 ID 和隐藏工具 ID，扩展区由其余可见工具推导；设置弹层在一条模拟工具栏中同时展示快捷/扩展区域。截图偏好已升级为 v7，v6 按 breaking replacement 原则重建默认值。
