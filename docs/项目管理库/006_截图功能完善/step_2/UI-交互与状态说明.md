# Step 2 UI / 交互与状态说明

状态：approved-for-implementation
最后审阅：2026-07-12
来源级别：confirmed UED

## 1. 设置页

- 截图设置“输出”分组增加“保存截图历史”开关，默认关闭。
- 下一行展示“自动识别截图文字”，默认关闭；历史关闭时保留值、降低透明度并禁用，不隐藏也不重排页面。
- 两行复用现有设置 section、38pt 行高、右对齐 switch、分隔线和中英日本地化。
- 历史或 OCR 写入失败只显示弱状态，不弹阻塞式确认框。

## 2. 截图系统标签

- 收藏仍固定第一；截图系统标签进入普通标签序列，使用橙色相机图标，不显示普通颜色圆点。
- 用户可拖动截图标签改变普通标签顺序，并看到 2pt accent 插入线。
- 右键菜单不展示重命名、删除、改色和合并；设置页同样不出现这些操作。
- 普通截图记录的标签关系由系统维护，卡片菜单不提供添加或移除系统标签。
- 整个标签表面是拖动命中区，不再显示三横线手柄；点击仍用于筛选，拖动显示 2pt 插入线，键盘与 VoiceOver 排序路径保留。
- 剪贴板面板的截图标签不显示专用齿轮。剪贴板设置页在截图标签行尾部提供“截图设置 →”，点击后跳转截图设置并使用已有注意力定位。

## 3. 编辑器 OCR 工具

- OCR 工具沿用统一截图工具按钮指标，完整按钮区域至少 `36×36pt`，有 tooltip、键盘焦点和 VoiceOver label。
- 进入 OCR 后画布显示十字光标；单击识别当前完整裁剪区域，明确拖动时显示矩形并只识别选区。小于约 3pt 的拖动按单击处理，避免手抖导致静默取消。
- 识别进行中全编辑器覆盖轻量 busy 层，保留取消按钮和 Esc；其他工具、属性、完成、保存和画布交互不可用。
- 成功后选择框消失，结果浮层优先靠近工具条并限制在可见屏幕内，目标尺寸约 `360×260pt`。失败或超时保留选区供重试，取消清除选区。
- 浮层包含单一可编辑文本区、复制、关闭；空结果显示“未识别到文字”，失败和超时显示重试、关闭。
- 复制成功使用现有短暂状态反馈；关闭或像素内容变化清除结果，不保留隐藏草稿。
- 取消、超时和完成只允许一个终态生效；迟到完成不得覆盖取消或超时界面。

## 4. 历史与 OCR 状态

- 自动 OCR 进行中不阻塞截图完成或历史面板。
- 截图卡片沿用图片卡片样式和混合摘要；OCR 完成后搜索命中和详情文本刷新，不改变卡片排序。
- 详情页继续允许用户编辑 OCR；用户编辑后进入锁定状态，自动和 CLI OCR 不覆盖。
- 来源事实无法可靠获取时沿用 best-effort 表达，不把截图来源伪装为确定外部 App。

## 5. 可访问性与本地化

- 系统标签、设置开关、OCR 工具、busy 状态、结果浮层、错误和弱提示覆盖中英日。
- OCR 选择、取消、结果复制和关闭均有键盘路径；焦点关闭后返回 OCR 工具按钮。
- Reduce Transparency 下浮层使用稳定不透明 surface；浅深色下边界和焦点可辨识。
