# Step 3 验收计划

状态：implementation-in-progress
最后审阅：2026-07-17
来源级别：quality plan

## 1. 验收原则

- Step 3 当前处于实施中。本文件区分已执行的自动化门禁与尚未完成的真实 UI/资源证据，不用其中一类替代另一类。
- 算法正确性以有真值的代码 fixture 为主，真实网页/文档用于验证系统集成和体验；两者不能互相替代。
- 可见交互、Input Monitoring、真实滚动、HUD、编辑器和系统输出必须在最终安装版做真实证据，不能只用静态脚本验收。
- 失败、取消、崩溃、权限撤销和资源上限属于阻断路径；发现自动部分输出、正文误删、超限分配或绕过编辑器写 sink 时不得接受。

## 2. 自动化门禁

以下门禁已经落地；后续算法、状态或输出契约变化时必须同步更新 fixture 和断言，不能只保留字符串存在性检查：

- P16-A 拼接 Core fixture：覆盖纵向位移、变速重叠、多解、零/反向/横向移动、固定头部/页尾、动态边缘拒绝、动态块、到底候选和尺寸预算；输出结构化 `status/failures/observations/metrics`。
- P16-B 会话状态与恢复：覆盖 ready/Start、采集、3 秒倒计时及撤销、paused/Resume、limitReached、finish/cancel first-terminal-wins、stale generation 和单会话门禁。
- P16-C 权限与 HUD：覆盖 Input Monitoring 独立诊断、硬门禁、刷新/重启状态、HUD 自身窗口排除、键盘/VoiceOver 和中英日资源完整性。
- P16-D 输出与清理：覆盖中间帧零 sink、final stitch 失败、编辑器完成/保存、保存取消/失败、编辑取消、临时目录清理和崩溃后不恢复。
- P16-E Action / CLI：覆盖仅 status/finish/cancel、session ID、状态能力、paused/ready 拒绝 finish、stale session、竞争终态和低敏输出。

P16-A 至 P16-E 任一阻断失败均不得把 Step 3 标记 complete。生产阈值必须可追溯到 P16-A fixture 版本与 `拼接原型报告.md`，不能只存在于代码常量。

本轮 P16-A 至 P16-E 已通过；58.5 MP final stitch、PNG/JPEG/TIFF 输出和截图历史提交资源剖面已闭合。真实手动滚动、失败恢复和真实 Vision OCR 资源证据仍按第 4 节执行。在这些证据闭合前，Step 3 保持实施中。

## 3. 核心测试矩阵

### 拼接与内容完整性

- 小、中、大步长向下滚动；不同重叠比例、Retina 缩放、纯文本、图文、表格、代码、重复列表和空白区域。
- 零位移、向上滚动、横向漂移、快速惯性、滚动后回弹、丢帧和重复帧。
- 无固定区域、静态固定头部/页尾、动态粘性头部/页尾、多层粘性区域及正文边缘与固定区域相似。
- 动画、加载占位、闪烁光标和局部视频；无法可靠拼接时必须暂停而非误接。
- 真到底、短暂停顿、延迟加载和倒计时期间新增内容；3 秒倒计时可撤销且只完成一次。

### 状态、权限与恢复

- 屏幕录制/Input Monitoring 均允许、分别缺失、运行中撤销、授权后需重启或身份不匹配。
- ready 前不采集可输出帧；Start 后才建立首帧；普通截图和 Action 并发被会话门禁拒绝。
- 键盘滚动时把鼠标放在选区外，Page Down、方向键和 Space 仍应触发采样；滚轮和滚动条拖动在选区外不得误采样。
- 匹配歧义、capture 暂时失败、event tap 中断、显示器变化和资源压力进入 paused。
- Resume 成功从最后一致锚点继续；Resume 失败保持 paused；paused 不允许 GUI/CLI finish。
- App 正常退出、强制结束、崩溃模拟和重启后无恢复入口，stale 临时目录被清理且无输出。

### 尺寸与资源

- 宽、高、总像素分别成为最先限制项；90% 前无警告，达到阈值持续警告。
- 即将超限的一次 append 在分配前被拒绝；当前有效输出边长不高于 `16384 px`，总像素不高于 `64 MP`，绝对保护边界为 `32768 px` / `120 MP`。
- 接近有效上限时记录 frame match、final stitch、编辑器加载、PNG/JPEG/TIFF 输出、历史提交和 OCR 入队的峰值内存、临时磁盘和耗时。58.5 MP final stitch、三种编码及截图历史提交已经有显式 profile；真实 Vision OCR 仍需补充。
- 资源不足或 final stitch 失败时不打开损坏编辑器、不导出当前片段、不写 clipboard/history/OCR。

### 输出终态

- capturing、paused、finalizing、editing 各阶段检查 pasteboard changeCount、历史记录、payload sidecar、搜索/FTS 与 OCR queue，确认无本会话写入。
- 完成成功只提交当前 final revision 一次；保存面板取消/写盘失败不提交，保存成功后文件与同一 revision 的最终 sink 只执行一次。
- 保存或完成后的 pasteboard/history 单边失败和双边失败沿用 Step 2 状态语义，不回退到中间图。
- ready、capturing、倒计时、paused、limitReached、finalizing 和 editing 取消均完全无输出；finish/cancel 竞争 first-terminal-wins。
- 拼接图进入编辑器后分别执行完成、保存成功、丢弃、重截和失败，验证底层长截图会话只接收一次对应终态并回到 idle；随后必须能立即启动下一次长截图。

### CLI / Action

- Action registry 和 `blocks --help` 只增加 `blocks.screenshot.scrolling.status|finish|cancel`，不存在 start/resume 或长截图 no-editor 参数；CLI cancel 要求 `session_id` 和显式确认。
- status 的 idle/ready/capturing/bottom-countdown/paused/limit-reached/finalizing/editing 与 HUD 一致，且不泄露图像、区域、目标 App、路径或输入轨迹。
- finish 只在允许状态接受，不能跳过编辑器；paused/ready 返回结构化错误且无副作用。
- cancel 使用 session ID，清理完成后才成功；旧 ID 不影响新会话。
- GUI 与 CLI 同时 finish/cancel、重复请求、Broker 断连和迟到响应均不重复终态或 sink。

## 4. 真实 UI 与系统证据

- 最终安装版录屏：显式选择滚动长截图模式、单屏区域、ready Start、手动向下滚动、HUD 进度、Finish 和统一编辑器。
- 最终安装版录屏：高置信到底后 3 秒倒计时；继续滚动并出现新内容时倒计时撤销；再次到底后只完成一次。
- 权限证据：屏幕录制与 Input Monitoring 分别缺失、授权、刷新和必要重启；证明缺 Input Monitoring 时 Start 不可用且没有盲采集降级。
- 真实低敏网页与文档：结果与源内容逐段比对，记录接缝、缺行、重复行和固定头部表现；不能只展示缩小后的整图。
- 失败恢复录屏：可控歧义或 capture 中断进入 paused，Resume 后从一致锚点继续；无法恢复时取消且无输出。
- 90% 与有效上限证据：通过测试注入的较低上限验证完整 UI 路径，再用原型目标尺寸验证资源结论；不得为了触发产品绝对上限造成不可控系统压力。
- 输出证据：完成/保存前后 pasteboard changeCount、历史记录、OCR 状态和文件变化；取消、失败和崩溃路径必须证明没有本会话输出。
- UI/AX：HUD 拖动和屏幕边界、浅深色、Reduce Transparency、键盘路径、VoiceOver 状态播报和中英日本地化。

- 无 P0/P1；无正文误删、自动部分输出、崩溃恢复假象、超限位图或取消残留。
