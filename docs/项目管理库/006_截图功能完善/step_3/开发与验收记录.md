## 1. 已完成实现

- 在智能截图选择工具条中增加显式长截图模式；新会话恢复普通模式，长截图重截可延续本次模式。
- 长截图只允许单显示器固定区域。选区锁定后的准备态和采集态现在共用同一个 `520×64pt` 状态 HUD：左侧固定展示阶段与像素尺寸，右侧使用同一命令组；准备态显示开始、重新选择、取消，采集态显示暂停/继续、完成、取消。所有命令统一为 36pt 命中区、8pt 圆角、同一 popover 材质和相同 hover/focus/disabled 状态，不再保留准备态的第二套三按钮小工具条。共享 hosting 容器显式接收 first mouse，目标 App 保持激活时第一次点击也直接执行命令。Input Monitoring 是独立硬权限，不复用 Accessibility。
- `SCStream` 只接收完整帧，最高 30fps、`queueDepth = 6`。frame bridge 使用容量 4 的 post-demand 缓冲，并为每个语义 demand 分配稳定 request ID；返回帧只交付给对应 request，已合并需求会同步从帧源取消，不能误消费后续帧。捕获端最多保留 8 个 demand，帧回调只入有界处理队列，避免 30fps 回调在主线程串行堆积匹配工作。
- 滚动输入只触发采样，画面匹配决定方向。输入后立即采样、约 `80 ms` 再取运动帧、停止输入约 `180 ms` 后取稳定帧；完成前最多等待 `500 ms` 排空已请求的候选，避免最后一次滚动尚未评估就提前最终化。反向、重叠不足和多解先进入 `recovering`；此后由协调器每 `180 ms` 主动请求恢复帧，不依赖用户继续产生三次滚动事件，恢复锚点后自动继续，连续三次稳定失败才 paused。
- 匹配由 192px 全高灰度描述、全范围稀疏搜索、16 候选复核、二维多块相关性、致密纹理差和默认 30% 重叠比例组成；Core 无法唯一裁决时，App 侧三区域 Vision 或独立致密亮度估计只提供带符号提示。历史位移不能强制通过多解，低重叠只有在独立三区域全数一致且高置信时才接受。
- 固定页头/页尾只在可信 append 后形成共识；页头只保留一次，页尾以独立延迟条带保存。若后续帧不再含固定页尾，上一页尾会被丢弃，匹配器使用“上一帧去除旧页尾、当前帧保留完整正文”的非对称范围重新匹配，并从旧页尾起始位置覆盖写入；若出现新页尾则只保留延迟版本。页头与页尾同时变化时继续回退整帧重匹配，避免叠加不可靠假设。最终化前新增逐行连续覆盖检查，任何空洞都拒绝输出。
- `ScrollingScreenshotCaptureCoordinator`、`ScrollingScreenshotSessionCoordinator` 已拆出捕获支持、会话支持和 Vision 对齐模块；P16-B 对主协调器行数和支持类型回流设置 fail-closed 门禁。
- 长截图在展示选择层前同时检查屏幕录制和 Input Monitoring，未授权时直接拒绝，不先打开不可用 UI；选区锁定后和点击开始时再次复核，权限变化会禁用或终止开始路径。开始后根据选区实际可见窗口恢复外部目标 App；若入口来自 Blocks 设置页，不再把 Blocks 自身当作滚动目标。Broker 冷启动使用非激活配置，App 启动也不再无条件 activate；HUD、倒计时和取消确认均使用非激活 panel，不调用同步模态或唤起设置页。从设置页开始截图时，Blocks 设置窗口保留可见、位置和当前页面；ScreenCaptureKit 统一排除 Blocks 进程的全部窗口，使设置窗口不进入候选或截图像素。会话结束时仅恢复原外部 App 焦点，不对 Blocks 普通窗口执行 `orderOut`。
- 取消“疑似到底”倒计时后会先撤销倒计时帧需求并刷新当前 HUD，再展示丢弃确认；用户取消丢弃后不会停留在过期的倒计时状态。继续操作进入健康检查时有独立中英日状态播报，检查期间禁止重复点击。
- 最终输出失败只记录 stage、error domain 和 code；不记录截图正文、OCR、自定义标题或完整路径。截图历史已启用但 writer 不可用时也会输出低敏诊断，不再静默丢失。
- 会话使用 generation、terminal gate 和 exactly-once 终态；旧会话回调、迟到帧、重复 finish/cancel 均不能写状态、条带或 sink。编辑器完成先认领底层长截图终态，再执行剪贴板、文件和历史输出；Action 取消会先关闭编辑器，迟到完成回调不能再写出。清理重试耗尽时保留孤立缓存供下次启动清理，但立即释放内存会话 gate，下一次长截图不会永久报会话占用。
- 拼接图进入编辑器后继续保留原长截图 `sessionID`；完成、保存成功、丢弃、重截和失败都会把对应终态回传到底层会话并释放 gate。重复编辑器回调只接收第一个终态，不能留下阻塞下一次长截图的 `editing` 会话。
- Page Down、方向键和 Space 等键盘滚动可在鼠标不位于选区内时触发采样；只有滚轮和滚动条拖动要求指针位于选区，避免键盘滚动后无采样而被误判为重叠不足。
- 已接受内容写入权限为 `0600` 的会话条带目录；正常终态立即清理，启动时清理 stale 目录。资源采样、健康检查和分配前上限检查已接入。
- 当前有效上限为边长 `16384 px`、总像素 `64 MP`，90% 预警；绝对保护边界仍为 `32768 px` / `120 MP`，整数乘法溢出按超限处理。
- 长图只在 finalizing 成功后进入统一编辑器；只有“完成”提交最终 revision 到剪贴板/历史/OCR。“保存”只写指定文件，并以独立 `.saved` 终态关闭；保存取消/失败、编辑器取消、拼接失败和中间帧均不写剪贴板、历史或 OCR。
- 最终 PNG artifact、pasteboard、文件和历史使用同一不可变 revision；pasteboard writer 使用事务式多类型写入和受控 artifact 生命周期，避免只写一半或临时文件过早删除。
- 长图 OCR 使用纵向分块识别和重叠去重；CLI / Action 只提供 `status`、`finish`、`cancel`，不提供启动、恢复或无编辑输出。
- 普通截图相关的混合 DPI 共享边界量化、可见窗口裁决、编辑上下文构建、异步确认 sheet 和窗口生命周期也已同步收口，避免长截图改动破坏普通路径。
