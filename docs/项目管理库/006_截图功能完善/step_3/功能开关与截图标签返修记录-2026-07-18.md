# 截图、剪贴板功能开关与截图标签返修记录

状态：implemented-and-automated-verification-passed
最后审阅：2026-07-18
来源级别：implementation and verification record

## 1. 本轮范围

- 新增截图、剪贴板两个独立的整体功能开关，默认开启。
- 将旧“保存截图历史”语义替换为“截图标签”：截图完成后始终请求剪贴板归档，标签开关只决定是否附加截图系统标签。
- 剪贴板关闭时由剪贴板模块内部拒绝新捕获和截图归档，系统剪贴板写入与既有历史均保持不变。
- 增加不可变截图来源字段，使截图查询、OCR、导出和重复合并不再依赖可选标签。
- 增加剪贴板截图标签后的设置按钮，可跳转到截图设置对应行并执行两次 accent 提示。
- 同步完成长截图“从当前位置重新开始”、编辑范围比例约束、自定义比例、裁剪手势、工具条定位、倒计时退场和 Esc 直接取消等已确认返修。

## 2. 运行语义

- 截图关闭后，设置入口继续可见；菜单、快捷键、设置按钮和 Action 均拒绝新会话，Action 返回 `feature_disabled`。已经开始的捕获或编辑不被强制终止。
- 剪贴板关闭后停止 live capture，关闭面板并注销运行期面板/快捷粘贴能力；数据库、payload、标签、OCR 和搜索文档不删除，重新开启后恢复旧历史且不补录关闭期间的系统剪贴板变化。
- 本条 2026-07-19 已被显式输出终态取代：截图完成写系统剪贴板并调用归档；保存成功只写文件，不写剪贴板或历史。剪贴板关闭时完成路径的归档仍返回 `ignoredFeatureDisabled`，不写历史且不显示错误。
- 截图标签关闭时，事务内删除全部截图标签关联并隐藏系统标签，不删除截图记录。重新开启只影响未来截图，并恢复此前排序位置。
- 自动 OCR 与截图标签解耦；标签关闭时仍可处理新截图，剪贴板关闭时不产生新记录，因此不执行 OCR。

## 3. 数据与兼容边界

- 数据库升级至 v11：`clipboard_items.origin_kind` 记录不可变来源，`clipboard_tags.is_enabled` 记录系统标签启用状态。
- 迁移时仅将已有截图系统标签关联的记录回填为截图来源，不删除任何历史。
- 截图偏好升级至 v12；旧 `savesToHistory` 只在旧版本解码结构中一次性映射到 `addsScreenshotTag`，运行时不保留旧语义分支。
- 截图系统标签定义和排序在关闭期间保留，但不会出现在筛选和标签设置中。
