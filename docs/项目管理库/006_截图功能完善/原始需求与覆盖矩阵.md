## 1. 来源说明

输入来源是一份外部 ChatGPT 对话中的“Mac 截图功能列表”。该内容是未经项目验证的背景材料，只用作候选需求池。只有用户在本项目中明确确认、并写入阶段 PRD 的内容才是实施依据。

状态定义：

- `现有基线`：当前代码已有，但仍可能在后续阶段重构。
- `Phase N`：已纳入对应阶段方向；具体交互仍以该阶段确认后的 PRD 为准。
- `独立项目`：有价值，但不属于 006。
- `当前不纳入`：本路线图不安排，未来若需要重新立项。

## 3. 第一阶段明确非目标

- 不做截图历史持久化和 OCR 正式执行。
- 不做滚动截图、背景美化、AI 图片外发和自动化工作流。
- 不做图层工程文件长期保存；编辑完成后只输出扁平图。
- 不提供终端内交互式编辑器；CLI 的交互模式唤起运行中的 App。
- 不引入云服务、账号或外部图片托管。

## 4. 待阶段确认项

- 第一阶段及双模式重构已获用户确认并进入实现验证，不再把模式边界留到开发阶段临时决定。
- 全屏模式是否能稳定控制菜单栏、Dock 的包含行为，需要 Phase 1A 技术验证后确认最终产品文案。
- Phase 2 的历史创建时点、重复合并、系统标签、OCR 状态和 CLI 隐私契约已在 Step 2 PRD 中确认。
- Phase 3 的产品、UI、权限、失败和输出边界已确认并进入实施。重叠匹配、采样节奏、固定头部和到底条件已有代码 fixture 基线；内存预算、更低有效上限及真实路径稳定性仍需验证，不得把产品绝对边界描述为资源验收值。
- Phase 5 的 Provider 授权粒度、可发送数据类型和 AI 输出结构需在实现前专项评审。
