# 双击自动粘贴修复与验收

日期：2026-09-06
状态：实现已安装；TextEdit / Safari / Chrome 及补充场景通过，Codex 输入框待受控人工确认。

## 已确认问题与产品契约

安装版原先把 AX 输入控件作为粘贴硬前提。实际日志多次为 `capturedWindow=false, capturedRole=missing`，随后 `captured-focus-unverifiable`；系统另明确记录 `Blocks(33038) deny(1) mach-lookup com.apple.axserver`。主 App 已授予辅助功能并不解除其沙盒边界。

用户锁定的行为：无 Helper 时也必须支持双击自动粘贴到原 App、原窗口中的当前光标；窗口切换则取消。Helper 只能增强，不得成为安装/配对门槛。长期要求见[剪贴板自动粘贴契约](../../产品知识库/剪贴板自动粘贴契约.md)。

## 实现

- `ClipboardPasteTarget` 新增进程启动时间；上下文独立记录窗口服务器 windowID。保留的 AX 字段仅为兼容的可选信息，基础路由完全不读取外部 AX。
- 普通面板冻结打开时的目标；固定面板在双击发起时重新取得当前外部目标，然后请求保持不可变。发送前再次检查进程、启动身份、前台 App、窗口、请求有效性和写入凭据，不强制激活或后台派发。
- 事件权限改用 `CGPreflightPostEventAccess` / `CGRequestPostEventAccess`。权限刷新和权限引导回调只清理旧 pending 请求并提示重新双击，不自动重放。显式重试接口仍复用已提交凭据，避免再次写入。
- 保留插件准入、一次写入、近期记录提交与迟到效果隔离。只读复核补上首次 await 校验返回后的取消检查，防止旧请求在取消后仍弹权限提示。
- Helper v4 协议增加可选能力协商及只读 `inspectPasteTarget`，旧健康响应缺 capabilities 时为 `[]`，不重配。仅返回 editable / nonEditable / unknown，不返回正文、不操作剪贴板、焦点或按键。
- Client 从入口起总计最多 150ms，所有同步依赖移到专用队列，超时 one-shot 恢复调用方；真实后台退出前保持 busy，忙时直接降级。Helper 服务端同样单项在飞、80ms 单调截止，各次 AX 元数据读取使用剩余超时。未知/不可用/旧版本/超时走基础路径，仅明确 nonEditable 拦截。
- 未改主 App 沙盒或添加 axserver 例外；未改远程复制卡顿相关实现。独立 Helper 安装版未更新。

## 沙盒可行性门禁

临时 probe 位于 `/private/tmp/blocks-paste-feasibility-20260906/`，沿用已安装主 App 的开发签名身份与嵌入 profile，签名严格校验通过；两者签名中的 entitlement 字典逐项相同，sandbox=true。

Probe 未链接 Helper 客户端，只写合成文本并发送一次标准 Command+V。`CGPreflightPostEventAccess=true`，TextEdit 实际出现 `BLOCKS_SANDBOX_PASTE_PROBE_20260906`，已通过 CUA AX 值和实图核对。此证据只证明沙盒可行性，不替代后续真正双击验收。

准备过程中，针对背景窗口的 AX 聚焦不一定改变系统真实前台；probe 曾因前台仍是 Codex 而拒绝发送。通过 Finder 的真实文件打开操作切换前台后成功，未删除保护条件或绕过工具限制。
