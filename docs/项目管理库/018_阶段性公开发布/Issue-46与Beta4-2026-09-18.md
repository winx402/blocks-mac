# Issue #46 与 Beta 4

## 事实与范围

用户报告 Xcode 27.0（27A266a）在 `executeAction` 的 SIL SimplifyCFG 优化阶段重复崩溃。本机仅有 Xcode 26.6，不能重现或宣称已经消除 Xcode 27 的原崩溃。Git 对照确认 8390446 并未改变该函数本体，“剪贴板新增分支导致泛型膨胀”不是已证实的直接原因。

## 代码结构规避

- 泛型 `executeAction` 返回非泛型 `CLIExecutionOutput`，不在泛型执行函数中终止进程；9 个动作分发由非泛型 `emit` 统一退出。
- 独立编码、错误分类与输出文件生命周期，保留 finalize 后再编码的顺序，错误或取消清理临时文件。
- 使用 `@inline(never)` 隔离相关边界，不关闭优化，不改 IPC 身份验证、超时取消、命令参数及退出码。
- 新增 `cli_execution_output_self_test.py` 并纳入 CI。
