范围：#66 权限恢复重启、#68 更新准备，以及共用的 Broker 退出检查。此记录不替代

## 安装版复现

当前 UID501，官方 `/Applications/Blocks.app` 为 beta22/build22，Developer ID、Hardened
Runtime、App Sandbox 均保留。主 App PID49670 未被替换或强制结束。

在权限页选择辅助功能“已开启，仍无效”，检查后点击“重新打开并检查”。实际没有重启，
原 App 保持运行，界面报告安全重启未能完成。2026-10-23 17:18:09 的同次记录为：

```text
kernel: Sandbox: Blocks(49670) deny(1) process-info-listpids
Blocks: application-lifecycle event=failed intent=update category=participant_drain_failed
```

17:40 再次通过只读 unified log 查询复核上述时间、PID、拒绝项及失败分类。
准备流程中的 Broker 参与者调用 `currentBrokerProcessIDs`，原实现以 `proc_listallpids`
获取全进程列表；即使服务状态为未注册，安全检查也会走这条路径。失败不是输入框识别、
Helper 配对或用户有活动 CLI 任务的证据。系统权限没有修改。

## 独立签名沙盒探针

使用临时、独立 Bundle ID 的 AppKit 探针，Developer ID 与官方 App 同 Team，
Hardened Runtime 开启，唯一 entitlement 为 `com.apple.security.app-sandbox=true`。
没有申请新的 TCC 权限、沙盒例外、IPC 或后台服务。

受控 CLI 夹具仅打印自身 PID 后等待：可执行文件名为 `BlocksActionBroker`，但签名角色是
独立的 verification identifier，不是生产 Broker；不提供 IPC，也不接触剪贴板或用户数据。

同一个真实沙盒进程中得到：

- `proc_listallpids`、按 UID 和进程组的 `proc_listpids` 均返回 errno1。
- `sysctl(KERN_PROC_UID)`、`sysctl(KERN_PROC_ALL)` 的 sizing 与实际读取均成功。
- 实际返回长度与 `kinfo_proc` stride 对齐，ALL 列表包含其他 UID，不缩成当前 UID 范围。
- 两种列表均准确包含受控夹具一次；`proc_pidpath` 从沙盒读取其准确路径成功。

这证明候选 API 在当前系统／签名／沙盒下可执行，不证明生产 App 的完整重启或更新已经成功。
实现依据为 Apple 的 [sysctl 手册](https://developer.apple.com/library/archive/documentation/System/Conceptual/ManPages_iPhoneOS/man3/sysctlbyname.3.html)：
`KERN_PROC_ALL` 返回进程表；进程表在 sizing 与读取之间增长时必须处理缓冲区不足。
不从这台 macOS27 的结果推定全部受支持系统都已通过。

## 修复边界

仅替换进程列表的枚举层：使用公开 `sysctl(KERN_PROC_ALL)`，仍扫描全进程而非只扫当前
Bundle/当前 UID。保留既有路径分类、认证排空、恢复凭据、进程生命周期与退出确认。

读取采用有上限的对齐缓冲区和有限次重新 sizing；拒绝权限错误、异常长度、PID 数据异常
以及缺失当前进程的列表。失败不转换为空列表，不跳过 Broker 安全检查，不用强退、
注销服务、放宽身份校验或关闭沙盒掩盖错误。失败诊断不输出全进程路径或用户数据。

## 验证与剩余门槛

已接入独立 Darwin `BrokerProcessInventory.swift`，manager 只替换枚举入口；分类器、
认证排空与生命周期保护未改。失败新增固定 stage/reason/errno 的 unified log，
不输出进程名称、路径或 PID 清单；该失败日志的生产运行触发尚未验证。

同一签名沙盒探针直接编译上述**实际生产源文件**，不是另一份重写实现。三次实际枚举均：


拒绝。probe 的签名严格校验通过，唯一 entitlement 仍为 sandbox=true。之后正常关闭探针、

App 的 Launch Services 注册。原 `/Applications/Blocks.app` PID49670 保持不变。
