# 渠道能力矩阵

状态：implemented-locally
最后更新：2026-08-08

| 能力 | Direct Beta | App Store Beta |
|---|---|---|
| 架构与系统 | arm64，macOS 14+ | arm64，macOS 14+ |
| 更新 | Beta 1–2 手动打开下载页；Beta 3 计划接 Sparkle | TestFlight / App Store 系统更新 |
| CLI | 包含 | 从包内移除，设置入口不展示 |
| ActionBroker / LaunchAgent | 包含 | 从包内移除 |
| ClipboardBroker | 包内辅助进程 | 包内辅助进程，随 App Sandbox 边界运行 |
| Selection Helper | 独立、用户主动下载和授权；不由主 App 静默安装 | 不打包，不展示下载、打开或配对入口 |
| 外部 `.blocksplugin` | 允许用户主动安装 | 安装/导入/确认/加载均拒绝 |
| PluginRunner | 可执行允许的官网版插件 | 仅执行审核包内固定的内置插件；产物审计拒绝其他插件包 |
| 截图、剪贴板、翻译、OCR | 保留 | 保留，受沙箱和商店能力边界约束 |
| 诊断 | 本地脱敏 JSON，用户检查后自行提交 | 同一脱敏导出；测试反馈另由 Apple 提供 |
| 自动遥测 | 无 | 无 |

## 编译期边界

- `BLOCKS_DIRECT_BETA` 选择 Direct Beta 能力。
- `BLOCKS_APP_STORE_BETA` 选择商店兼容能力。
- 未设置二者时为开发渠道，不能被当作发布产物。
- AppStoreRelease 的构建阶段还会删除 CLI、ActionBroker 和 LaunchAgent；产物审计检查最终 `.app`，不只检查源码开关。

## 必须继续验证

- Store Archive 签名后的最终 entitlement、provisioning profile 和内嵌代码列表。
- PluginRunner 在审核包中不存在任何绕过宿主校验的外部代码入口。
- Sandbox 下截图、剪贴板、OCR、翻译与用户选择文件的真实交互路径。
- App Review 当前规则与最终渠道文案一致。
