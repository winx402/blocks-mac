# Issues #48/#49 与 Beta 6

## 实现与证据边界

- #48：收藏使用共享图标按钮的可选黄色 tint；overlay 保持稳定身份，父级 hover 覆盖所有 overlay。非固定面板外部关闭先 orderOut 再清理状态；单击只选择，移除默认详情层、状态传播及辅助功能详情入口，保留内部 Detail 模块。
- #49：保留 SwiftUI 原生 Menu，macOS 15+ 明确允许窗口激活事件；原 macOS 14 first-mouse 策略保留。标签使用共享 chip feedback 样式和限定可见区域的手形光标。
- 诊断 probe 不命中、不消费事件，返回原 event；只记录 group、window、key 和阶段，不记录正文、查询或来源名称。可见范围取 bounds 与 visibleRect 交集，避免 AppKit 未裁剪 visibleRect 误报相邻控件。
- 用户原日志在 14:16:26 有菜单动作，14:34:23/42/47 有菜单服务打开，14:34:54 有成功选择，之后无菜单日志。该时间线不能证明具体哪个层吞掉事件；当前补丁是激活策略加固与诊断，不把推断写成已确认根因。

## 隔离生产 UI 实测

使用当前开发构建的独立副本、独立 Bundle ID 和数据目录，仅 3 条合成记录。禁用 live capture、Helper 等后台服务，未访问用户历史、未更改权限、未更新日常安装版。这不等同正式安装版全链路验收。

- 格式/时间/来源菜单均打开并实际筛选；标签 Examples 筛选为两条，昨天筛选为一条。
- 单击记录仅选中、没有详情；辅助功能无详情动作。
- 收藏后显示黄色星标，坐标点击星标取消收藏。
- 固定面板切换至合成焦点窗口后，菜单仍可打开和筛选。诊断实际观测 key=true，不能据此声称已证明原始 non-key 首击路径。
- 工具无法可靠产生持续纯悬停或真实全局外部鼠标事件；外部关闭视觉、纯 hover 稳定性及原 macOS 27 长时间/多显示器场景仍未验证。#48/#49 保持开放，发布补丁不代替原场景验收。
