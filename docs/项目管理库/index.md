## 项目目录规则

- 每个项目使用 `NNN_项目名/` 作为独立目录，例如 `001_工具重命名/`。
- 不拆阶段的项目，文档直接平铺在项目目录下，例如 `项目说明.md`、`prd.md`、`实施记录.md`。
- 拆分多个阶段的项目，在项目目录下放 `step.md` 作为阶段总览，并按需创建 `step_1/`、`step_2/` 等阶段目录。
- 子 agent 输出必须进入所属项目目录；如果输出只属于某个阶段，则放入对应 `step_*` 阶段目录。
- 根层只维护本索引、项目目录和归档目录，不再新增散落的规划产物或实施记录目录。
