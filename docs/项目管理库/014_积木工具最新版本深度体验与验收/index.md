## 结论

本轮对最新本地 Debug 版本执行了重新构建、唯一运行实例确认、真实 UI 深度体验、外部 App 快捷键验证、冷启动复核、运行时日志审阅和自动化回归。

修复后核心阻断项通过：三个默认全局快捷键已在外部 TextEdit 中逐一真实触发；“数据与审计”清空已覆盖取消和确认；剪贴板与翻译浮窗已完成低敏核心交互。Provider/翻译反馈、重复标签、品牌、布局以及可归因的运行时告警同步收口。补充发现的“复制普通文本形式的 Codex 线程 ID 后整机卡顿”也已按真实主线程采样定位并修复，最终安装版隔离验证未再出现同步图片解码栈。

本轮继续关闭了此前可控的剩余项：外部翻译引擎的缺失配置状态现在可在设置页直接选择并取得安装版反馈；自动化触发页明确区分“规则已定义”和“运行能力未开放”；OCR 增加真实 Vision 中英日/混排基准、低置信度大图分块补救，并在安装版截图编辑器完成真实识别。

当前只保留外部环境边界：AX 自动化读取最小 SwiftUI `Text` 程序也会触发同样的负尺寸几何日志，证明该日志来自 macOS 26 的 AppKit/AX `ThemeWidgetControlViewService` 链路，而不是 Blocks 页面布局。真实 Provider 网络、Keychain 和系统权限变更仍未获授权，继续标记未验证，不伪装成产品修复。
