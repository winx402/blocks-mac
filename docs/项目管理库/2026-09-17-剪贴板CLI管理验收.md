# #43 剪贴板 CLI 管理与迁移

## 已实现

- 官方 `blocks clipboard` 入口：查询、搜索、查看、导入、导出、收藏、标签、分组创建/改名/移动、预览确认删除。
- Broker 验证身份，App 使用现有存储串行队列与提交门禁；CLI 不直写数据库。
- 版本化 JSON，严格批量校验、去重与分组冲突处理、事务/附件回滚、真实 dry-run。
- 导入拒绝符号链接、FIFO、超限及不安全 RTF；导出文件 0600、不覆盖既有路径。
- 摘要开关生效；全文查看/导出每次确认实际范围，45 秒超时，批准后重验快照。外部令牌不能绕过确认，dry-run 不输出全文。

## 本轮验证

- LocalDevelopment 主 App、CLI、Helper 构建通过。
- 最终专项 XCTest：33/33（13 Core、4 Host、16 Consent），无跳过。包含隔离数据库往返、SQL 失败回滚、取消、RTF 边界、数据变更、授权拒绝/超时/关闭与迟到回调，以及响应编码后的取消/撤权终检和相对日期跨日/时区选择变化。
- 较早扩展回归：94/94（含原截图仓储与 Broker）；最终隐私补丁由上述 33 项专项覆盖，未把较早结果标成最终全量重跑。
- CLI 参数与真实临时文件 I/O 自检通过；P14/P15 旧 CLI 合约门禁通过。修正独立编译依赖与未签名 CLI 应在身份校验阶段拒绝的旧断言。
- 未改动真实历史数据库，未开启本机 CLI 服务，未批准真实内容导出。
- 最终开发安装版已更新并正常打开；实机设置页显示摘要开关、单次确认说明、禁用的未实现默认范围/时长，以及仍关闭的动作代理服务。内置已签名 CLI 的 `clipboard --help` 返回新增命令。

## 初次提交时尚未通过的交付门槛

- 安装版签名 CLI → Broker → App 的真实授权导入/导出流程，需要用户开启 CLI 服务后使用明确的测试范围验收。
- 尚无 PasteEasy 实际导出样本；通用 JSON 格式并不等于其私有格式已适配。
- 初次提交时 #43 保留开放，不以测试通过冒充完整迁移验收。本轮不发布新版本。

## 安装版端到端复验（用户随后授权）

使用已签名安装版内置 CLI，经真实 Broker/App 执行；临时开启动作代理服务，仅处理五条具有随机唯一标记的合成记录。

- `text/url/rich_text/file_url/image` 五类型导入成功；dry-run 后查询没有新增，正式导入 inserted=5。
- 重复导入 inserted=0、duplicates=5；按导入返回的精确 ID 查询全部记录。
- 收藏、移动到内置 work 分组、标签 favorite 增删、取消收藏成功；创建分组 dry-run 成功（没有持久创建测试分组，真实创建/改名仍由此前隔离测试覆盖）。
- 两次真实导出请求均出现 App 授权面板，展示操作与实际选中数5；第一次取消返回 full_content_access_denied 且不生成文件，第二次仅允许本次后导出成功。
- 导出五种 payload 与原始输入逐字段/字节一致，输出权限0600，终端结果不包含完整文档；导回仍为5条重复，无新增。
- 临时关闭摘要开关后，限定测试标记的搜索返回 summary_access_denied；随后恢复摘要开关为原值。
- 正常退出并重启 Blocks 后，五条精确 ID 仍存在。
- 删除预览选中5条，使用对应 token 确认后删除5条；逐个 ID 查询均为 record_not_found。未操作已有历史。
- 动作代理服务恢复为关闭，界面状态为未登记。

发现既有标题搜索限制：图片仅自定义标题包含标记时，内容搜索未命中；精确 ID 的查询与导出正常。该项单独登记问题，不宣称搜索完全无缺陷。

结论：#43 的通用导入、管理和导出通道通过安装版主链路验收，按用户要求关闭。PasteEasy 私有格式适配不在本次实现范围，仍不宣称已验证该产品的数据迁移。没有发布新版本。
