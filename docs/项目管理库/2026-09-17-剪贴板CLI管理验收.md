# #43 剪贴板 CLI 管理与迁移

## 已实现

- 官方 `blocks clipboard` 入口：查询、搜索、查看、导入、导出、收藏、标签、分组创建/改名/移动、预览确认删除。
- Broker 验证身份，App 使用现有存储串行队列与提交门禁；CLI 不直写数据库。
- 版本化 JSON，严格批量校验、去重与分组冲突处理、事务/附件回滚、真实 dry-run。
- 导入拒绝符号链接、FIFO、超限及不安全 RTF；导出文件 0600、不覆盖既有路径。
- 摘要开关生效；全文查看/导出每次确认实际范围，45 秒超时，批准后重验快照。外部令牌不能绕过确认，dry-run 不输出全文。

## 本轮验证

- LocalDevelopment 主 App、CLI、Helper 构建通过。
- 最终专项 XCTest：33/33（13 Core、4 Host、16 Consent），无跳过。包含隔离数据库往返、SQL 失败回滚、取消、RTF 边界、数据变更、授权拒绝/超时/关闭与迟到回调，以及响应编码后的取消/撤权终检和相对日期跨日/时区选择变化。
- 较早扩展回归：94/94（含原截图仓储与 Broker）；最终隐私补丁由上述 33 项专项覆盖，未把较早结果标成最终全量重跑。
- CLI 参数与真实临时文件 I/O 自检通过；P14/P15 旧 CLI 合约门禁通过。修正独立编译依赖与未签名 CLI 应在身份校验阶段拒绝的旧断言。
- 未改动真实历史数据库，未开启本机 CLI 服务，未批准真实内容导出。
- 最终开发安装版已更新并正常打开；实机设置页显示摘要开关、单次确认说明、禁用的未实现默认范围/时长，以及仍关闭的动作代理服务。内置已签名 CLI 的 `clipboard --help` 返回新增命令。

## 尚未通过的交付门槛

- 安装版签名 CLI → Broker → App 的真实授权导入/导出流程，需要用户开启 CLI 服务后使用明确的测试范围验收。
- 尚无 PasteEasy 实际导出样本；通用 JSON 格式并不等于其私有格式已适配。
- #43 保留开放，不以测试通过冒充完整迁移验收。本轮不发布新版本。
