## 2026-07-26 全局局部通知组件

### 实现事实

- 新增共享通知等级、关闭策略、描述、卡片和展示状态。状态只管理所属模块当前
  一条通知，支持优先级、同键去重、悬浮/焦点暂停和生命周期取消，不引入跨窗口
  队列。
- SwiftUI 页面统一使用 `BlocksNotificationHost`；截图捕获这类无 SwiftUI
  宿主的场景只通过一个 `.nonactivatingPanel` 桥接共享卡片。桥接窗口不成为
  Key Window，通知不改变原第一响应者。
- 剪贴板旧屏幕共享橙色横幅、Published 状态、关闭接口和对应本地化已删除。
  屏幕共享旧签名重现只保留诊断日志，不再产生 UI。
- 剪贴板通知锚定标签筛选可见视口尾部；翻译和截图设置使用内容区右上角；截图
  捕获使用当前显示器安全区顶部；截图编辑通知避让顶部状态条。
- 真实安装版首次验收发现通知内部 3pt 状态标记接受了父 Overlay 的整页高度，
  导致 HUD 被拉成整列玻璃。已为卡片固定垂直固有尺寸，重新构建后真实截图确认
  恢复为内容自适应高度。
