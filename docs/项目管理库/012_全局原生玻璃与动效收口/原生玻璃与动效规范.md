# Blocks 原生玻璃与动效规范

状态：implementing
日期：2026-07-23

## 设置导航

- `SettingsNavigationShell` 是主窗口和 Settings Scene 的唯一导航壳层。
- Sidebar 使用 `NavigationSplitView + List(selection:)`，列宽范围为
  `208 / 224 / 248pt`。
- Detail 自己持有顶部锚定的垂直 `ScrollView`；详情内容高度不得参与侧栏根布局。
- Sidebar 使用系统选中态、SF Symbols 和语义色，不自绘选中描边、渐变徽标或阴影。

## 表面职责

- `BlocksSurfaceRole` 是 SwiftUI/AppKit 共用的材质语义。
- macOS 26 的自定义浮层使用 `NSGlassEffectView` / `glassEffect`，同层相邻
  玻璃由 Container 聚合。
- macOS 14–25 使用 `.sidebar`、`.popover`、`.hudWindow`、
  `.contentBackground` 等语义 Material。
- 开启“降低透明度”时使用系统语义实色。
- 设置内容使用标准 `GroupBox` 和系统控件；禁止每个设置分区重复套玻璃。

## 动效职责

| 角色 | 标准时长 | 使用范围 |
| --- | ---: | --- |
| microFeedback | 120ms | 悬浮反馈、插入光标、紧凑控件状态 |
| stateChange | 180ms | 展开、结果/错误、反馈消息 |
| navigation | 220ms | 设置导航、浮层和注意力定位 |

“减少动态效果”开启后禁止位移、缩放和玻璃形变；微反馈立即切换，其他状态最多
使用 120ms 淡入淡出。禁止根容器无边界隐式动画。

## 截图参数

- 四项配置使用相同的 `Key + 4pt + 96×28pt Value` 结构。
- Key 为 11pt semibold、固定宽度、轻量 Accent 背景；Value 为 12pt medium。
- 标签不可点击，完整 Value 区域可点击；切换语言和值时工具条外形不改变。

## 局部通知

- 全 App 自定义通知只使用 `BlocksNotificationCard` 和
  `BlocksNotificationPresentationState`；各模块持有自己的展示状态，不建立跨窗口
  全局队列。
- 卡片默认宽 300pt，可在 260～360pt 内收敛；圆角 12pt、内边距 12pt、
  内容间距 10pt，使用 `BlocksSurfaceRole.hud`。卡片必须按内容决定高度，禁止
  接受宿主 Overlay 的整页高度提案。
- 信息、成功、警告、错误仅通过 3pt 左侧标记、16pt SF Symbol 和语义色区分，
  不给整卡铺高饱和背景。
- 成功默认 2.5 秒、信息默认 4 秒关闭；警告、错误和带操作通知手动关闭。鼠标
  悬浮或键盘焦点进入卡片时暂停计时，离开后继续。
- 同一模块的新通知替换旧通知；持久错误不能被低优先级通知覆盖。相同
  `deduplicationKey` 合并次数和时间，不重复播放入场动画。
- 通知不能主动取得第一响应者、改变当前选择或截获 Esc。页面退出、窗口关闭和
  通知替换必须取消旧计时任务。
- 剪贴板通知浮在顶部标签筛选可见视口尾部下方 6pt；截图捕获/编辑通知位于当前
  屏幕安全区顶部，截图设置通知位于内容区右上角。系统级长截图 HUD、行内校验和
  危险操作确认继续使用各自既有职责，不重复弹通知。
