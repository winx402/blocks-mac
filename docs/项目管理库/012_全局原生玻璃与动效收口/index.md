# 012_全局原生玻璃与动效收口

状态：historical-implemented-superseded-by-017
最后审阅：2026-07-23
来源级别：project control

## 目标

- 主窗口和 Settings Scene 共用原生设置导航壳层。
- SwiftUI 与 AppKit 只保留一套按职责划分的 Apple 原生材质入口。
- 截图参数条用稳定、等宽的 Key/Value 层级表达配置关系。
- 建立全 App 唯一动效角色，并完整响应“减少动态效果”。

## 当前边界

- 保留“跟随系统 / 浅色 / 深色”，但只控制 `NSApplication.appearance`。
- 截图画布、选区、标注颜色和最终输出不参与主题或玻璃渲染。
- 动画不介入复制、自动粘贴、截图绘制、裁剪、拖动、缩放和命中计算。
- 不升级偏好或数据库版本，不重置用户配置。

## 当前结论

- 代码迁移、自动化测试、静态门禁、Debug/Release 构建与 Analyze 已通过。
- 最新 Debug 安装版已重新构建；真实 UI 控制通道本轮不可用，因此浅色、深色、
  降低透明度和减少动态效果的安装版截图/录屏仍明确标记为待补，不能据此宣布
  视觉验收完成。

本项目保留原生材质和动效实施历史。当前设计原则、Token、组件、治理和分阶段改造口径已转移到
[017_全局 UI 与交互设计系统](../017_全局UI与交互设计系统/index.md)；如有冲突，以 017 为准。
