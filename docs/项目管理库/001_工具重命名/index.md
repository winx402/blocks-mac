## 项目目标

- 中文产品名统一为“积木工具”。
- 技术名统一为 `blocks`。
- App、CLI、代码、schema、脚本、当前有效文档和验证工具统一迁移。
- Bundle ID、App Group、Keychain service 等系统身份全量换新为 `app.blocks.*` / `group.app.blocks.*`。

## 目录规则

- 当前项目暂不拆阶段，项目说明、方案、任务派发、子 agent 输出、评审和验收记录先平铺在本目录下。

- 子 agent 输出文件命名建议为 `YYYY-MM-DD-角色-主题.md`，并放在本项目目录或对应阶段目录内。
