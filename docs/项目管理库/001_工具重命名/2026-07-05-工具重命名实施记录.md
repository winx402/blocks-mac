本记录追踪旧称“奇点 / JDTool”到“积木工具 / blocks”的首轮实施。旧称仅用于说明迁移来源；当前有效命名以 `积木工具`、`积木 AI 工具箱`、`Blocks` 和 `blocks` 为准。

## 已执行范围

- App 目录从 `apps/JDTool/` 迁移到 `apps/Blocks/`。
- Xcode project、scheme、target、product、module、主 App、CLI、Login Item helper、entitlements 路径迁移为 `Blocks` / `BlocksCore` / `blocks` / `BlocksLoginItemHelper`。
- Bundle ID 迁移为 `app.blocks.*`，App Group 迁移为 `group.app.blocks.*`。
- App 显示名迁移为“积木工具”，项目正式描述迁移为“积木 AI 工具箱”。
- Action namespace、schema catalog、schema 文件名和 examples 迁移为 `blocks.*`。
- 构建脚本、验证脚本、spike 工具、当前有效技术/产品/验证文档和入口索引迁移到新路径和新命名。
- 归档区 `docs/项目管理库/000_归档/` 保留旧称，不作为当前事实源机械改写。

## 验证结果

- 旧名残留扫描通过：活跃代码、脚本、schema 和当前文档中未发现 `apps/JDTool`、`JDTool.xcodeproj`、`JDTOOL_`、`jdtool.*`、`com.jdtool`、`group.com.jdtool` 等旧技术命名残留；归档区和本项目旧称说明不纳入机械清理。
- Xcode project 清单通过：`Blocks.xcodeproj` 暴露 `Blocks`、`BlocksCore`、`blocks`、`BlocksLoginItemHelper` targets 和 `Blocks`、`BlocksCLI`、`BlocksCore`、`BlocksLoginItemHelper` schemes。
- App build 通过：`xcodebuild -project apps/Blocks/Blocks.xcodeproj -scheme Blocks -configuration Debug -derivedDataPath DerivedData/Blocks build`。
- CLI build 和 smoke 通过：`BlocksCLI` 构建成功；`DerivedData/Blocks/Build/Products/Debug/blocks list` 和 `blocks run blocks.screenshot.capture --dry-run --mode region` 返回 `blocks.screenshot.capture`。
- Schema / action smoke 通过：`python3 tools/spikes/p2_action_smoke.py validate-schemas`、`python3 tools/spikes/p2_action_smoke.py smoke`、`swift test --package-path tools/spikes/blocks_schema_validator_probe`。
- 关键验证门禁通过：`python3 tools/spikes/test_p2k_contracts.py`、`python3 tools/verification/p8n_clipboard_capture_font_settings_checks.py`、`python3 tools/verification/p7n_alpha_readiness_gate_checks.py --timeout 240`。
- 迁移适配验证通过：`python3 tools/verification/p7h_clipboard_autopaste_activation_checks.py`、`python3 tools/verification/p7q_screenshot_window_fullscreen_checks.py`。
