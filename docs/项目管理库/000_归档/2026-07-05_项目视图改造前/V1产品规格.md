# V1 产品规格

状态：proposed
最后审阅：2026-07-01
来源级别：derived specification

本规格把 V1 的三类通用工具细化为可设计、可开发、可验收的产品边界。它承接用户给出的初步构想，并参考成熟产品调研记录：[2026-07-01 成熟产品参考](../调研与验证库/2026-07-01-成熟产品参考.md)。

## V1 产品判断

V1 不追求工具数量，而追求三类工具的日常可用深度：

1. 截图：默认 `Option + A` 触发且可配置，支持窗口、全屏、拖动区域，截图后出现图片和功能组。
2. 剪贴板：默认 `Option + V` 触发且可配置，保留历史和格式，支持搜索、过期清理、固定和分组。
3. 翻译：覆盖选中文本、输入文本、剪贴板文本、截图 OCR 文本，结果与当前任务上下文结合。

AI、CLI、agent 和 hook 是横向能力，不能替代三类工具自身的成熟交互。

## 统一体验原则

- 快捷键优先：核心动作必须能在 1 次快捷键后进入可操作界面；默认快捷键必须可更换、可禁用、可恢复默认。
- 原地处理：结果面板尽量贴近当前任务，不强迫用户切换到聊天窗口。
- 低延迟：截图预览、剪贴板面板、翻译结果的首屏反馈必须足够快；具体指标在 P2 spike 中量化。
- 可回退：AI 处理前保留原始内容，处理后允许复制、撤销、重新生成或保存历史。
- 权限可解释：截图、剪贴板、文件、AI 调用都要显示为什么需要权限、处理了什么内容。
- UI 与 agent 同源：UI、CLI、hook 调用同一个 action core，不维护三套业务逻辑。

## 工具 1：截图

### 核心 Jobs

1. 快速截取屏幕局部并复制给别人。
2. 对窗口或全屏截图做标注、保存、拖拽或置顶参考。
3. 对截图里的文字继续 OCR、翻译、总结或交给 AI 处理。

### V1 必做

- 快捷键：默认 `Option + A`，可更换、可禁用、可恢复默认，并在冲突时提示。
- 截图模式：拖动区域、窗口、全屏。
- 截图选择：拖动框选、取消、重选、确认，显示尺寸。
- 截图后浮层：展示图片预览和功能组。
- 基础动作：复制、保存、另存为、拖拽到其他 App、重新截图。
- 图片动作：标注、OCR、翻译、总结入口。
- 历史记录：保存截图来源、时间、尺寸、后续 action 摘要。
- 权限异常：无屏幕录制权限时给出清晰引导。

### V1 暂缓

- 滚动截图。
- 录屏/GIF。
- 背景美化模板。
- 精细测距、取色、放大镜。
- 云分享链接。

### V1 不做

- 自动理解所有截图内容并主动推送建议。
- 无确认地把截图内容发送到云端 AI。
- 面向团队协作的云端截图库。

### 验收场景

| 场景 | 验收标准 |
| --- | --- |
| 拖动截图 | 按默认 `Option + A` 或自定义截图快捷键后可框选区域，确认后出现预览和功能组。 |
| 窗口截图 | 可选择一个窗口截图，边界不应明显错位。 |
| 全屏截图 | 可截当前屏幕，并进入同一结果浮层。 |
| 快速复制 | 截图后一次操作复制图片到剪贴板。 |
| AI 入口 | 点击翻译/总结前展示将处理的文字或图片范围，并要求确认。 |

## 工具 2：剪贴板

### 核心 Jobs

1. 找回最近复制过的文字、图片、链接或文件引用。
2. 固定常用内容并按主题分组，长期复用。
3. 对某条历史内容执行翻译、改写、总结、敏感信息识别等 AI 处理。

### V1 必做

- 快捷键：默认 `Option + V`，可更换、可禁用、可恢复默认，并在冲突时提示。
- 历史面板：按时间倒序展示，支持键盘选择和搜索。
- 格式保留：保存纯文本、富文本、图片、链接、文件路径/引用的可恢复表示。
- 保存策略：支持按时间和数量限制保存；过期内容自动清理。
- 固定：固定项不会过期。
- 分组：固定项可进入分组或 pinboard。
- 删除：单条删除、批量删除、清空历史。
- 暂停记录：用户可临时关闭剪贴板记录。
- 隐私排除：支持排除指定 App；默认不记录明确敏感来源。
- 详情视图：查看原始内容、格式类型、来源 App、复制时间。

### V1 暂缓

- 跨设备同步。
- 团队片段库。
- 复杂标签系统。
- 高级语义搜索。
- 自动识别所有密码/密钥类型。

### V1 不做

- 未经用户确认上传完整剪贴板历史。
- 默认监听并处理所有剪贴板内容。
- 替代密码管理器。

### 验收场景

| 场景 | 验收标准 |
| --- | --- |
| 弹出历史 | 按默认 `Option + V` 或自定义剪贴板快捷键后历史面板快速出现并可键盘选择。 |
| 格式保留 | 富文本或图片复制后，从历史恢复时保留可用格式。 |
| 过期清理 | 超过保存时间或数量上限的非固定项被清理。 |
| 固定分组 | 固定项不会过期，并可归入分组。 |
| 隐私排除 | 被排除 App 的复制内容不进入历史。 |
| AI 处理 | 对单条剪贴板内容执行翻译/改写时，只处理用户选中的条目。 |

## 工具 3：翻译

产品参考：翻译交互优先参考 Bob，尤其是划词翻译、截图翻译、输入翻译、多入口复用和可被外部脚本/agent 调用的能力；DeepL 和 Easydict 作为补充参考。

### 核心 Jobs

1. 翻译当前选中文本或手动输入文本。
2. 翻译剪贴板历史中的某条内容。
3. 翻译截图或图片中的 OCR 文本。

### V1 必做

- 输入入口：手动输入、选中文本、当前剪贴板、剪贴板历史条目、截图 OCR 文本。
- 快捷入口：默认翻译快捷键待定；设置页必须支持配置、禁用、恢复默认和冲突提示。
- 结果展示：原文/译文对照，显示来源、目标语言、处理状态。
- 操作：复制译文、替换当前剪贴板、保存历史、重新翻译。
- 多入口一致性：划词翻译、输入翻译、截图翻译应共享同一套结果面板和 action 能力。
- 语言：至少中英互译；语言检测作为 P2 技术验证项。
- AI 调用确认：来自截图或剪贴板的内容进入云端模型前必须展示预览。
- Provider 抽象：翻译服务通过 provider 接入，不把某个模型写死到 UI。

### V1 暂缓

- 多语言批量翻译。
- 术语库。
- 长文档翻译。
- 原图版式覆盖翻译。
- 多翻译服务并排比较。

### V1 不做

- 自动监听剪贴板并静默翻译。
- 无确认上传截图 OCR 全文。
- 以聊天窗口替代翻译工具本身。

### 验收场景

| 场景 | 验收标准 |
| --- | --- |
| 手动翻译 | 输入文本后获得译文，并能复制或保存。 |
| 剪贴板翻译 | 对当前剪贴板或历史条目翻译，不处理未选中的历史内容。 |
| 截图翻译 | 截图 OCR 后展示原文，再由用户确认翻译。 |
| 失败处理 | provider 失败时保留原文和错误信息，可切换或重试。 |
| Agent 调用 | CLI 提交翻译任务后返回结构化 JSON。 |

## AI 增强边界

V1 的 AI 能力分两层：

### 工具内 AI

- 截图：OCR 后翻译、总结、内容识别。
- 剪贴板：翻译、改写、总结、敏感信息识别。
- 翻译：翻译、润色、术语解释。

### 外部 AI/agent 接入

- CLI 模式：配置本地 CLI provider，例如 Codex、Claude Code、GitHub Copilot、Qoder CLI、opencode 等候选；具体可用能力必须在 P2 逐一核验。
- API 模式：配置 OpenAI-compatible 或其他 LLM API provider。
- 调用方式：工具 action 将输入整理为结构化 payload，provider 返回结构化结果；UI 再把结果嵌回具体功能界面。

## Hook 能力边界

Hook 是未来的自动化扩展点，V1 只定义边界，不开放无约束脚本系统。

候选 hook 点：

- 截图完成后：`after_screenshot_captured`。
- OCR 完成后：`after_ocr_completed`。
- 剪贴板内容保存前：`before_clipboard_item_saved`。
- 剪贴板条目粘贴前：`before_clipboard_item_pasted`。
- 翻译请求发出前：`before_translation_requested`。
- AI action 完成后：`after_ai_action_completed`。

V1 hook 原则：

- Hook 默认关闭。
- Hook 必须可预览、可禁用、可审计。
- 修改用户内容或阻断操作的 hook 必须有明确提示。
- Agent 可以生成 hook 草案，但生效必须经过用户确认。

## P1 退出条件

- 三类工具都有明确 V1 必做、暂缓、不做。
- 每类工具至少 3 个 Jobs 和 5 个验收场景。
- AI、CLI、hook 的边界写清楚，但不提前承诺所有 provider 可用。
- P2 可以基于本规格开展 action schema、权限和技术 spike。
