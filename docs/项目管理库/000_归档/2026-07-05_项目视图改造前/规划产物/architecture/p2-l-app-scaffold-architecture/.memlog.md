- (constraint) [ADOPTED] 用户要求 P2-L 采用 BMAD fast path，产出 architecture spine / ADR，并同步项目技术知识库与看板。
- (constraint) [ADOPTED] P2-G 已确认正式 App sandbox-first；Direct Download 和 App Store 双出口暂不锁死。
- (constraint) [ADOPTED] P2-K 已完成第一轮技术验证，但多屏、权限撤销、第三方复杂剪贴板样本、长期 helper 功耗和真实 provider 调用仍未覆盖。
- (decision) 正式工程形态暂定为 SwiftUI + AppKit + sandbox-first + SMAppService helper + shared action core；该决定绑定 P3 前 scaffold 的初始进程边界。
- (decision) 主 App 拥有 UI、权限引导、设置、确认卡片、Keychain 配置、审计展示和用户可见状态，不把长期后台采集塞进主进程。
- (decision) Login Item/helper 优先承载剪贴板 recorder、后台心跳和轻量事件采集；默认不执行外部 CLI provider、hook 脚本或任意自动化。
- (decision) CLI 使用 jdtool 前缀和统一 JSON envelope；CLI、UI、agent 后续共享 action core，敏感路径通过 requires_confirmation 返回或由主 App 确认。
- (decision) Provider 和 hook 均不得绕过用户确认；external_transfer 和 destructive_or_hook 继续是 P3 前必须保留的安全边界。
- (decision) JSON Schema 文件继续作为接口事实源；第一方 action 用 Swift typed validation，外部输入和 hook manifest 预留完整 validator adapter。
- (assumption) P2-L 只改文档和决策记录，不创建正式 Xcode/App 工程；正式 scaffold 或 P3-A 另起计划。
- (event) P2-L architecture spine started from P2-K verified evidence and user-approved implementation plan.
- (event) P2-L architecture spine finalized and synchronized to decision record, technical knowledge base, project board and indexes.
