- (constraint) 用户要求本轮按 BMAD Architecture → Story → Dev Story → Code Review → Acceptance 执行，目标是架构收敛而非新增产品功能。
- (constraint) 当前产品文档 docs/产品知识库/工具/文本/剪贴板历史-当前产品与实现逻辑.md 是 P8-M 不回归基线。
- (decision) 剪贴板采用 local-first modular controller paradigm：AppState 只保留跨模块兼容转发和 app-level 协调，剪贴板查询、preview、ingest、source options 由 ClipboardController 承接。
- (decision) SwiftUI panel view 是 composition root：可以装配 header、filter、tray、card、row、detail tracking，但不得重新定义 AppKit coordinator、filter domain、card/detail component 或 UserDefaults key。
- (decision) NSPanel presenter 只拥有 panel lifecycle、frame/resize、focus、target app capture 和 dismiss island；自动粘贴错误类型和 Command+V 执行由 ClipboardAutoPasteCoordinator 独立承担。
- (decision) 详情浮层只能有一套实现：单 child NSPanel + panel-level mouse tracking + screen bridge；禁止回退到父 panel 内部 SwiftUI overlay 裁剪路径。
- (decision) 筛选、Pinboard、Preview、Localization 分文件，文件名必须表达职责；ClipboardRecorder+Localization 只保留 item kind 本地化展示。
- (decision) 剪贴板 UserDefaults key/default/clamp 集中到 typed settings 支持层；本轮不改已有 key，不引入 key migration。
- (decision) 实时复制新增、内容直显、图片缩略图、单/双击粘贴、条目宽度、bottom 高度 resize、filter click island、Pinboard 操作和自动粘贴均属于无回归合同。
- (assumption) 本轮只做模块化和同模块内 bug/优化修复；生产持久化、完整隐私策略、Pinboard 编辑、Paste Stack 和富文本编辑另起 story。
- (decision) 静态门禁必须跟随模块边界更新：允许符号迁移到新文件，禁止重新出现多套 hover/filter/resize/auto-paste 逻辑。
- (event) P8-M architecture spine started from user-approved refactor plan and implementation-informed product baseline.
- (event) Code review found local-only hover detail exit risk; fixed by adding active detail mouse-location polling and P8-M guardrail detail_exit_tracking_not_local_only.
