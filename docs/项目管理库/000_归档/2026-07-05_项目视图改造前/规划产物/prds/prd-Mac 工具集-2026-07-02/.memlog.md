- (decision) V1 PRD 范围固定为截图、剪贴板和翻译三类通用工具；文件图片批处理、录屏、启动器、团队协作云功能不进入 V1。
- (decision) AI 不做独立聊天入口；OCR、翻译、总结、改写、敏感识别必须嵌入具体工具流程和结果面板。
- (decision) PRD 继承 sandbox-first、jdtool action schema、P2-L scaffold 架构和三级 confirmation 边界；不重新决定技术实现。
- (decision) PRD 面向后续 UX Spec、Architecture、Epics/Stories；需求用 UJ、FR、SM 和 Glossary 保持可追踪。
- (assumption) 目标用户暂按 Mac 高频内容处理用户、agent power user、开发者/知识工作者描述；具体付费人群仍未锁死。
- (assumption) V1 成功指标以本地可验收质量和日常可用为主，不设置收入或增长指标。
- (assumption) 翻译默认快捷键仍待产品确认；PRD 只要求可配置、可禁用、可恢复默认和冲突提示。
