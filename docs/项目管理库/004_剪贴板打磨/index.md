## 项目目标

- 把剪贴板从“保护优先、元数据优先”的当前体验，调整为“明文优先、可搜索、可编辑”的日常工具体验。
- 明确搜索、设置、CLI、provider、日志、自动化等链路取消默认 payload 保护后的可控行为边界。
- 将现有“分组/固定”能力升级为可扩展的“标签/收藏”模型。
- 修复面板搜索、筛选展开、条目点击反馈、空间利用和详情信息组织等高频路径问题。
- 为后续 PRD、设计评审、架构拆解、开发和验收提供稳定输入。
