| 路径 | 需要确认的问题 | 建议证据口径 |

| 搜索 + 标签 + 编辑后索引 | 编辑 plain text / URL / rich text / OCR text 后，新内容能被搜索命中；旧内容不误命中；标签筛选和搜索组合不丢结果 | 低敏 repository fixture，覆盖 Step 1 / Step 2 / Step 4 的 search document rebuild 和索引事务 |
| 真实内容可访问 + 输出可控 | 面板 / 详情可使用真实内容语义，CLI / audit / 日志仍 bounded、低敏、结构化，不输出完整真实 payload | P13A / P11E / P13E 组合检查，sanitizer 明确不输出真实 payload、完整 URL、完整路径或 secret |
