App 架构师已产出 `step_4/App架构师-技术方案-v0.md`。项目负责人预审认为：技术方案 v0 覆盖 PRD v1 的核心边界和必答问题，未扩大到 Step 5 / Step 6，可以进入角色复审。

## 范围判断

方案保持在 Step 4 范围内：

- Bounded detail read model。
- Metadata snapshot。
- Detail edit read / full value read / save purpose。
- 单一 Store / Repository save command。
- Plain text、URL、rich text、image OCR text 编辑方案。
- 保存事务、异步 reindex 例外和失败状态。
- Fake pasteboard / adapter spy / static scan 的系统剪贴板不写入证据。
- Rich text fidelity gate 和降级接受记录。
- OCR user-edited / retry / late completion 冲突处理。
- P13D fail-closed verifier。
- 开发拆分建议和风险取舍点。

方案未提前进入：

## PRD v1 必答问题覆盖

已覆盖：

1. 富文本 payload 当前格式与最低保真范围。
2. 富文本无法保真时的降级 / 暂缓 / 只读路径和项目负责人接受记录。
3. 单一 Store / Repository detail edit save command。
4. payload、summary、search document、FTS、updatedAt、detail read model 的默认同事务方案。
5. `saved-index-pending` / `reindex-failed` 作为异步 reindex 例外路径。
6. 系统 pasteboard 不写入证据组合。
7. URL absolute URL / scheme / custom scheme / file URL 边界。
8. OCR user-edited 持久化标记和 retry / late completion 防覆盖。
9. Bounded detail read model 和 metadata snapshot 字段。
10. detail edit purpose 与 hover / paste / copy / translation 隔离。
11. record missing、payload missing、revision conflict 的用户可见状态。
12. P13D 脚本、输入、断言、输出 schema 和回归矩阵。

## 进入复审前不要求 App 架构师立即返工

当前没有阻塞角色复审的预审 P0/P1。以下问题应交由角色复审进一步判断：

- Stable detail editor 的具体承载形态是否满足 UI 体验。
- Rich text RTF round-trip 的最低保真策略是否足够可实现。
- OCR user-edited schema migration 是否最小且可维护。
- P13D static scan / fixture smoke 的 fail-closed 边界是否充分。
- Pasteboard 不写入证据是否覆盖间接写入路径。
- Low-sensitive 输出是否能防 URL 全文、OCR 原文、真实路径和图片/base64。

## 角色复审要求

角色复审不只提出问题，也应给出可吸收建议和推荐口径。结论使用：

- `approve`
- `approve-with-changes`
- `rework-required`

如有 P0/P1，必须说明阻塞原因和建议改法；如只是开发阶段或 verifier 细化项，应明确标为非阻塞。

## 建议复审角色

- UI/交互设计师：复审 stable detail editor、固定 action bar、dirty-navigation、metadata layout、VoiceOver / keyboard 输入。
- 开发：复审方案可落地性、批次拆分、repository save command、schema migration、P13D baseline。
- 测试/质量：复审 P13D、fixture、事务失败、pasteboard spy、低敏 evidence。
- 代码审查：复审 View / Store / Repository 边界、AppState 不扩权、purpose 隔离、schema migration 风险。
- 安全合规顾问：复审真实剪贴板不触发、pasteboard 不写入证据、低敏输出、purpose 边界和用户内容处理。
