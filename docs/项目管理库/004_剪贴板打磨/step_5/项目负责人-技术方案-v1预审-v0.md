- `privacy_app_search_fields_004`
- `privacy_app_filter_combination_004`

- `privacy_app_row_a11y_004`

- `layout`

v1 已在 fail-closed 条件中写明缺 `ui_interaction` 子字段或 required scenario 时 P13E 失败。

### 3.2 P1-2：capture bridge 一等验证对象

v1 已将以下 capture bridge 场景写入 P13E required scenarios：

- `privacy_capture_bundle_restricted_004`
- `privacy_capture_bundle_allowed_004`
- `privacy_capture_app_path_precedence_004`
- `privacy_capture_default_allow_004`
- `privacy_capture_missing_path_fallback_004`
- `privacy_capture_snapshot_low_sensitive_004`

v1 已补齐 `capture_bridge` evidence schema，并明确每个 capture scenario 必须包含：

- `decision`
- `matched_rule_type`
- `mutation_performed=false`
- `payload_read=false`

v1 已在 fail-closed 条件中写明：

- `PrivacyPolicySnapshot` 必须包含 bundle id 与 app path 的 allowed / restricted 集合。
- `ClipboardCapturePolicy` 必须消费 `PrivacyPolicySnapshot`，不得仍只消费旧 `excludedBundleIdentifiers`。
- capture bridge scenario 缺关键字段时 P13E 失败。
