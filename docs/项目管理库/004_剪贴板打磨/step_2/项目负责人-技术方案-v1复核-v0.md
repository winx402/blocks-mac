## 3. 复核结果

### 3.1 已吸收必须项

技术方案 v1 已把以下进入开发前必须固定的点写成硬契约：

- `clipboard_tags` / `clipboard_record_tags` 或等价 `Tag / RecordTag` 模型是独立当前事实源。
- favorite 是唯一 built-in tag，收藏关系来自 RecordTag，不来自旧 pinned 字段。
- AppDatabase V2 migration、favorite seed 幂等、旧 pinned / pinboard 不迁移。
- tag name normalizer 固定为 NFKC、trim、Unicode whitespace fold、control rejection、locale-independent case folding，并包含 `favorite` / `收藏` reserved aliases。
- 推荐 `ClipboardTagRepository` + `ClipboardTagStore`，并明确 `ClipboardStore`、`AppModel`、View 的边界。
- mutation result 覆盖 changed tag IDs、affected record IDs、removed tag IDs、selected tag transition 和 search invalidation。
- delete / merge 原子事务、失败不半更新、active selected tag 迁移规则明确。
- `preservePinned` / `clearUnpinned` 在 Step 2 内退出或替换为 favorite 语义，不后置。
- Settings row、右键菜单、favorite immutable、删除/合并文案、长标签/窄宽度/VoiceOver/键盘路径具备最小 UI 合同。
- P13B fail-closed verifier、legacy scan 分层、旧 P8/P9/P11 迁移和 Search Gate 三态输出已定义。
- repository smoke、UI fixture、错误反馈和低敏输出证据矩阵已定义。
- 开发拆分已按用户补充收敛为较大批次，不再机械拆成过细 2A/2B/2C/2D。
