## 3. 技术方案必须覆盖

- SwiftUI hover 安全桥 / hit-test 区域 / 短延迟收起 / 再进入取消收起 / 明显离开收起。
- toolbar 空间优先级：右侧关键操作、搜索框最小宽度、筛选组最大宽度、宽 / 常规 / 窄 / 最小可用窗口矩阵。
- selected / focused 状态先写，paste / detail / OCR retry / async completion 后做；提供低敏事件证据口径。
- 面板顶部 active 单击 / 双击 `Menu` 退出，改为显性互斥控件；如设置页也提供，同 key `clipboard.panel.pasteActivationMode`。
- side list row 与 bottom tray card 分别做密度和尺寸稳定方案。
- hover / selected / focused / OCR / indexing / excluded / skipped 状态不导致 row/card 尺寸跳动。
- 低敏 fixture、截图/录屏、键盘、VoiceOver 验收证据如何落地。
- Step 3 专属门禁 P13C 或等价 verifier 的断言、输入、输出和 fail-closed 规则。
- Step 1 P13A、Step 2 P13B、P8/P8I/P9A/P9B/P11E 的回归关系，避免 Step 3 改坏已接受事实源。
