## 3. 复核结果

### 3.1 已吸收必须项

技术方案 v1 已把进入开发前必须固定的点写成可执行契约：

- viewport evidence 按 bottom / side `position` 分开，并记录真实宽高 bucket；不要求伪造当前面板无法达到的 360-459pt 证据。
- hover 使用安全桥、短延迟、re-enter cancel、明显离开和立即关闭条件，并明确默认 180ms / 12pt / 16pt 与可调范围。
- hover bridge 优先 SwiftUI overlay / geometry，必要时才用窄 `NSViewRepresentable`；不得引入全局事件 monitor，必须 hit-test transparent。
- toolbar / filter / paste activation fallback 明确保留 all / favorite / active clear / settings / close / paste activation 的可达路径。
- 面板顶部 paste activation 不再使用 `Menu` / 下拉；fallback 只能是 radio group 或互斥按钮组，并与 Settings 如有同项时共用 `clipboard.panel.pasteActivationMode`。
- row/card 主激活必须进入局部 activation handler，不再直接把 tap gesture 接到 paste。
- selected / focused / event record 必须早于 paste、detail、OCR retry、copy 等动作。
- focused、hover、interaction token 均限定为 view-local 或局部 view model-local 状态，不进入 `AppState`、repository、database 或持久化事实源。
- rapid A -> B stale completion 必须有 interaction token / latest guard。
- side list row 与 bottom tray card 使用各自 metrics，状态变化不得改变外部尺寸，点击目标不得低于当前基线。
- P13C evidence manifest 采用 fail-closed 规则，逐条记录 viewport、artifact、interaction event、keyboard checklist、VoiceOver checklist 和 sanitizer 结果。
- selected/focused 事件日志覆盖单击粘贴、双击粘贴、detail open、OCR retry、rapid stale completion 五类场景。
- keyboard / VoiceOver checklist 字段、必填项和 pass/fail 规则已固定。
- 回归矩阵覆盖 P13C、P13A、P13B、P8、P8I、P9A、P9B、P11E、Blocks build、BlocksCLI build、CLI help 和 `git diff --check`。
