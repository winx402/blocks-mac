# 013 核心交互架构与体验收口

状态：automation-verified-real-ui-partial
最后审阅：2026-07-24
来源级别：project control

## 目标

- 在不改变用户数据和已确认产品语义的前提下，收敛剪贴板、截图编辑器和设置页面的状态所有权与运行链路。
- 消除剪贴板主线程同步查询、截图编辑器整树无差别刷新、设置导航错误可选项等已确认问题。
- 通过隔离数据、自动化和安装版真实操作共同验证功能、UI、交互、性能和无障碍。

## 实施边界

- 剪贴板只保留一套查询、复制提交和自动粘贴事务。
- 截图编辑器继续由 `ScreenshotEditorStore` 对 Presenter 提供稳定门面，内部状态、手势、渲染、OCR 和输出按职责拆分。
- 设置页继续使用原生 `NavigationSplitView`、系统 Sidebar 和全局表面角色。
- 不升级数据库或截图偏好版本，不重置剪贴板历史、标签、工具、水印、快捷键和主题。
- 本项目不自动推进 005、006、011、012 的既有阶段状态。

## 阻断标准

- P0/P1 功能、焦点、生命周期、数据一致性或明显 UI 问题未关闭。
- 剪贴板查询仍在主线程同步访问数据库，或过期结果可以覆盖当前列表。
- 截图存在双渲染链路、过期 revision 提交或命令按钮暴露工具选中语义。
- 设置侧栏仍包含非路由可选行，或中英日/浅深色/辅助功能下出现明显布局漂移。

## 当前结论

- 剪贴板读取、面板会话、记录动作和 OCR 调度已提取为独立所有者，面板筛选和搜索只接受最新 generation。
- 截图编辑器已经建立分片状态、单 revision 渲染管线和不可变 Canvas 快照；输入控制与 OCR 浮层从巨型 View/Canvas 中拆出。
- 设置 Sidebar 的品牌说明不再进入可选择列表；清理策略改为标准分段控件，尾列和滚动行为继续使用共享规范。
- 自动化、Debug/Release 构建和 Xcode Analyze 已通过。安装版已取得设置页与截图编辑器结构证据；锁屏后无法继续完成更多工具、连续剪贴板和完整辅助功能鼠标矩阵，因此这些项目仍标记为待验证。
