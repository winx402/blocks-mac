## 验收中发现并修复的真实缺陷

9. **真实剪贴板后置事件没有业务内容**：生产 `clipboard.did_persist_capture` 过去只有记录 ID 与去重状态，导致智能贴签、内容雷达和颜色收藏册在真实入口拿不到正文。现由保存后的真实记录构造 v2 内容输入，并在异步 Hook 生命周期内维持资源 lease。
10. **插件中心仍暴露开发者内部概念**：旧详情直接展示 Hook、权限 ID、Schema、哈希和原始日志。现 UI 只渲染 Manifest v6 的用户展示模型，技术细节统一由 CLI 查询。
11. **通用插件 CLI 缺少 AI 开发闭环**：旧入口只能管理已安装插件。现独立开发服务补齐 JSON 信封、固定退出码、fixture 隔离测试、打包、安装计划/哈希确认、调用、日志与内置目录命令。
12. **合法配置默认值被校验器误拒绝**：颜色、文件、标签、数字滑杆和多选默认值过去只按少数类型验证。现按字段类型检查字符串、数值和数组，Manifest v6 契约测试覆盖该问题。
13. **插件自带页面仍显示英文**：插件中心名称和用途已本地化，但 UI 组件树仍只读取默认标题与静态值。现 UI 组件支持 Manifest 通用本地化描述，运行时或本地状态补丁仍具有更高优先级。
14. **调试日志无法证明宿主动作闭环**：Hook 日志过去记录 mutations，却遗漏 actions、UI patches 和 diagnostics。现调试模式记录安全结构投影、计数与已批准动作 ID／诊断级别，不持久化插件业务正文、字段名或输入；关闭调试时仍只保留最小元数据。网络审计继续按专用 byte count + SHA-256 契约记录。

1. **通用插件无法启用**：旧翻译/OCR 连接验证被错用到 Hook/Action/UI 插件。现在只有声明翻译/OCR 能力的插件需要连接验证。
2. **通用 CLI 复用翻译源动作**：`blocks plugin` 现在使用独立 `blocks.plugin.manage`，不再经由翻译源命名的 Broker 动作。
3. **首次存储读取使 Hook 失败**：Host Bridge 没有允许合法的顶层 JSON 标量，导致未初始化的 `null` 无法返回 JavaScript。现已允许 JSON fragment，并用真实 XPC 回归闭合。
4. **Clipboard Broker 测试子进程在 sandbox 初始化退出**：根因是 Xcode 测试签名注入了超出子进程契约的 entitlement，现在嵌入后按源 entitlement 规范化签名。
5. **CLI scaffold 可选参数合同不一致**：帮助标记参数可选，解析器却要求三项全部提供。现在每项独立可选，通用插件与翻译源使用各自的缺省模板。
6. **详情返回污染插件目录滚动状态**：插件中心曾嵌套在设置页公共 ScrollView 中，详情页滚动会让返回后的目录停留在错误位置。插件中心现独立拥有滚动容器，并以进入详情的插件作为返回锚点。
7. **架构门禁在 AppTests 中挂起**：测试宿主启用了 App Sandbox，却直接从工作区读取源码，`Data(contentsOf:)` 被系统阻塞。运行时测试现只读取 App Bundle 并验证通用能力注册表；源码引用检查迁移到独立 Shell 静态门禁。
8. **翻译源 CLI 门禁仍断言旧 scaffold 行为**：实现已允许 `--id`、`--name`、`--output` 分别可选，脚本仍期待不完整参数报错。现改为仅指定输出目录生成临时包，并以同一 CLI 重新校验生成结果。

## 已知实机边界与残余风险

- 最新安装版已验证 XPC Hook、存储、共享状态、调试 UI、插件目录与智能贴签真实事件/宿主动作/持久化闭环；低敏验收记录仍保留在剪贴板历史中，未绕过产品接口直接删除用户数据库记录。
- 8 个官方插件均已通过严格包校验和统一 Runner 代表性测试；智能贴签已完成真实剪贴板入口闭环，其余 7 个插件尚未全部逐一通过安装版 UI 手工触发每个业务分支，不得写成全量实机通过。
- `screenshot.color_sample.begin` 当前使用系统 `NSColorSampler` 完成跨屏取色、Esc 取消和 sRGB/坐标返回；自动化覆盖能力合同，未在本轮逐一手工覆盖混合 DPI、透明像素与所有屏幕边缘。
- 定时任务的执行/取消有自动化覆盖，但尚未进行跨睡眠/唤醒的长时间安装版实验。
- 日志脱敏、保留时间和容量裁剪已自动验证；未用 100MB 真实日志压满用户目录。
- 插件中心已有安装版视觉证据；VoiceOver 的全量逐控件人工朗读未在本轮全覆盖。
- Xcode 仍提示本机 CoreSimulator 版本比 Xcode 预期旧，以及无 AppIntents 依赖时跳过元数据提取；两者都不是 macOS 产物的编译失败。
