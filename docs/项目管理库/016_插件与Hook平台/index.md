# 016 插件与 Hook 平台

状态：插件中心用户化、AI 开发 CLI 与智能贴签真实闭环已验证；未逐项取得的官方插件实机证据继续保留待验证
最后审阅：2026-08-01
来源级别：用户确认计划

## 目标

- 将旧 Hook 草案、翻译/OCR `.blocksplugin` 和 Action 能力统一为一个插件平台。
- 通过隔离 JavaScriptCore/XPC 运行插件；宿主只开放版本化事件、动作、资源、存储和声明式 UI。
- 覆盖剪贴板、截图、翻译、Provider、快捷键/自动化和 App 生命周期。
- 保持 Manifest v1-v5 插件、现有配置、Keychain Secret 和启用顺序兼容。

## 实施顺序

1. 固化 Manifest v6、Host API v2、事件、决策、动作、资源与 UI 契约。
2. 数据库 v16 和内置插件安装来源元数据迁移。
3. 通用 Hook 路由、XPC 运行时、动作/资源/存储桥与调试审计。
4. 各功能模块接入首批语义事件和宿主动作。
5. 将 Hook 设置页升级为统一插件中心。
6. 示例插件、自动化、安装版和安全验收。

## 已确认边界

- `will.*` 串行、可修改或阻止；`did.* / failed.*` 异步且不能倒改事务。
- 默认 fail-open；可声明 fail-closed，安装时单独确认。
- 不开放 Shell、原生动态库、数据库直连、任意 UI 或 WebView。
- 大内容通过只读分块资源句柄传输，不做业务截断。
- 插件 UI 只能使用宿主组件和预定义模块插槽。
- 调试默认关闭；开启后记录完整调用链，但 Secret、认证信息和系统凭据始终脱敏。

## 当前实现

- Manifest v6、Host API v2、v1-v5 兼容解码和精确重新授权摘要；v6 增加面向用户的名称、摘要、场景、示例、数据说明及配置字段本地化元数据。
- 数据库 v16：通用插件元数据、安装来源、内置目录版本、Hook 顺序、私有/共享状态、定时任务与审计。
- 唯一 XPC/JavaScriptCore 生命周期，覆盖 Hook、动作、UI 动作和定时任务。
- 串行前置 Hook、异步后置 Hook、fail-open/fail-closed、超时与因果链重入保护。
- 版本化宿主动作注册表、插件导出动作和插件间显式导入动作；异步宿主动作通过 operation ID 定向回传完成或失败事件。
- KV、文档、FIFO 队列、CAS 及共享 namespace 变更事件。
- 只读可取消资源流；业务内容不截断，分块仅是传输机制。
- 宿主 UI schema、状态 Patch 和剪贴板/截图/翻译/Provider/设置插槽。
- 插件中心改为“可搜索/筛选列表 → 独立详情长页”；UI 只展示能做什么、何时工作、输入输出示例、当前规则、最近运行状态及自然语言数据说明。Hook ID、Manifest、Schema、哈希和原始日志仅由 CLI 提供。
- 8 个官方插件以独立 `.blocksplugin` 资源包随 App 分发，按需安装且默认关闭：智能贴签、粘贴净化、链接整理、内容雷达、截图 OCR 助手、术语守卫、单词卡和颜色收藏册。
- 通用截图取色能力 `screenshot.color_sample.begin` 由 Host API v2 提供；宿主业务代码不引用任何内置插件 ID。
- 内置包同权限更新可自动替换；权限或域名扩大时保留已安装版本，等待用户重新审查。
- 每插件持久调试开关、强制脱敏日志、7 天/100MB 滚动策略及安全模式。
- 独立 `PluginDevelopmentService` 与稳定 JSON 信封 CLI，覆盖 `init → api → validate → doctor → test → pack → install plan/apply → invoke → logs → disable/remove → catalog` 完整开发闭环；所有命令不执行任意 Shell，也不直连用户数据库。
- `clipboard.did_persist_capture` v2 发送真实保存后的记录身份、内容元数据及允许的正文/资源引用；v1 插件继续获得旧投影。智能贴签、内容雷达和颜色收藏册不再依赖测试专用理想 payload。

本轮自动化已取得 8 个官方插件 Manifest v6 严格校验、真实剪贴板事件契约到智能贴签 Runner 的闭环，以及 CLI 隔离目录完整开发流程证据。最新安装版进一步验证了智能贴签从真实复制、XPC Hook、通用宿主动作到标签持久化的完整链路；其余逐插件业务触发、长时间定时任务、VoiceOver 全量朗读等没有取得的证据仍列在验收记录中，不由编译或单测替代。
