# 011 Blocks 端到端体验收口

状态：implementation-validation
最后审阅：2026-07-21
来源级别：project index

## 目标

- 全屏截图进入编辑器后，截图内容之外只显示跟随主题的中性背景，不再把棋盘格误当成窗口底色。
- 窗口截图只命中实际可见的普通窗口、Sheet、Popover 和 App 浮动面板；完全被遮挡的窗口不可选，部分可见窗口只从露出区域响应，但输出仍是完整精确窗口。
- 用低敏隔离数据复核剪贴板、截图和设置的边界状态，修复能够确定、能够独立验证且不改变产品语义的问题。

## 边界

- 不修改截图文档格式、输出像素语义或用户偏好版本。
- 菜单、Tooltip、系统覆盖层和 Blocks 选区层既不可选择，也不遮断后方正常窗口。
- 不读取或提交用户真实剪贴板正文、截图内容、水印或文件路径。
- 本项目不推进 005、006 的既有项目阶段。
