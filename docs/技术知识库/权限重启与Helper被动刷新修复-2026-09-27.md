# 权限重启与 Helper 被动刷新修复

## 修复

1. 权限刷新重启不再通过打开同一App的非空返回值认定新进程启动成功。独立启动器先正向检查父PID存活，并通过管道发出READY；主App验证独立子PID后进入原有退出流程。启动器只在旧PID消失后打开原bundle，有界等待约15秒。2秒内未握手或启动失败时保留旧App；重复请求共享同一结果且只退出一次。结果命名改为scheduled，明确不是“新App已经启动”。
2. Helper授权引导结束、权限页onAppear和翻译设置页task均采用`refresh(allowLaunch: false)`。明确启动/重新检测和App启动恢复入口保留，不把页面出现等同于启动意图。
