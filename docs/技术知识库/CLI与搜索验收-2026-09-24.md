- #61：精确 FTS token 改为前缀查询；过滤后的 FTS 零结果才使用多词 AND 子串兜底。LIKE 的百分号、下划线和反斜杠被转义；保留过滤、排序与限量。LIKE 可能扫描 search_text，不能把结果限量说成扫描成本有硬上限。

3. 使用三个唯一内容的自建记录（含一张合成 PNG）完成导入；没有重复合并，没有创建用户分组或标签。
4. 图片自定义标题可搜索（#44），中文前缀/中缀、英文大小写前缀、完整 token 和中词共 12 组查询均限定到自建记录并正确命中；面板中缀搜索也显示该合成图片。
