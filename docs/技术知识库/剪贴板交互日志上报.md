# 剪贴板交互现场信息

发生筛选菜单无响应、收藏按钮闪烁或外部关闭闪烁后，请先不要重启 Blocks：

1. 立即在设置的“数据与审计”页面选择“诊断导出”。
2. 检查生成的 JSON，再随 Issue 附上；同时说明大致时间、操作步骤、是否固定面板及是否多屏。
3. 此日志增强从已发布的 [beta.7](https://github.com/winx402/blocks-mac/releases/tag/v0.1.0-beta.7) 开始提供，beta.6 不包含。

`clipboardInteractionTrace` 是本次运行最近 256 条交互事件，超过上限淘汰最旧项，`dropped` 显示被淘汰数量。只在内存保留，重启丢失；无自动上传。导出已有应用版本、系统版本与权限摘要。

- `session`：每次打开请求生成的随机关联标识；`sequence` 与 `uptime` 用于确定先后和间隔。
- `filterPointer` / `filterSelection`：收到控件区域点击与选择回调。只有前者不证明菜单打开；缺少后者可能是取消或未处理，不自动判为故障。键盘/辅助功能选择也可能没有指针事件。
- `probeAttached` / `probeDetached`：诊断观察器生命周期。
- `rowHover` / `favoriteHover` / `favoriteAction` / `rowDisappeared`：悬停状态、收藏动作发起前状态及条目消失。control 是临时随机视图标识，不是记录 ID；重新创建视图可能改变。
- `externalDismiss` / `closeRequested` / `closeStarted` / `orderedOut` / `closeCompleted`：关闭链路；另记录固定/关闭中拒绝及陈旧完成回调。窗口的 key/visible/alpha、固定状态、待关闭状态和屏幕数量有助于判断阶段。

不收集剪贴板内容、搜索词、标签名、来源应用、窗口标题、文件路径或真实记录 ID。统一日志分类为 `clipboard-interaction`，悬停为 debug，其余为 info；系统不保证长期保留这些级别，因此现场排查优先使用内存快照的诊断导出。此导出不改变异常反馈开关，也不会自动向 GitHub 附加内容。
