# 控件语义与交互

## 控件选择

- 持久化的二态设置统一使用系统 Switch，例如功能启停、默认行为、服务启用和插件布尔配置。
- 禁止使用单选、分段、菜单或文字按钮表达 `Bool`。
- 一次性确认（例如“我已阅读风险”“确认外发”）使用 checkbox；它不是持久设置。
- 多项可同时选择使用 checkbox；少量互斥模式使用分段控件；较多互斥选项使用菜单；必须同时比较的三项及以上可使用单选组。
- 设置业务页面不得直接创建原始 `Toggle`。Switch 使用 `SettingsBooleanSwitch`／`SettingsToggleRow`，checkbox 使用共享确认或多选组件。

## 命中与状态

- 设置行最低 44pt；紧凑控件的可见尺寸可以更小，但命中区必须满足全局密度契约。
- Switch 仅由实际控件命中；导航行和动作行可整行点击。不得混用相同视觉却不同命中规则。
- 设置页的普通表单行、说明行、Slider 行、状态行、导航行、危险行和预览行必须使用共享行类型，禁止页面再定义私有尾列或私有行壳。
- 表单的加载、校验、保存和失败反馈使用预留几何的共享状态槽；不得在状态变化时推动相邻控件。
- Sheet 使用“固定标题／说明 → 可滚动内容 → 固定底部操作”壳层；校验消息不得改变 Sheet 的外部尺寸。
- 所有控件必须定义 idle、hover、pressed、focused、selected、disabled、loading、success、warning 和 error 中适用的状态。
- 动态按钮只能改变自身状态或占用预留槽位，不得推动稳定按钮。
- 紧凑工具栏需要即时说明时，使用共享非激活 Tooltip；提示不得参与原布局、获取焦点或被滚动容器裁剪，点击、窗口失焦和宿主消失时必须统一清理。

## 键盘与无障碍

- 所有主要操作必须可由键盘到达并具有清晰焦点反馈。
- 图标按钮必须提供准确的 accessibility label；状态不能只靠颜色表达。
- VoiceOver 的名称描述“做什么”，值描述“当前是什么”，提示只补充不明显的后果。
- 禁用控件仍需可理解；关联说明必须明确原因和下一步，而不是只降低透明度。
