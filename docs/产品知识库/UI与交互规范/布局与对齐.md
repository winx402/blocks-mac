# 布局与对齐

## 通用原则

- 页面只建立一套内容边界。标题、分区、正文、列表和反馈不能各自发明水平起点。
- 稳定操作行在加载、成功、失败或动态按钮变化时不得被反馈替换、伸缩或跳行。设置分组的反馈追加在操作行之后，仅在有反馈时显示，不为无反馈状态保留空白卡片；反馈出现时允许下方分组顺延，但不得重建操作控件或丢失焦点。
- 视觉对齐以可见内容边界为准，不以控件透明命中区、系统内缩或外层容器边界冒充对齐。
- 尺寸使用全局 Token；禁止为了单页观感写任意固定宽度、圆角或 Spacer 补丁。
- 应用 Chrome、设置、浮层和控件统一使用 macOS 系统字体与系统字重，让字体随界面语言、辅助功能和系统排版规则自然适配；不得在 App 根视图强制指定单一语言字体。截图标注等用户内容可以按文档样式使用明确字体，但不得反向影响应用界面。

## 设置页

- 设置窗口统一使用“后退／前进 → 当前页标题”的原生工具栏；正文不重复放返回按钮。仅通用、截图、剪贴板、翻译四个一级页保留“图标、标题、一句说明”概览，其余页面直接展示分区或内容列表。
- 窗口级历史包含一级分类与真实子页面；前进／后退恢复该路由的滚动与草稿。模态编辑器、保存、删除及安装操作不纳入页面历史。
- 页面宽度按职责选择：普通表单使用 `form` 760pt 上限，内容浏览器使用 `content` 1120pt 上限，Sheet 表单使用 `sheet` 640pt 上限。不得因为宽窗口将标签和值无限拉开。
- 字体层级：概览标题 `title2 semibold`，分区标题 `subheadline semibold primary`，设置项标题 `body primary`，主要说明 `callout secondary`；代码和次要标识保持各自语义字体。
- 页面分区间距18pt，分区标题与内容间距8pt，分组水平内缩16pt，设置行最低40pt。分组圆角10pt；只对设置场景使用不透明系统画布和比画布略亮的分组背景，浮窗材质不变。
- 分区标题与该分区首个设置行标题共用左基线，允许误差不超过 1pt。
- 分区标题操作、Switch、Picker、输入框、数值和按钮的可见尾端共用右边缘，允许误差不超过 1pt。
- “右对齐”是控件容器尾端对齐；不修改系统控件内部文字的原生排版。
- 标准设置值与设置行的完整内容区域垂直居中，视觉中心误差不超过 1pt；禁止标题首行 Alignment Guide、`.top + 1pt` 等经验补偿。说明文字可以向下增长，但不得改变尾列的统一右边缘。
- 820pt 最小窗口仍保持横向设置行；长标题或说明可换行，但值控件继续锚定统一尾列。
- 分区标题与内容必须使用同一个 `SettingsLayout.sectionContentHorizontalInset`；设置行尾部内容必须由 `SettingsValueColumn` 承担。
- 设置页面不得直接使用 `Spacer()`、私有 frame 或包装器修补尾列。
- Source List 使用无标题的10pt留白分组，行高30pt、图标20pt、符号12pt，不叠加原生分组标题间距；设置侧栏只允许纵向滚动，横向滚动条、横向弹性和横向偏移必须关闭。侧栏材质覆盖标题栏，仅背景忽略安全区域。
- 设置主内容、二级页和 Sheet 保留纵向滚动能力；设置页使用系统自动滚动指示与顶部滚动边缘效果，滚动内容不能侵入工具栏控件。

## 结构表面与内容绘制

- 设置分区使用低对比度系统分组底色；常态无描边、无阴影、无重复毛玻璃，仅在“提高对比度”时增加语义边界。
- 结构性背景、材质、描边、阴影和圆角只能由 Foundation 的 Surface Role 与 Token 生成。
- 图片像素、截图标注、透明度棋盘和颜色样本属于真实内容绘制，可以使用专用渲染，但必须进入按用途声明的白名单，不得被当作通用结构样式。

## 响应式和长内容

- 窄窗口先压缩说明和可伸缩内容，不能先移动主要操作。
- 长文本应换行或截断并提供 Tooltip／无障碍完整值；不得让相邻控件漂移。
- 主题、语言、状态切换不得改变页面骨架、滚动位置和第一响应者。
