# 状态反馈与动效

## 稳定几何

- 加载、校验、成功、失败和重试使用预留反馈槽、覆盖层或独立 HUD，不得挤压输入框、设置行、列表和工具条。
- 同一任务的迟到结果不得覆盖用户已经输入或更新的状态。
- 危险操作必须先确认，并明确可撤销或不可撤销口径。

## 反馈

- 点击、选择和切换应在 100ms 内出现可见反馈；耗时任务随后更新阶段。
- 成功优先使用短暂状态图标或紧凑确认；错误说明真实原因、影响和可行下一步。
- 通知不获取第一响应者，不遮挡当前主要任务，不承担长期状态展示。

## 动效

- 动效只解释来源、去向、层级、完成或恢复。
- 拖动、裁剪、缩放、绘制和手柄操作为直接操作，不使用补间动画。
- 使用 `BlocksMotionRole`，禁止无状态边界的隐式 `.animation`。
- 开启“减少动态效果”时取消位移、缩放和玻璃形变，仅保留不超过 100ms 的透明度变化或立即切换。
