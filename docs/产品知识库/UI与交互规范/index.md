# UI 与交互规范

状态：active

最后审阅：2026-08-02

来源级别：authoritative product experience standard

## 适用范围

本目录是 Blocks 长期 UI 与交互规则的唯一产品级入口，适用于主窗口、设置、剪贴板、截图、翻译、插件、浮层、HUD 和辅助页面。

优先级从高到低：

1. 当前用户明确确认的需求与验收口径。
2. 本目录的通用规则。
3. 全局代码 Token 与共享组件契约。
4. 模块项目文档中的局部规则。
5. 历史截图和旧实现。

模块特定尺寸、业务状态或一次性方案不得写入本目录。项目计划和验收证据继续放在 `docs/项目管理库/`。

## 开始 UI 工作前

1. 阅读本页。
2. 阅读与任务相关的专题文档。
3. 检查现有全局 Token、组件和相邻页面，不建立第二套样式。
4. 明确正常、加载、空、错误、禁用、焦点和危险操作状态。
5. 明确安装版证据和可自动验证的几何／行为契约。

## 产品性格

Blocks 的体验应当是：**原生利落、快而克制、稳定可预期**。爽感来自直接、准确、连续和可恢复，不来自夸张动效或局部视觉特效。
