# MVP 范围假设

状态：proposed
最后审阅：2026-07-01
来源级别：derived summary

## V1 目标范围

当前 V1 计划从“AI 桌面内容处理器 + AI agent 本地工具层”的最小交集启动，并以产出三类通用工具为目标。

V1 目标能力：

1. [截图](交互整合/截图与图片处理/index.md)。
2. [剪贴板](交互整合/剪贴板文本工作台/index.md)。
3. [翻译](交互整合/翻译工作台/index.md)。

这些能力的共同点是高频、本地上下文强、AI 增益明确，并且适合暴露给 agent 调用。它们相对通用，当前不以具体垂直目标用户作为前置条件。它们仍需通过技术验证和产品规格阶段确认具体深度，不应理解为一次性铺开所有子功能。

## 首版应验证的体验闭环

每组能力都需要同时回答两类使用路径：

- 人如何通过 Mac UI 快速完成任务。
- agent 如何通过结构化输入调用同一能力，并拿到稳定输出。

首版成功不只取决于工具数量。三类工具都要具备可日常使用的核心深度，并且至少第一个工具纵切要达到可替代同类独立工具的基础质量。

## 暂缓能力

以下能力暂不列入首版承诺，除非后续验证显示它们服务于首批闭环：

- 录屏和快剪。
- 日历。
- 计算器。
- 壁纸模糊。
- 通用快捷启动。
- 复杂素材库和创作者工作台。
- 文件与图片批处理工作台。

## MVP 验收假设

首个可用版本至少应满足：

- 三类工具均具备完整 UI 核心路径。
- 三类工具均具备 CLI JSON 调用路径。
- 权限请求、失败提示、执行结果和日志可解释。
- AI 调用有明确确认边界和本地/云端数据处理说明。
- 输出结果可以被用户复用，也可以被 agent 继续处理。
