# 交互整合

状态：proposed
最后审阅：2026-07-01
来源级别：authoritative definition

本目录维护用户看到的入口、视图、快捷菜单和工作台如何组合底层工具模块。

交互整合不是底层工具本身。一个入口可以组合多个底层工具，一个底层工具也可以被多个入口复用。

## 设计原则

- 先定义底层工具能力，再定义它们在哪些视图出现。
- 截图后的底部菜单和图片文件入口可以展示相同图片功能。
- 工具入口不必和底层工具一一对应。
- 同一底层 action 应在 UI、快捷菜单、CLI / agent 中保持一致。
