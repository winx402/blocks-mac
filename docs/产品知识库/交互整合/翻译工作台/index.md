# 翻译工作台交互整合

状态：proposed
最后审阅：2026-07-01
来源级别：authoritative definition

本入口把图片 OCR 翻译、剪贴板文本翻译、手动文本翻译和 agent 翻译 action 组合成一个通用翻译工具。它不是只服务截图，也不是只服务剪贴板；翻译应成为可被多个入口复用的共享 action。

默认快捷键为 `Control + Option + D`。用户自定义或禁用时，以设置 > 快捷键当前绑定为准。

产品参考以 Bob 为主：划词翻译、截图翻译、输入翻译、OCR、翻译窗口多开、自定义插件、AppleScript/PopClip 调用是需要重点拆解的成熟能力。DeepL 和 Easydict 作为交互补充参考。

## 输入入口

| 入口 | 输入 | 说明 |
| --- | --- | --- |
| 手动文本 | 用户粘贴或输入文本 | 最基础翻译路径，不依赖截图或剪贴板历史。 |
| 选中文本 | 当前 App 中选中的文本 | 通过快捷键触发，在当前任务上下文附近显示结果。 |
| 剪贴板 | 当前剪贴板或历史剪贴板文本 | 需要用户明确选择，默认不静默上传全部历史。 |
| 截图 OCR | 截图或图片选区 OCR 文本 | 复用截图与 OCR 能力，翻译前展示将处理的文本。 |
| 图片文件 OCR | 图片文件 OCR 文本 | 复用图片打开、OCR 和导出能力。 |
| CLI / agent | 文本、图片路径、目标语言和上下文 | 返回结构化译文、来源、语言和错误信息。 |

## V1 做到什么程度

- 支持中英互译。
- 支持原文/译文对照。
- 支持译文编辑、复制和替换当前剪贴板。
- 支持跨 App 快捷触发，但普通复制不应触发云端翻译。
- 划词翻译、截图翻译、输入翻译复用同一套结果面板和 action 能力。
- 翻译前展示即将处理的文本，尤其是来自截图、图片和剪贴板的内容。
- 保存最近翻译结果、来源入口、目标语言和失败原因。
- CLI / agent 输出稳定 JSON。

## 首版不做

- 多语言批量翻译。
- 术语库和团队翻译记忆。
- 保留原图版式的图片翻译。
- 长文档翻译工作流。
- 自动监听剪贴板并静默翻译。

## 待验证项

- 翻译是否需要独立主窗口，还是作为全局快捷面板优先。
- 语言检测是否进入 V1，还是只支持用户显式选择源语言/目标语言。
- 翻译 action 和 AI 改写 action 是否合并为一个 text-transform action，还是保持独立。
