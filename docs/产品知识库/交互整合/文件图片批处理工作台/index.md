状态：proposed

## 整合定位

本入口把批量选择、图片格式转换、压缩尺寸调整和批量命名组合成一个安全批处理工作台。

- [批量命名](../../工具/文件/批量命名.md)

## 主要视图

- 文件列表。
- 处理规则面板。
- 预览结果面板。
- 冲突和风险提示。
- 执行进度和失败项记录。

## 交错关系

- 同一批文件可以同时使用格式转换、压缩尺寸和批量命名。
- AI 命名建议属于批量命名能力，但必须在工作台中预览并确认。
- CLI / agent 可以提交批处理任务，但覆盖、移动、删除原文件必须进入确认边界。
