# V1 交互规格草案

状态：proposed
最后审阅：2026-07-01
来源级别：UX draft

本草案定义截图、剪贴板、翻译和设置页的交互骨架。它不是正式 PRD，也不是最终视觉规范；后续正式 PRD 和正式 UX `DESIGN.md` / `EXPERIENCE.md` 可以基于本草案继续收敛。

粗略视觉方向见：[V1 视觉方向草案](V1视觉方向草案.html)。

## 设计边界

- V1 覆盖截图、剪贴板、翻译和设置页。
- 快捷键有默认值，但必须可更换、可禁用、可恢复默认。
- AI、agent 和 hook 不做独立聊天入口，必须嵌入具体工具的结果面板或确认流程。
- 截图内容、剪贴板完整内容、外部 AI/API 调用和 hook 生效前必须可预览、可取消、可审计。
- 文件图片批处理不回到 V1，只作为后续候选入口保留。

## 全局界面地图

| Surface | 入口 | 用途 | V1 关键状态 |
| --- | --- | --- | --- |
| 菜单栏入口 | 点击菜单栏图标 | 展示工具入口、暂停记录、最近状态和设置入口。 | 正常、权限缺失、剪贴板暂停、provider 不可用。 |
| 截图选择视图 | 默认 `Control + Option + A` 或用户自定义快捷键 | 区域、窗口、全屏截图。 | 选择中、重选、取消、权限缺失。 |
| 截图结果浮层 | 截图完成后自动出现 | 预览图片和后续动作。 | 可复制、可拖拽、AI 确认、处理失败。 |
| 剪贴板历史面板 | 默认 `Control + Option + V` 或用户自定义快捷键 | 搜索、恢复、固定、分组和处理剪贴板历史。 | 空历史、搜索无结果、暂停记录、敏感遮蔽。 |
| 翻译面板 | 用户自定义快捷键、划词触发、截图/剪贴板 action | 翻译选中文本、输入文本、OCR 文本和剪贴板条目。 | 翻译中、成功、失败、provider 切换、外发确认。 |
| 设置页 | 菜单栏、主窗口、权限提示跳转 | 管理快捷键、权限、隐私、AI provider、CLI/agent、hook 和数据。 | 冲突、禁用、恢复默认、需要重授权。 |

用户自定义或禁用时，以设置 > 快捷键当前绑定为准。

## 快捷键规则

| 工具 | 默认快捷键 | 可配置要求 |
| --- | --- | --- |
| 截图 | `Control + Option + A` | 可更换、可禁用、可恢复默认；冲突时提示占用来源或提示用户重新设置。 |
| 剪贴板 | `Control + Option + V` | 可更换、可禁用、可恢复默认；禁用后菜单栏仍可进入历史。 |
| 翻译 | `Control + Option + D` | 可更换、可禁用、可恢复默认；设置页提供录入入口；必须检测与截图、剪贴板和系统常见快捷键的冲突。 |

交互要求：

- 快捷键设置使用“点击录入新快捷键”的控件，不要求用户手动输入文本。
- 每个快捷键行必须显示当前状态：启用、禁用、冲突、未设置。
- 恢复默认只影响对应工具，不重置其他设置。
- 冲突不应静默保存；用户可以取消或继续录入另一个组合。

## 截图交互

### 截图选择视图

触发后进入屏幕选区状态。用户可以选择区域、窗口或全屏；选区显示尺寸，支持取消和重选。

```text
+--------------------------------------------------+
|  translucent screen overlay                       |
|                                                  |
|        +------------------------------+          |
|        | selected region              |          |
|        | 1280 x 720                   |          |
|        +------------------------------+          |
|                                                  |
|  [Region] [Window] [Fullscreen]    [Cancel]      |
+--------------------------------------------------+
```

状态：

| 状态 | 行为 |
| --- | --- |
| 选择中 | 显示选区边界、尺寸和当前模式。 |
| 窗口悬停 | 高亮目标窗口边界。 |
| 权限缺失 | 不进入选区，显示说明和“打开系统设置”。 |
| 取消 | 回到触发前状态，不保存历史。 |

### 截图结果浮层

截图完成后出现轻量浮层，默认不遮挡主要任务。浮层包含图片预览、基础动作和图片处理动作。

```text
+----------------------------------------------+
| Screenshot                                     |
| +-------------------------------+  Actions    |
| | image preview                 |  Copy       |
| |                               |  Save       |
| |                               |  Drag       |
| +-------------------------------+  Pin        |
| [Annotate] [OCR] [Translate] [Summarize]       |
| AI confirmation appears here when needed       |
+----------------------------------------------+
```

动作：

- 基础动作：复制、保存、另存为、拖拽、置顶、重新截图。
- 图片动作：标注、OCR、翻译、总结、内容识别。
- AI 动作：先展示将处理的区域、OCR 文本或图片摘要，再由用户确认。

失败处理：

- OCR 失败：保留图片，提示重试或改用手动选区。
- AI provider 失败：保留原图和 OCR 文本，允许切换 provider 或重试。
- 保存失败：提示路径问题，不丢失当前截图。

## 剪贴板交互

### 历史面板

`Control + Option + V` 或自定义快捷键打开历史面板。默认按时间倒序展示，搜索栏自动聚焦。

```text
+------------------------------------------------+
| Search clipboard history...        [Paused off] |
|------------------------------------------------|
| Pinned                                         |
| [API payload template] [Support reply]         |
|------------------------------------------------|
| Today                                          |
| > Text   2 min ago    Mock clipboard summary   |
|   Image  8 min ago    1200 x 800 PNG           |
|   Link   1 h ago      example.com              |
|------------------------------------------------|
| Detail preview / actions                       |
| [Paste] [Copy] [Pin] [Group] [Translate] [AI]  |
+------------------------------------------------+
```

状态：

| 状态 | 行为 |
| --- | --- |
| 空历史 | 说明尚无记录，并提供开启/检查权限入口。 |
| 暂停记录 | 顶部显示暂停状态，允许继续搜索旧记录。 |
| 搜索无结果 | 保留搜索词，提供清除搜索。 |
| 敏感遮蔽 | 默认只显示类型、来源和时间，完整内容需用户确认。 |

详情预览：

- 文本：显示纯文本和可恢复格式提示。
- 富文本：显示简化预览和格式类型。
- 图片：显示缩略图、尺寸、文件类型。
- 链接/文件引用：显示目标、来源 App、复制时间。

AI 处理：

- 仅处理当前选中的条目。
- 对完整内容执行翻译、改写、总结或敏感识别前展示预览。
- 不允许默认处理完整历史。

## 翻译交互

### 翻译面板

翻译面板复用 Bob 式多入口：划词翻译、输入翻译、截图 OCR 翻译、剪贴板条目翻译。结果面板保持同一结构。

```text
+----------------------------------------------+
| Translate                         Provider v |
| Source: Selection / Clipboard / Screenshot    |
| +--------------------+ +--------------------+ |
| | original text      | | translated text    | |
| |                    | |                    | |
| +--------------------+ +--------------------+ |
| [Copy] [Replace Clipboard] [Save] [Retry]     |
| [Polish] [Explain term]                       |
+----------------------------------------------+
```

入口规则：

- 划词翻译：从当前 App 选中文本进入，结果出现在当前上下文附近。
- 输入翻译：用户手动输入或粘贴文本。
- 截图 OCR 翻译：先显示 OCR 原文，再确认翻译。
- 剪贴板翻译：用户选择当前剪贴板或某条历史后进入。
- CLI / agent 翻译：返回结构化结果，不绕过 UI 的敏感确认策略。

失败处理：

- provider 超时：显示失败原因、耗时和重试。
- provider 不可用：允许切换 provider。
- OCR 文本不可信：提示用户检查原文后再翻译。
- 外部 API 未配置：跳转设置页 AI Provider 区域。

## 设置页信息架构

设置页采用左侧导航、右侧详情的 Mac 桌面结构。设置项不做成营销说明页，优先服务重复配置和排障。

```text
+-------------------------------------------------------+
| Settings                                              |
|-------------------------------------------------------|
| Sidebar            | Detail                           |
| Shortcuts          | Screenshot   Control + Option + A  [Edit]  |
| Permissions        | Clipboard    Control + Option + V  [Edit]  |
| Clipboard          | Translate    Control + Option + D  [Edit]  |
| Privacy Exclusions | Conflict warnings appear inline  |
| AI Providers       | [Restore Defaults]               |
| CLI / Agent        |                                  |
| Hooks              |                                  |
| Data               |                                  |
+-------------------------------------------------------+
```

### 设置分区

| 分区 | V1 内容 |
| --- | --- |
| 快捷键 | 截图、剪贴板、翻译快捷键；编辑、禁用、恢复默认、冲突提示。 |
| 权限与隐私 | 屏幕录制、辅助功能、剪贴板、文件访问、登录项状态和引导。 |
| 剪贴板保存策略 | 保留时间、数量上限、固定项不过期、暂停记录、清空历史。 |
| 隐私排除 App | 添加/移除排除应用，默认不记录明确敏感来源。 |
| AI Provider / API | provider 列表、启用状态、数据外发确认策略、密钥配置入口。 |
| 本地 CLI / agent | Codex/Claude Code/GitHub Copilot/Qoder/opencode 等候选的检测状态和测试入口。 |
| Hook | hook 草稿、触发点、权限、启用确认、审计记录。 |
| 历史清理与数据管理 | 清理截图历史、剪贴板历史、翻译历史、AI action 记录。 |

### 权限提示模式

权限提示必须解释三件事：

1. 为什么需要权限。
2. 会处理什么数据。
3. 用户如何关闭或撤销。

## AI / Agent / Hook 嵌入规则

| 能力 | 出现位置 | 必须确认的情况 |
| --- | --- | --- |
| OCR | 截图结果浮层、图片处理区 | 通常不需要外发确认；若使用云 OCR 必须确认。 |
| 翻译 | 截图、剪贴板、翻译面板 | 来自截图或剪贴板、且进入外部 provider 时必须确认。 |
| 总结 / 改写 | 截图结果、剪贴板详情、翻译结果 | 输入包含敏感来源或外部 provider 时必须确认。 |
| Agent 查询 | CLI / agent 设置、剪贴板历史 | 默认只返回摘要；完整内容需授权。 |
| Hook | 设置页 Hook 分区、相关工具确认流 | 生效、阻断、修改、删除、外发内容时必须确认。 |

## 关键走读路径

1. 用户按截图快捷键，框选区域，复制图片到聊天窗口。
2. 用户截图后点 OCR，再点翻译，确认 OCR 文本进入 provider，复制译文。
3. 用户按剪贴板快捷键，搜索历史，固定一条常用回复并放入分组。
4. 用户从剪贴板历史选择一条文本，执行 AI 改写，确认只处理当前条目。
5. 用户划词翻译，provider 失败后切换 provider 并重试。
6. 用户进入设置页修改截图快捷键，发现冲突，改用另一组快捷键。
7. Agent 请求读取剪贴板历史，UI 只允许摘要；读取完整内容需要用户确认。
8. Agent 生成 hook 草稿，用户在设置页预览权限和效果后手动启用。

## 验收检查

- V1 产品规格中的必做项均能在本草案找到对应界面或状态。
- 截图、剪贴板、翻译都有入口、主界面、成功状态、失败状态和权限/确认状态。
- 快捷键具备默认值、可更换、可禁用、恢复默认和冲突提示。
- AI/API/hook 不存在静默外发或静默生效路径。
- HTML 视觉方向页可离线打开，不依赖构建工具，不作为最终视觉定稿。
