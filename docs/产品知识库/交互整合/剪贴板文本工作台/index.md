# 剪贴板文本工作台交互整合

状态：proposed
最后审阅：2026-07-01
来源级别：authoritative definition

## 整合定位

本入口把剪贴板历史、文本搜索、AI 改写和敏感信息识别组合成一个文本工作台。

默认快捷键为 `Control + Option + V`，但必须支持更换、禁用、恢复默认和冲突提示。用户自定义或禁用时，以设置 > 快捷键当前绑定为准。交互参考 Paste 的 pinboard/分组思路，但 V1 必须先保证历史记录、格式保留、搜索、固定、过期清理和隐私排除。

## 主要视图

- 剪贴板历史列表。
- 搜索和过滤栏。
- 固定内容分组 / pinboard。
- 文本详情和编辑区。
- 图片、富文本、链接、文件引用的预览。
- AI 改写结果面板。
- 敏感信息遮蔽预览。

## 交错关系

- 剪贴板历史提供输入，文本搜索负责找回，AI 改写负责处理，敏感信息识别负责风险提示。
- CLI / agent 可以查询剪贴板历史摘要、读取授权条目、调用文本改写或敏感信息识别，不一定经过剪贴板历史视图。
- AI 处理默认只作用于用户选中的条目，不处理完整历史。
