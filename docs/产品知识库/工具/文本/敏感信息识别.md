# 敏感信息识别

状态：proposed
最后审阅：2026-06-29
来源级别：authoritative definition

## 模块定位

识别文本中的潜在敏感信息，并提供遮蔽建议。

## V1 功能

- 识别邮箱、手机号、URL。
- 识别疑似 API key、token、私钥片段。
- 识别身份证样式文本、银行卡样式文本。
- 生成遮蔽预览。
- 用户确认后复制遮蔽版本。

## 做到什么程度

- 默认保守提示，不自动删除或替换用户原文。
- 本地规则优先。
- 用户能关闭或调整提示强度。

## AI 结合点

- AI 可用于用户主动触发的深度检查，例如判断一段文本是否包含隐私风险。
- 默认不静默发送全部剪贴板历史。

## 首版不做

- 法务级合规审计。
- 自动清洗所有历史记录。
