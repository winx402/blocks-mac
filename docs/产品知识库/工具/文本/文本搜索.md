# 文本搜索

状态：proposed
最后审阅：2026-06-29
来源级别：authoritative definition

## 模块定位

在剪贴板历史或用户输入文本中快速找到目标内容。

## V1 功能

- 关键词搜索。
- 按类型过滤，例如链接、代码片段、普通文本。
- 按时间范围过滤。
- 搜索结果复制和定位。

## 做到什么程度

- 最近数千条文本记录应能快速搜索。
- 搜索结果要显示匹配位置或摘要。

## AI 结合点

- 语义搜索可作为 V1 验证项：用户用自然语言描述要找的内容，系统返回可能相关条目。
- 是否使用本地 embedding 或云端模型需技术验证。

## 首版不做

- 全局文件内容搜索。
- 跨设备搜索。
