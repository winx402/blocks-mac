# 剪贴板历史

状态：proposed
最后审阅：2026-07-01
来源级别：authoritative definition

## 模块定位

记录和管理用户最近复制过的内容，包括文本、富文本、图片、链接和文件引用。

## V1 功能

- 通过默认 `Control + Option + V` 或用户自定义快捷键弹出剪贴板历史。
- 用户自定义或禁用时，以设置 > 快捷键当前绑定为准。
- 记录文本、富文本、图片、链接和文件引用。
- 保留内容格式，恢复粘贴时优先使用原始格式。
- 去重。
- 时间排序。
- 搜索。
- 固定常用内容。
- 固定内容分组。
- 删除单条。
- 清空历史。
- 暂停记录。
- 设置保留数量或保留时间。

## 做到什么程度

- 记录必须稳定，不能频繁漏记或重复刷屏。
- 用户必须能随时暂停记录和清理历史。
- 默认不记录明确排除的敏感应用。
- 固定内容不参与过期清理。
- agent 默认只能读取历史摘要，读取完整内容需要用户授权或明确配置。

## AI 结合点

- 本模块不直接调用 AI。
- 它为文本搜索、AI 改写、翻译、总结和敏感信息识别提供输入。

## 首版不做

- 跨设备同步。
- 团队片段库。
- 自动读取密码管理器字段。
- 默认上传完整剪贴板历史给 AI。
