# 图片打开与预览

状态：proposed
最后审阅：2026-06-29
来源级别：authoritative definition

## 模块定位

打开并展示一张图片，为 OCR、标注、翻译、总结、识别和导出提供统一图片上下文。

## V1 功能

- 从本地选择图片打开。
- 拖拽图片打开。
- 从截图结果接收图片。
- 显示文件名、尺寸、大小和来源。
- 缩放、适配窗口、拖动查看。
- 支持选定局部区域供其他模块处理。

## 做到什么程度

- 图片打开失败要说明原因，例如格式不支持、文件不存在、权限不足。
- 图片预览要能服务截图结果和本地图片两种入口。
- 区域选择结果应能传递给 OCR、翻译、总结和内容识别。

## AI 结合点

- 本模块不直接调用 AI。
- 它负责向 AI 类模块提供图片、选区和基础元数据。

## 首版不做

- 批量图片管理。
- 图片对比。
- 图片收藏库。
