# 内容识别

状态：proposed
最后审阅：2026-06-29
来源级别：authoritative definition

## 模块定位

从图片 OCR 文本中识别可操作信息和风险信息。

## V1 功能

- 识别 URL。
- 识别邮箱、手机号、金额、日期。
- 识别错误码和常见报错形态。
- 识别疑似密钥、身份证样式文本、银行卡样式文本。
- 对识别结果提供复制、遮蔽或进一步处理入口。

## 做到什么程度

- 风险识别默认保守提示，不替用户自动删除原文。
- 识别结果要能解释来源，例如来自哪段 OCR 文本。
- 敏感信息提示应优先本地规则完成。

## AI 结合点

- 规则识别无法判断的复杂内容，可由用户主动触发 AI 深度识别。
- AI 识别不得静默上传整张图或全部 OCR 文本。

## 首版不做

- 证件、票据、发票的完整结构化识别。
- 图表理解。
- UI 自动化点击。
