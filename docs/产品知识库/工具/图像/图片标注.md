# 图片标注

状态：proposed
最后审阅：2026-06-29
来源级别：authoritative definition

## 模块定位

对图片添加沟通型标注，服务截图分享、问题反馈、教程说明和内容强调。

## V1 功能

- 箭头。
- 矩形框。
- 高亮。
- 马赛克。
- 文字备注。
- 撤销和重做。
- 导出带标注图片。

## 做到什么程度

- 标注能力以沟通效率为目标，不追求专业图片编辑。
- 标注操作必须轻量，用户截完图后可以快速画重点。
- 标注图应可复制和保存。

## AI 结合点

- V1 不要求 AI 自动标注。
- 后续可基于 AI 识别错误区域、重点文本或敏感信息后建议标注。

## 首版不做

- 图层管理。
- 专业绘图工具。
- 复杂样式系统。
