# 结果导出

状态：proposed
最后审阅：2026-06-29
来源级别：authoritative definition

## 模块定位

把图片处理结果输出给用户或其他工具模块。

## V1 功能

- 复制原图。
- 保存原图。
- 导出标注图。
- 复制 OCR 文本。
- 复制翻译结果。
- 复制总结结果。
- 导出 Markdown 结果。
- 输出 JSON 结果给 CLI / agent。

## 做到什么程度

- 用户应能清楚知道导出的是原图、标注图还是文本结果。
- CLI / agent 输出必须结构化，包含状态、结果和错误信息。
- 导出失败要说明原因。

## AI 结合点

- AI 结果通过本模块被复制、保存或传给 agent 后续处理。

## 首版不做

- PDF 报告导出。
- 自动同步到第三方笔记。
- 多结果模板系统。
