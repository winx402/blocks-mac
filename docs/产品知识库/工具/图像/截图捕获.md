# 截图捕获

状态：proposed
最后审阅：2026-07-01
来源级别：authoritative definition

## 模块定位

从屏幕获取一张图片。它只负责截图触发、选择、捕获和截图结果基础动作，不负责 OCR、翻译、总结等图片处理。

## V1 功能

- 默认全局快捷键 `Control + Option + A`、用户自定义快捷键、菜单栏或主窗口触发截图。
- 用户自定义或禁用时，以设置 > 快捷键当前绑定为准。
- 区域截图。
- 全屏截图。
- 窗口截图。
- 选择框调整大小和位置。
- 显示截图尺寸。
- 取消、重新选择、确认截图。
- 复制图片到剪贴板。
- 保存或另存为图片。
- 拖拽截图到其他 App。
- 截图后出现图片预览和功能组。
- 截图权限未开启时给出引导。

## 做到什么程度

- 截图链路必须短，用户按默认或自定义快捷键后可以直接框选并完成截图。
- 区域选择必须可控，至少支持重选和取消。
- 权限失败不能静默失败，必须告诉用户去哪里开启权限。
- 截图结果应能传递给图片类工具继续处理。
- 截图后浮层必须足够轻，不应遮挡用户继续判断下一步。

## AI 结合点

- 截图捕获本身不需要 AI。
- AI 应在截图产生图片后，由 OCR、翻译、总结、识别等模块处理。

## 首版不做

- 滚动截图。
- 延时截图。
- 录屏。
- 截图自动理解内容。
