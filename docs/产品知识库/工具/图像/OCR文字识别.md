# OCR 文字识别

状态：proposed
最后审阅：2026-06-29
来源级别：authoritative definition

## 模块定位

从图片或图片选区中提取文字，为复制、翻译、总结、结构化提取和 agent 调用提供文本基础。

## V1 功能

- 整图 OCR。
- 选区 OCR。
- 展示识别文本。
- 识别文本可编辑、复制、重新识别。
- 保留基础段落结构。
- 输出 OCR 文本、识别区域和置信度信息；置信度是否可用取决于技术实现。

## 做到什么程度

- 中英文常见截图文字应可用。
- 识别结果可以不完美，但必须允许用户编辑和复制。
- 无文字、图片过大、识别失败要有明确反馈。

## AI 结合点

- OCR 结果可以作为 AI 翻译、AI 总结、内容识别的输入。
- 可用 AI 修正 OCR 文本，但 V1 不默认启用；用户应能看到原 OCR 文本。

## 首版不做

- 复杂表格高精度识别。
- 公式识别。
- 保证版式还原。
