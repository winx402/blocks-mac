# 历史与结果记录

状态：proposed
最后审阅：2026-06-29
来源级别：authoritative definition

## 模块定位

记录用户最近执行过的截图、图片处理、文本处理和批处理结果。

## V1 功能

- 保存最近截图记录。
- 保存图片处理记录。
- 保存 OCR、翻译、总结结果摘要。
- 保存剪贴板处理结果。
- 保存批处理任务结果。
- 重新打开、复制结果、删除记录。

## 做到什么程度

- 历史记录要能帮助用户复用结果，而不是只做审计日志。
- 用户可以删除记录。
- 敏感内容记录需要遵守权限与隐私设置。

## AI 结合点

- AI 结果应记录生成时间、输入来源和动作类型。
- 不应无条件保存完整敏感输入。

## 首版不做

- 云同步历史。
- 多设备历史。
