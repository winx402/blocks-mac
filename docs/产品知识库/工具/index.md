# 基础工具模块

状态：proposed
最后审阅：2026-06-29
来源级别：authoritative definition

本目录维护基础功能模块。这里的“工具”不是用户看到的入口或完整工作台，而是可被多个入口、视图、快捷菜单、CLI / agent 调用复用的底层能力。

入口和视图组合放在 [交互整合](../交互整合/index.md)。一个交互入口可能组合多个底层工具；一个底层工具也可能出现在多个入口中。

## 通用深度要求

每个大类文档内部按模块列举基础功能。每个基础功能模块都必须满足：

- 能说明自己提供的底层能力，不混入具体入口布局。
- 能说明输入、输出、失败情况和权限要求。
- 涉及 AI 时，必须说明触发点、输入内容、输出形态和用户确认边界。
- 能被至少一个交互整合入口引用。
- 有清晰的 V1 范围和后续扩展边界。
