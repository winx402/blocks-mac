# 批量选择与任务

状态：proposed
最后审阅：2026-06-29
来源级别：authoritative definition

## 模块定位

为批量文件和图片处理提供选择、预览、任务队列、进度和失败记录。

## V1 功能

- 拖拽选择文件。
- 文件选择器选择文件或目录。
- 展示文件名、类型、大小、路径和状态。
- 任务队列。
- 进度反馈。
- 成功项和失败项记录。
- 失败项重试。

## 做到什么程度

- 批处理不能静默跳过失败项。
- 用户要能在执行前看到将处理哪些文件。
- 任务结果要可追踪。

## AI 结合点

- 本模块不直接调用 AI。
- 它为 AI 批量命名、分类建议和规则生成提供文件上下文。

## 首版不做

- 后台长期任务调度。
- 云端文件同步。
