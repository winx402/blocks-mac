# 批量命名

状态：proposed
最后审阅：2026-06-29
来源级别：authoritative definition

## 模块定位

安全地批量生成、预览和执行文件重命名。

## V1 功能

- 序号命名。
- 日期命名。
- 保留原文件名片段。
- 查找替换。
- 前缀和后缀。
- 新旧文件名预览。
- 命名冲突检测。
- 撤销策略。

## 做到什么程度

- 所有批量改名必须先预览。
- 冲突不能静默覆盖。
- 涉及覆盖或移动原文件时必须二次确认。

## AI 结合点

- AI 可根据文件名、图片内容或 OCR 文本生成命名建议。
- AI 命名只生成候选，用户确认后才执行。

## 首版不做

- 自动移动文件。
- 无确认自动重命名。
- 复杂资料库管理。
