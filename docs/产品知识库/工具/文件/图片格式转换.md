# 图片格式转换

状态：proposed
最后审阅：2026-06-29
来源级别：authoritative definition

## 模块定位

将一批图片从一种格式转换为另一种格式。

## V1 功能

- 常见图片格式转换。
- 输出目录选择。
- 保留或重写文件名。
- 转换前预览输出路径。
- 失败项记录。

## 做到什么程度

- 默认输出到新目录，不覆盖原文件。
- 不支持的格式要明确提示。
- 转换结果路径要清晰可追踪。

## AI 结合点

- 本模块不需要 AI。
- AI 可以在交互整合层辅助解释格式选择，但不是底层转换能力。

## 首版不做

- 视频转换。
- 专业色彩管理。
- 承诺所有元数据完整保留。
