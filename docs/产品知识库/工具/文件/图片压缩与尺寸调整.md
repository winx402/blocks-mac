# 图片压缩与尺寸调整

状态：proposed
最后审阅：2026-06-29
来源级别：authoritative definition

## 模块定位

批量压缩图片或调整图片尺寸。

## V1 功能

- 按质量压缩。
- 按目标体积压缩；是否精确达到目标体积取决于技术验证。
- 按宽高调整尺寸。
- 按百分比调整尺寸。
- 按最长边调整尺寸。
- 显示压缩前后体积预估或结果。

## 做到什么程度

- 用户执行前应能理解压缩或改尺寸规则。
- 默认输出到新目录。
- 失败项不能影响已成功项的记录。

## AI 结合点

- V1 不需要 AI。
- 后续可根据目标平台建议尺寸和压缩参数。

## 首版不做

- 专业图像增强。
- 无损压缩承诺。
- 自动识别所有平台规格。
