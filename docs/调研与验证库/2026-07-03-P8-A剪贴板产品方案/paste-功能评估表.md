# Paste 功能评估表

状态：pending review
最后审阅：2026-07-03
用途：把 Paste 官方能力转成积木工具剪贴板 V1 取舍

## 评估口径

- `V1`：进入剪贴板 V1 产品打磨范围，后续开发拆分时按优先级排期，但不再作为悬而未决的“可选项”。
- `V1.1+`：有价值，但需要更多数据、权限、同步或复杂交互。
- `不做`：不符合当前产品边界，或会把项目带向云协作/商业体系。

## 对积木工具的启发

Paste 的强项不是某个按钮，而是四个产品原则：

1. **内容可见**：用户靠视觉预览找东西。
2. **筛选自然**：搜索字段和 filter chips 共同缩小结果。
3. **长期内容有组织层**：Pinboards 让固定不只是“不删除”。
4. **隐私控制前置**：排除 App、暂停记录、保留策略是核心设置，不是高级调试。

积木工具 V1 应吸收这些原则，但不照搬云同步、共享协作、订阅或跨端体系。

## Shared Pinboards 说明

Shared Pinboards 在 Paste 中是“把某个 Pinboard 共享给其他人”的协作能力，依赖 Apple 原生 iCloud 分享、成员邀请、读写权限和链接访问控制。它和积木工具 V1 的“本地固定分组”不是同一种能力：

- 本地固定分组：单机、本地数据、服务个人复用，进入 V1。
- Shared Pinboards：跨用户、跨设备、成员权限、同步与撤销访问，当前不进入 V1，只保留为 V1.1+ 协作方向。
