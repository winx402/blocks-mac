# P8-A 剪贴板产品方案报告

状态：pending review

阶段边界：产品方案；不改代码、不写验证脚本、不进入实现

## 结论摘要

当前剪贴板模块的问题不是单点视觉瑕疵，而是产品层级仍停留在“调试摘要面板”：条目缺少内容预览模型，筛选缺少结构化维度，固定内容缺少组织层，设置页缺少 macOS 风格的信息分组。继续只调间距、按钮和局部文案会反复返工。

P8-A 建议把剪贴板模块重设为三层产品结构：

1. **历史浏览层**：以内容卡片为核心，快速看到“我复制过什么”，而不是看到“这条记录是什么类型的说明”。
2. **查找筛选层**：搜索、格式、时间、来源、分组共同工作，用户能在几秒内缩小结果。
3. **长期复用层**：固定内容进入 Pinboard 式分组，可重命名、换组、编辑文本内容，并按组过滤。

本阶段只提交方案，等待确认后再拆 P8-B 开发。

## 产品原则

1. **内容优先**：剪贴板历史的主价值是“找回复制过的东西”，条目卡片必须优先展示内容预览。
2. **格式可辨**：文本、图片、链接、文件和富文本不应共用一个摘要模板。
3. **查找可组合**：搜索、格式、时间、来源、分组应能组合，不互相覆盖。
4. **管理不打扰浏览**：pin、删除、重命名、移动分组进入右键菜单或详情，不常驻挤压卡片。
5. **隐私边界可见**：排除 App、敏感内容、不可恢复项要明确展示“为什么没有内容”，而不是空白或失败。
6. **本地优先**：V1 不因参考 Paste 而引入云同步、协作或外部服务。
7. **筛选低占用**：筛选维度增多后，默认只占一排图标；展开和选择只在需要时出现。
8. **agent 授权前置**：CLI/MCP 可以调用剪贴板摘要能力，但完整内容读取必须由用户在 UI 中确认范围。

## V1 范围建议

### V1 必做

- bottom 面板顶部收紧，移除底部提示。
- 内容卡片差异化渲染：文本、富文本、图片、URL、文件、混合、排除项。
- hover 详情跟随鼠标并防裁切。
- 右键菜单承载固定、删除、重命名、移动分组、复制为纯文本。
- 顶部图标组筛选：格式、时间、分组、来源；支持 hover 展开、选择后暂显筛选名、多筛选叠加和一键清空。
- 筛选保留策略：面板关闭后默认 30 秒清空，可设置为立即、15 秒、30 秒、1 分钟、永不自动清空。
- Pinboard 式固定分组：创建、改名、颜色、移动条目。
- 来源 App 筛选。
- 批量选择和批量删除。
- Quick Paste 数字快捷键。
- 纯文本粘贴快捷动作。
- Paste Stack 式顺序粘贴。
- 预览内编辑文本/富文本；图片编辑推迟。
- Agent CLI / MCP 读取剪贴板历史的设置入口和完整内容 UI 授权面板。
- 剪贴板设置页重构为用户任务分区。
- 隐私排除独立成页：App 列表 + toggle + 最近来源 App + 选择应用 + 手动 bundleId 高级入口。

### V1.1+ 候选

- 图片编辑。
- 图片 OCR 搜索。
- iCloud/跨设备同步。
- 共享 Pinboards：基于 iCloud/成员权限的跨用户共享固定分组。

### 不做

- 照搬 Paste 的协作、订阅、云同步体系。
- 默认上传剪贴板内容。
- 默认开放真实用户历史完整内容给 agent。
