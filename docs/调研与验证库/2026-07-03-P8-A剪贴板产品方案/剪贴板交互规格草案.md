# 剪贴板交互规格草案

状态：pending review
最后审阅：2026-07-03
适用范围：`Control + Option + V` 剪贴板浮层与相关条目交互

## 面板结构

### Bottom 模式

- 面板固定贴屏幕底部，满宽，不允许横向调整。
- 高度允许通过顶部 handle 调整并保存。
- 面板内部自上而下分为：
  1. 紧凑工具栏：搜索框、格式/时间/分组/来源筛选图标组、清空筛选、设置、关闭。
  2. 主内容区：横向滚动卡片 tray。
  3. 临时状态层：空状态、暂停状态、无结果状态，占用主内容区而不是新增底部 footer。
- 不显示常驻底部提示文字。

### Left / Right 模式

- 面板贴屏幕左/右侧，高度使用屏幕可见高度，不允许拖动。
- 布局改为纵向：顶部搜索和筛选，下面是纵向卡片列表。
- 分组筛选可显示为下拉或窄侧栏，避免压缩内容卡片。

## 顶部工具栏

| 区域 | 方案 |
| --- | --- |
| 搜索框 | 左侧主入口；默认聚焦；支持直接输入搜索。 |
| 格式筛选图标 | 默认只显示格式图标；hover 展开 `全部 / 文本 / 富文本 / 图片 / URL / 文件 / 混合 / 排除`。 |
| 时间筛选图标 | 默认只显示时间图标；hover 展开 `全部 / 今天 / 昨天 / 前天 / 最近三天 / 最近一周 / 上周 / 自定义`。 |
| 分组筛选图标 | 默认只显示分组图标；hover 展开 `全部 / 未分组 / 固定分组`。 |
| 来源筛选图标 | 默认只显示来源图标；hover 展开 `全部 / 最近来源 App / 已排除来源占位`。 |
| 清空筛选 | 仅在存在 active filter 时显示；一键恢复格式、时间、分组、来源为全部。 |
| 设置按钮 | 打开 Clipboard 设置页并关闭浮层。 |
| 关闭按钮 | 关闭浮层，不影响主 App。 |

筛选组行为：

- 默认状态：搜索框后面是一排筛选图标，不展开具体文字，保证内容卡片尽量靠上。
- Hover 状态：鼠标移入某个筛选图标时，在图标下方或邻近位置展开该组可选项；展开层不改变主卡片带布局。
- 已选状态：鼠标移开后，如果该组选择了非全部项，图标后短暂显示筛选名，例如 `图片`、`最近一周`、`工作资料`。多组筛选可以同时显示短标签。
- 叠加规则：搜索 query 与格式、时间、分组、来源筛选取交集；空结果必须显示当前条件和清空筛选按钮。
- 清空规则：清空筛选按钮清除格式、时间、分组、来源；搜索框内有自己的清空按钮，避免用户误删正在输入的搜索词。
- 保留规则：面板关闭后筛选默认保留 30 秒，设置中可改为 `立即 / 15 秒 / 30 秒 / 1 分钟 / 永不自动清空`。如果用户在保留窗口内重新打开面板，筛选仍生效；超过保留时间后恢复全部。

筛选结果区需要显示简短状态，例如 `图片 · 最近一周 · 3 项`。该状态不放在底部。

## 条目卡片

### 通用字段

- 主展示：按格式渲染的内容预览；pinned item 可用自定义名称作为标题，但仍展示原始内容作为次级识别。
- 次展示：时间。
- 状态：仅保留低占用标记，例如 pinned、排除、不可恢复、隐私占位。
- 来源 App、URL 解析、格式细节、大小、hash、可恢复状态默认不放在卡片常态里，进入 hover 详情。
- 默认不显示 pin/delete 按钮。

### 格式差异化

| 格式 | 卡片展示 |
| --- | --- |
| 文本 | 展示正文前 2-4 行；代码样文本使用等宽字体和轻量语法感。 |
| 富文本 | 展示纯文本 fallback，同时用 `RTF` badge 标记保留格式。 |
| 图片 | 展示本地缩略图；下方显示尺寸/来源/时间。 |
| URL | 展示 URL host 和路径摘要；若已有本地标题元数据则展示标题；V1 不自动联网抓取。 |
| 文件 | 展示文件名、数量、扩展名/类型图标；不展示完整真实路径。 |
| 混合 | 展示主要格式 + item count，提示“多格式”。 |
| 排除项 | 展示来源 App、时间和“已按隐私规则跳过内容”。 |

## Hover 详情

- Hover 详情跟随鼠标或卡片锚点，不固定在面板角落。
- 详情浮层应按当前屏幕 visibleFrame 进行边界避让。
- 如果卡片靠近底部，详情显示在上方；靠近右侧则向左展开。
- 详情内容：
  - 完整一点的内容预览，但不超过安全高度。
  - 格式、来源、时间、大小、hash 短摘要、是否可恢复。
  - URL 的本地解析信息，例如 host、path、已知标题；默认不联网抓取 favicon、摘要或页面内容。
  - 隐私/排除原因。
  - 对 pinned item 展示分组和自定义名称。
- 详情不包含常驻 pin/delete 按钮；管理动作使用右键菜单。

## 右键菜单

| 动作 | 可用条件 |
| --- | --- |
| 粘贴 | 可恢复且存在目标 App。 |
| 复制到剪贴板 | 可恢复。 |
| 复制为纯文本 | 文本、富文本、URL。 |
| 固定 / 取消固定 | 所有非排除项。 |
| 移动到分组 | pinned 或可固定项；选择后自动 pinned。 |
| 重命名 | pinned item 优先；普通项可先固定后命名。 |
| 删除 | 所有历史项。 |
| 显示详情 | 所有项。 |

删除需要明确是删除本地历史记录，不删除系统剪贴板当前内容。

## 固定分组

- 分组采用 Pinboard 心智，中文界面可称“固定分组”。
- 每个分组包含：名称、颜色、排序、item count。
- 固定条目可以：
  - 移动到分组。
  - 从分组移除但保留在历史中。
  - 重命名显示名。
  - 保留原始内容预览作为次级信息。
- “未分组固定”作为系统默认组，不可删除。

## Paste Stack 式顺序粘贴

V1 纳入基础顺序粘贴能力，但不和云同步或共享协作绑定。

- 用户可通过右键菜单或多选操作把条目加入 Stack。
- Stack 以小型状态条展示当前队列数量和下一条内容摘要。
- 每次执行粘贴时按队列顺序消耗一条，直到队列为空。
- Stack 只保存本机临时队列，不跨设备同步，不默认持久化。

## 预览内编辑

- 文本和富文本条目支持在详情/预览里编辑副本，保存后成为新的本地可恢复条目或替换原固定条目，具体 destructive 语义需要二次确认。
- 普通历史条目编辑时应优先生成新条目，避免用户误以为原始复制记录未改变。
- 图片编辑不进入 V1。

## Agent CLI / MCP 授权面板

- agent 默认只能读取 redacted summary：条目 ID、类型、时间、来源候选、短摘要、是否 pinned，不读完整内容。
- 读取完整内容必须弹出 UI 授权面板，用户按范围确认：
  - 单条 / 多条 / 当前筛选结果。
  - 时间范围。
  - 格式范围。
  - 分组范围。
  - 授权持续时间。
- 授权面板必须展示请求来源、用途摘要、将读取的条目数量和风险等级，不展示不必要的完整内容预览。
- 授权过期后 agent 只能回到摘要级访问。

## 空状态和异常状态

| 状态 | 展示 |
| --- | --- |
| 无历史 | 显示“复制内容后会出现在这里”，可保留一个低调的设置入口。 |
| 搜索无结果 | 显示当前筛选条件，并提供“清除筛选”。 |
| 暂停记录 | 主内容区顶部显示暂停状态，允许恢复。 |
| 排除 App 命中 | 只显示隐私占位，不显示内容。 |
| 不可恢复 | 允许查看摘要和复制当前可展示文本，不承诺自动粘贴。 |

## 键盘交互

- 打开面板后搜索框聚焦。
- 左右箭头在 bottom tray 中移动选中。
- 上下箭头在 left/right 模式中移动选中。
- Return 粘贴当前选中项。
- Esc 关闭。
- Command-F 聚焦搜索。
- Context Menu 键或 Control-click 打开右键菜单。
