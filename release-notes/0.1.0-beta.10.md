# Blocks 0.1.0-beta.10

## 设置界面

- 统一侧栏与标题栏背景，调整图标、配色、分组间距与设置行排版。
- 设置窗口统一提供后退、前进、右键历史菜单及 Command-[ / Command-]；恢复对应页面的滚动位置、焦点和非敏感草稿。
- 精简重复标题与正文返回入口，修正滚动内容侵入标题栏的问题。
- 侧栏显示／隐藏移到“显示”菜单，支持 Command-Option-S。
- 修复插件异步安装完成后覆盖用户较新导航，以及服务配置草稿被根页面退出覆盖的边界。

## 开发安装维护

- 日常 Run 入口统一使用固定位置的源码安装；成功提交安装事务后清理旧应用包，失败时保留必要恢复材料。
- 不清理用户历史、收藏、设置、凭据或配对。

## 验证及边界

- 137项设置相关定向测试通过，并检查中英日文、窄窗口、深浅色、系统增强对比度及真实导航交互。
- 本版不改变截图、剪贴板或翻译浮窗的业务逻辑，不把模态编辑器或业务操作加入导航历史。
- 本机旧源码版曾返回 `preparation_failed`，通过正常退出主程序及内置Helper后完成源码升级；本版不宣称该自动退出准备问题已修复。
- macOS14及以上，Apple Silicon；此版本仍为Beta测试版。
