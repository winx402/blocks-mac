# Blocks 0.1.0-beta.25

## 翻译提示

- 将翻译面板的辅助提示从“原文”标题行分离，移除突出的控件式外壳；短状态与详细说明分层，不再依赖隐藏的横向滚动。
- 划词助手未就绪时显示具体状态和“完成设置”，直达现有设置向导；手动输入和截图翻译仍可使用，不再被误解为整个翻译功能失败。
- 提示的实际高度纳入布局预算，保留原文输入区的默认高度、随文本增长和内部滚动；真实操作失败仍有警示。

## 剪贴板空态与筛选

- 空态在剩余记录区域居中，去掉独立深色短块，使用面板现有材质；搜索和筛选无结果时可主动“返回全部记录”。
- 使用“记录”“搜索”“筛选”等用户文案，不再把元数据或索引实现术语用于普通无结果提示；加载、读取失败和真正无历史仍独立处理。
- 收紧格式、时间、来源三个控件，长名称保持截断与完整提示，选择和清除不推动相邻控件。默认控件区域可点击，活动筛选的清除按钮保持独立。
- 三个下拉使用原生菜单首击与生命周期管理，保护菜单选择和关闭 Escape，不重写筛选数据规则；诊断分别记录真实打开、关闭和选择，不包含搜索词或来源名称。

## 安装说明

Apple Silicon，macOS 14+。主 App 与内置 Helper 整包升级；不更改系统权限、配对、CLI 授权或数据格式。

原有权限、旧后台服务和长时间／多显示器等问题按各 Issue 的实际证据继续跟踪，不因本次发包自动关闭。
