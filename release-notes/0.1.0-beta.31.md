# Blocks 0.1.0-beta.31

本版包含未公开的 beta.30 候选中的本地自动化和菜单栏修补，以及安装验收后的后续调整。

## 菜单栏和主窗口（#81）

- 菜单栏图标是独立的系统状态项。隐藏图标不会请求退出 Blocks；可在「通用 → 显示菜单栏图标」恢复。登录启动和显式退出不变。
- 显示图标的开关使用原生控件，由控件本身提供可访问名称和状态。关闭主窗口后，可用 Dock 或 Finder 重开同一设置窗口，不需要另起进程。

## 本地自动化（#79、#80）

- 代理服务已登记不等于动作入口已就绪。现在确认 Broker 到主程序的实际往返后才显示就绪；连接中断、启动超时和健康检查失败进入有界重连，旧回调不能覆盖新连接，在途请求也不会只因健康探测或拒绝停用而被中断。
- 主程序、Broker 的签名验证和官方动作代理的系统登记移到后台；验证和登记完成前不会提前宣告可用。后台验证有容量限制，保留原来的签名、同用户及进程身份要求。
- 划词助手被动刷新也在后台验签，不自动重新关联。窗口生命周期、登记和签名日志仅记录阶段、线程、耗时与结果，不记录剪贴板正文或凭据，也不自动上传。

本地定向回归 333 项通过，零失败、零跳过；包含注册与退出竞态、原生菜单栏开关和窗口重开路径。原报告中四天驻留后偶发失联的场景仍需要原机长期复测。

Apple Silicon，macOS 14+；主 App 和 Helper 整包升级，不重置现有数据、系统授权及配对。
