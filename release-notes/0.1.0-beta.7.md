# Blocks 0.1.0-beta.7

面向 Apple Silicon，要求 macOS 14 或更新版本。

## 剪贴板现场诊断

- 增加筛选点击/选择、收藏悬停及面板关闭各阶段的结构化日志，记录窗口状态、事件顺序和临时会话标识，帮助定位 #48/#49 的间歇交互问题。
- “设置 → 数据与审计 → 诊断导出”现在包含本次运行最近最多 256 条交互事件。请在问题发生后、重启前导出，检查 JSON 后随 Issue 提交；事件仅存内存，不自动上传。
- 不记录剪贴板正文、搜索词、标签名、来源应用、窗口标题、文件路径或真实记录 ID。

## 验证边界

16 项定向测试通过，测试宿主运行中已捕获对应统一日志；包含有界事件缓存、脱敏导出和安全写入验证。此版本增强现场诊断，不宣称 #48/#49 原间歇场景已根治。
