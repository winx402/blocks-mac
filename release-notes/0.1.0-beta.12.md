# Blocks 0.1.0-beta.12

Apple Silicon，macOS 14 或更新版本。

## 修复

- 修复剪贴板标签筛选行尾部多出至少 120pt 空白的问题；溢出时仍可通过右键新建标签，新建输入框会进入可视区（#60）。
- 源码开发版 CLI 改由主 App 承载，不再依赖独立 Action Broker 的 SMAppService 启动；避免系统拒绝自签 Broker 启动后，总开关与新版本升级继续依赖该 Broker（#59）。
- 保留双向进程身份/CDHash 校验、模块授权、逐次确认、输出文件描述符传递和请求取消。正式沙盒发行版仍采用原有 XPC/Broker 路径。
- 修复新路径在忙碌停用失败后，恢复操作可能取消原执行任务的边界。

## 验证与边界

- 新传输层验证实际 ad-hoc 签名与 audit-token 双向认证、未登记路径/身份拒绝、输出句柄、超时及正式编译排除。
- 本机为 macOS 26.6.2；macOS 27 自签报告原环境仍需复验，不将本机通过等同于该环境修复已验收。
- 新版本不会强行移除旧 LaunchAgent。旧版本仍有不可达的注册时，安装器继续安全失败；需保留旧安装与匹配的身份清单，处理一次性迁移。
- 旧版自动源码升级准备在本机仍可能失败；正常退出旧 App/Helper 后可安装。本版不声称修复所有旧版迁移问题。
