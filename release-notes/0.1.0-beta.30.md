# Blocks 0.1.0-beta.30

## 本地自动化连接恢复（#79）

- “服务已登记”不再等于“动作入口就绪”：通过 Broker 到主程序的实际往返确认后才显示可用；连接中断、注册超时和健康检查失败会转入有界重连。
- 增加周期、系统唤醒和手动复查；健康检查只确认当前连接，不反复注册服务或强行停止正在处理的任务。
- 为连接代际、迟到回调、更新暂停和退出增加隔离，旧连接的结果不能覆盖新连接状态。健康检查淘汰的旧路由会保留已接收请求的回复，不主动中断这些请求。
- 修正忙碌任务拒绝更新或停用后的恢复：不再为了恢复入口而停止并撤销尚在执行的任务。

## 启动期签名验证（#80）

- 主程序与 Broker 的启动身份验证移到后台工作队列；仍先完成严格身份校验，再启用连接，不降低同用户、签名或进程身份要求。
- 后台验证限制排队容量，取消和超时不会提前释放正在执行的原生验证占用；过期排队工作不会继续做昂贵的验证。
- 划词助手的后台状态刷新也移走签名检查，保留断开意图、代际隔离和通知合并，不自动重新关联助手。
- 增加本机低敏日志，记录固定验证阶段、是否主线程、耗时和系统状态码；连接日志只记录状态与相对时间，不记录剪贴板正文、分组名称或凭据，不自动上传。

## 验证边界

本地使用 Xcode 27.0、macOS 27.2.1 完成正式配置的隔离测试构建；定向回归 388 项通过、零失败，14 项依赖专用权限宿主或已关联正式助手的测试跳过，不计为通过。覆盖身份策略、验证容量、在途回复、启动超时、健康恢复、更新取消与 Helper 刷新竞争；另通过安装更新安全自检、发布流水线自检及 7 项独立关联夹具测试。

本轮针对已确认的连接状态、恢复和签名验证路径修补。原报告中“主程序驻留四天后入口失联”的现场未在开发机重现；冷启动查询成功不代表这个长期驻留场景已经通过。

Apple Silicon，macOS 14+。主 App 与内置 Helper 整包升级；不重置系统权限、数据库或既有配对。
