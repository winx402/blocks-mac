# Blocks 0.1.0-beta.13

Apple Silicon，macOS 14 或更新版本。

## 修复

- 剪贴板搜索支持中文及英文前缀，保留大小写不敏感；前缀过滤后没有结果时使用转义后的子串兜底，覆盖中文中缀和驼峰中词。面板与 CLI 使用相同路径，不重建索引（#61）。
- 修复 CLI 首次安装在目标文件尚未存在时创建文件书签而失败的问题。先用真实目录书签保留恢复能力，文件创建后再生成文件书签；保留原子替换及身份/摘要校验（#47）。
- 修复源码 CLI 取消入口错误要求裸 UUID，导致真实 `req_` 请求 ID 被拒绝的问题；现在使用统一请求标识契约（#59）。
- 包含上一轮 Helper 响应回调仲裁修复：完整响应等待 EOF 时，连接状态变化不再抢先丢弃有效结果；严格的接收错误、完整帧和超时检查不变（#50、#57）。
- 增加更新准备的脱敏阶段日志，以及默认关闭的原生拖拽交互验收夹具。

## 验证与已知边界

- 已在本机验证合成图片导入、自定义标题检索、12 组前缀/中缀/大小写查询、一次性导出授权及拒绝读取、收藏/取消收藏、按 ID 删除。
- 源码版开启模块即自动安装 `blocks-dev`，更新后命令继续有效；模块关闭后返回 `module_disabled`。测试后恢复原来的关闭状态，未改 shell 配置。
- 安全卸载继续保留隔离恢复副本，不自动删除可能被替换的路径；核对并回收副本后通过 App 重新检查完成恢复。
- 本机为 macOS 26.6.2/Xcode 26.6；双屏、Xcode 27、原无 OU 证书和旧 TCC 状态等项目仍保留原环境验收，不声称全部 issue 已关闭。
- Helper 长运行约一天后出现一次 AppKit/CoreUI 窗口崩溃，重启可恢复，#51 已重新开放。此版本不宣称修复该崩溃。
