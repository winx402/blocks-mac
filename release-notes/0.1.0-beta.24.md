# Blocks 0.1.0-beta.24

## 权限恢复与安全重启

- 修复官方沙盒版枚举进程失败，导致权限恢复无法继续重启的问题。
- 先关闭权限恢复弹窗再交接重启器，避免弹窗阻塞退出；后台短请求在退出 Hook 后出现时，有界等待其自然结束。
- 权限恢复失败时保留具体、安全的原因分类。未配对助手会提示从 `blocksHelper` 菜单正常退出后重试，不再统一要求等待不存在的任务。
- Helper 准备超时、无法连接或旧协议拒绝，不再冒充已确认的任务忙碌；未知错误使用中性提示，不展示任意底层错误内容。
- 新检查、重试和取消会清理陈旧失败提示；失败原因不加入跨进程恢复票据。

## 更新与旧 CLI 服务恢复

- 更新准备失败时显示原因，并保留有效重试入口和已验证的下载；不需要为了更新先配对助手。
- 使用实际助手菜单名 `blocksHelper` 指引正常退出。
- 区分 Broker 忙碌、身份拒绝、协议不兼容、失联、超时和恢复冲突，不把未知错误统称为任务忙碌。
- 为能够认证且身份匹配的旧开发版 Broker 提供带持久化票据的安全迁移，保留取消、崩溃和普通退出的恢复边界。
- 官方安装脚本在替换前检查包内进程及当前用户的两个 Broker 服务域；状态未知或仍有进程运行时保留原安装。

## 安装与边界

Apple Silicon，macOS 14+。官方 DMG 经 Developer ID 签名、公证并 stapled；主 App 与内置 Helper 整包升级。

这些修复不会授予系统权限。最终授权仍由用户在系统设置确认，不自动清除 TCC、历史、收藏或配对，也不强停正在运行的组件。

已经运行且无法认证的旧 Broker 不能由新代码直接修补其进程。原故障环境和其他未完成验收的 Issue 继续单独跟踪，不因本次发包自动关闭。
