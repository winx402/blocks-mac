# Blocks 0.1.0-beta.2

本版本面向 Apple Silicon，要求 macOS 14 或更新版本。

## 修复

- 权限诊断根据真实签名标志和证书链识别 ad-hoc / 固定证书，不再把“没有 Team ID”直接当成临时签名（#35）。
- 同一次运行内，每种系统权限只请求一次系统授权；重复操作继续提供应用内引导，不反复调用授权 API（#37）。
- 对“系统设置已开启但应用仍未获权”提供用户确认后的定向恢复说明，不自动重置权限、不推断或修改 TCC 数据库（#34）。
- 源码版 Helper 新建配对密钥采用只信任当前已校验主 App 与 Helper 的钥匙串访问列表；Helper 访问采用无弹窗模式，旧条目不能读取时保留密钥并显示恢复说明，不自动重配（#36）。官方发行版继续使用共享钥匙串访问组。
- CLI 翻译源连接测试保留底层网络错误代码，并提供可操作的错误说明（#28 后续修复）。
- 助手辅助功能主按钮直接打开拖动授权引导，明确主 App 与 Helper 是两个权限条目（#38）。
- 助手按需启动使用最长约 3 秒的渐进等待，监听进程启动/退出恢复状态，区分未运行与安全连接失败，并提供登录项设置入口说明（#39）。
- 剪贴板新面板优先跟随待粘贴目标窗口所在屏幕；目标不可用时按指针屏幕、主屏回退，底部仍贴物理屏幕底边（#40）。
- 收紧翻译面板“原文”行留白，并避免中文输入法合成期间占位文字重叠；未确认拼音不提交给翻译模型（#41、#42）。

## 安装与注意事项

下载此 Release 的 DMG，拖入“应用程序”。已有正式版用户可在 Blocks 中选择 Beta 更新频道后检查更新；源码开发版不会被正式更新替换。

新方案不会绕过 macOS 的安全保护。已锁定的钥匙串、签名改变后不再信任当前 App 的旧条目，可能仍需用户解锁或明确修复访问权限；应用不会用反复弹窗、清空配对或明文存储代替修复。录屏、辅助功能首次授权仍由系统管理。
