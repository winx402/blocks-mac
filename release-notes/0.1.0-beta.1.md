# Blocks 0.1.0-beta.1

发布候选说明。此文件不代表版本已经发布；可安装产物以 GitHub Release 中正式提供的签名、公证附件为准。

## 本轮变更

- 源码版统一显示为 Blocks，固定安装到用户应用程序目录；保留原有数据、钥匙串和配对命名空间。
- 支持固定本机证书签名，覆盖安装时检查签名身份连续性；证书不可用时拒绝静默降级。没有证书的环境仍可使用明确标示限制的临时签名构建。
- 修复源码版剪贴板 Broker 的沙盒继承不匹配及无界重启，并提供不可用反馈。
- 剪贴板底部面板始终贴当前屏幕物理底边，不再为 Dock 预留底部空白。
- 修复窗口背景未覆盖标题栏安全区的问题，调整筛选栏、翻译标题行和截图工具区布局。
- 截图插件的多行属性使用受限滚动视口，错误反馈不再挤入固定工具行；联合多屏截图的工具区避开物理安全区。
- 改进 CLI 错误返回、本地测试进程清理、临时应用注册清理和启动窗口显示。
- 退出立即隐藏界面，后台清理超过 5 秒进入独立硬截止；私有子进程按登记身份清理，不终止独立 Helper 或无关进程。
- 新增默认关闭的异常反馈与 CLI 预览、确认提交；退出期间只记录本机诊断，不执行网络反馈。
- 固定签名本地构建支持 Helper 安全自动关联，保留已有配对与密钥。
- 修复设置侧栏宽度、标题栏材质连续性、翻译错误内联显示及标题空白区域拖动。
- 修复剪贴板复制后迟到历史查询覆盖近期使用顺序的竞态。

## 安装与升级边界

- 官方发行目标：Apple Silicon、macOS 14+。源码构建仍需要完整 Xcode 26+。
- 首次更换签名身份可能需要重新授权；不能承诺系统永远不再提示权限。
- 本机固定证书源码版的两次覆盖安装已验证授权保留，但这不替代官方 DMG 首装与 Sparkle 跨版本升级验收。
- 2026-09-10 使用受控 TextEdit 全屏文稿完成浅深色截图编辑显示检查：3840×2160 原图铺满屏幕，工具区叠加在图内；尺寸、圆角和撤销已实机操作。完整多语言、VoiceOver 与覆盖窗口绘制拖拽仍未全部验收。
- 正式发布前仍必须补齐公证配置、主 App/Helper 分发 profile，并完成尚未通过的安装版交互及升级门禁；不得发布临时签名包或要求关闭系统安全保护。
