# Blocks 0.1.0-beta.28

## 翻译与剪贴板样式

- 翻译原文输入区不再在聚焦时显示整块蓝色描边和填色，编辑区域自然融入面板；保留插入光标、文字选区、中文输入和原有编辑行为。
- 格式、时间、来源筛选器不再额外绘制系统矩形焦点环；保留选中状态、独立清除按钮、鼠标首击与键盘菜单操作。
- 仅调整这两处局部装饰，不改变全局焦点样式或其他控件。

## 外接显示器问题诊断

- 补充剪贴板窗口、控件点击、激活和原生菜单生命周期的低敏时序与几何诊断，帮助区分点击未到达、菜单未打开和菜单打开后关闭。
- 不记录搜索词、筛选值、来源名称、剪贴板正文或设备名称。外接屏菜单失效仍由 #49 跟踪，不将单屏验证视为外屏问题已解决。
- “数据与审计 → 导出诊断”包含这份有界、无内容的结构化快照，无需单独收集原始系统日志；事件仅存内存，请在重启前导出，分享前仍需自行检查。
- 修复诊断报告导出到用户所选目录时，沙盒拒绝创建旁边临时文件导致保存失败的问题；继续保留原子写入、取消清理和并发覆盖保护，不增加目录访问权限。

## 安装说明

Apple Silicon，macOS 14+。主 App 与内置 Helper 整包升级；不更改权限、配对、CLI 授权或数据格式。
