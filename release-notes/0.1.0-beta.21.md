# Blocks 0.1.0-beta.21

## 翻译面板（#70／#71）

- 扩大原文有效编辑面积、缩减内边距；输入多行或长文本时有界增长，保留语言栏和结果区。
- 语言选择使用原生菜单，补齐首次点击、菜单跟踪与面板关闭之间的保护；源语言和目标语言分别居中。
- 自动检测源语言时，交换操作说明需要先选择源语言，不再无反馈。
- 增加不含原文、译文和语言选择值的菜单生命周期诊断日志。

## 剪贴板右键菜单（#72）

- 右键与 Control-click 穿过仅负责主点击的原生覆盖层，恢复现有记录菜单。
- Control-click 不再被当成主点击；正常单击、双击和原有业务／插件菜单保持原路径。

## CLI 服务连接（#69）

- Broker 启动时固定自身已验证身份，连接时由系统再次校验实际 XPC 对端的精确角色签名要求。
- 增加分阶段、限频、低敏身份拒绝日志；持续连接失败时提供“重新检查”，明确安全恢复状态。
- 不强停旧 Broker、不清配对或授权。此补丁不能替换已经运行的旧进程；原故障环境与真实跨版本恢复仍需验证，#69 保持开放。

## 验证边界

已完成无证书构建、135 项定向 XCTest，以及生命周期安全、退出看门狗、发布自检和 UI 门禁。
