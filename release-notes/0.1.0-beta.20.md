# Blocks 0.1.0-beta.20

## 更新失败可见、可重试（#68）

- 点击“安装并重启”后显示安全准备进度；失败时显示当前阻塞原因和有效的“重试安装／稍后”，不再留下失效的安装按钮。
- 重试沿用 Sparkle 已验证下载与保存的安装回调，不重新下载；重复点击不会多次提交安装。
- 区分未配对助手、配对密钥不可读、助手忙碌、CLI 服务及数据备份阻塞；不会把钥匙串读取失败误判成未配对。
- 正在运行但未配对的助手可由用户正常退出后重试，不要求为更新而配对；不强杀进程、不清配对、不绕过安全退出。
- 增加低敏的更新准备阶段、参与者、原因和重试可用性日志，不记录凭据、文本或路径。

## 从旧版安装

此修复在运行 beta.20 的 App 中生效，不能追溯改变 beta.18/19 的更新窗口。
旧版若已卡在安装页面，请正常退出划词助手，再从 Blocks 设置中的“重试安全安装”继续；
或下载本版本 DMG，正常退出旧 App 与助手后替换应用。不要强退正在写入数据的任务。

## 验证边界

本轮 67 项定向 XCTest、生命周期／退出／钥匙串 ACL／发布自检及 UI 设计门禁通过。
隔离 App 使用真实 Sparkle 标准窗口及生产更新协调器／恢复窗口，验证失败、稍后、继续、重试和单次安装回调；
安全退出是合成场景，不代表真实跨版本升级、原安装环境或用户数据迁移已经验收。
这些实机项目仍在 #68 跟踪；#66/#67 等既有未完成验收不因本次发包而关闭。

Apple Silicon，macOS 14+；官方 DMG 由本机 Developer ID 签名、公证后发布。
