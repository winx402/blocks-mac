# Blocks 0.1.0-beta.6

面向 Apple Silicon，要求 macOS 14 或更新版本。

## 剪贴板交互（#48）

- 收藏星标统一为黄色；收藏控件保留稳定的视图身份，扩大条目悬停检测至覆盖控件，减少移入按钮时消失、闪烁的风险。
- 点击外部关闭非固定面板时先隐藏窗口再清理状态，避免关闭过程重新显示不透明面板；固定面板保持原行为。
- 移除默认详情展示入口及相关辅助功能动作。单击选择记录，双击仍执行粘贴；内部详情模块保留。

## 筛选交互（#49）

- 保留系统原生格式、时间、来源菜单，改进窗口激活点击策略。
- 标签筛选增加手形光标及悬停、按压反馈，保留选中状态样式。
- 增加不含剪贴板正文的筛选点击与选择诊断，帮助定位间歇性无响应。

## 验证边界

24 项定向测试、开发构建及 UI 设计系统检查通过；隔离生产界面中已验证菜单选择、标签筛选、单击不弹详情和收藏切换。持续纯悬停、真实外部点击关闭的视觉表现，以及 macOS 27 长时间、多显示器间歇场景仍待复验，不宣称这些原场景已完全解决。
