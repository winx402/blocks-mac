# Blocks 0.1.0-beta.19

## 权限恢复（#66）

- “已开启，仍无效”先检查当前进程，再提供“重新打开并检查”；官方签名版不再缺少重启入口。
- 重启前安全暂停并排空任务，独立启动器仅重新打开当前 App。准备失败、退出未完成时保留 App，不强退、不自动重试。
- 重启后返回权限页继续检查；仍未通过时引导重新添加当前 App，返回后自动检测。
- 区分辅助功能读取、按键发送、录屏、输入监控及助手权限。终端重置命令仅保留在高级诊断，不自动执行。
- 增加低敏的检查来源、结果、阶段、时间和进程身份日志，不采集屏幕或输入内容。

## 划词助手设置（#67）

- 权限页和翻译页共用“完成设置”入口：打开可信助手、人工输入配对码、完成助手权限、验证认证连接。
- 助手未配对时显示等待连接；本机服务已监听不再被描述成主 App 已连接。
- 人工配对失败保留具体原因，不被后台刷新覆盖；仅新的配对操作或真实认证检查成功清除。
- 提示配对密钥保存失败的单边状态；旧配对码不会被测试或文案当成可重复使用的恢复方案。

## 验证边界

- 包含权限恢复状态、重启取消/失败、迟到回调、并发操作、配对码消费与错误保留的回归测试。
- 最终 103 项定向 XCTest、应用更新安全、助手密钥隔离和发布失败路径自测通过；Developer ID 签名的沙盒重启探针通过。
- 不修改系统 TCC、配对协议、客户端信任、沙盒边界或普通退出行为。
- 原安装环境的权限恢复、真实选中文字获取及跨版本授权保留仍需复验；不把模拟权限通过当成系统授权成功。
- #64 钉钉粘贴、#65 完整登录启动和 #59 / #62 旧 Broker 迁移的既有未验证边界保留。
- Apple Silicon，macOS 14+；官方包经 Developer ID 签名、公证和 stapling。
