# Blocks 0.1.0-beta.4

面向 Apple Silicon，要求 macOS 14 或更新版本。

## CLI 编译兼容性

- 针对 Xcode 27 Beta 报告的 `executeAction` 优化器崩溃（#46），拆开泛型动作计算、输出文件生命周期及进程终止，并隔离内联边界。
- 保持优化开启，不移除命令或改变权限要求；截图、翻译和剪贴板 CLI 的参数、JSON 及退出码合约保持不变。

## 验证边界

本版本由 Xcode 26 工具链构建与发布。Xcode 27.0（27A266a）原崩溃环境仍待重试确认；这是代码结构规避补丁，不宣称已在缺席的工具链上验证成功。

保留 Beta 3 的剪贴板导入/导出/管理、标题索引及无 Team ID 开发签名兼容补丁。下载签名 DMG 后安装；官方用户可选择 Beta 频道检查更新，源码开发版保持独立。
