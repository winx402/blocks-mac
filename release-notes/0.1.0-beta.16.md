# Blocks 0.1.0-beta.16

## 翻译面板

- 精简为原文、居中的语言栏和始终展开的译文；减少重复卡片底色，统一来源运行状态的位置。
- 移除结果收起和翻译取消按钮。输入停止 0.8 秒后自动翻译；中文等输入法的选词期间不发起翻译，确认文字后再计时。
- 修复编辑、输入法组合态或插件预检期间，调整来源顺序可能使旧译文重新出现的问题。
- 修复 Apple 本地翻译在语言对不变时，连续输入新文本可能停在“翻译中”的问题。
- 按首次输入选择窗口与原文区域尺寸，阅读和流式输出时保持稳定；明确手动调整过的窗口尺寸继续保留。
- 保留复制、朗读、收藏、来源排序、单来源重试和错误恢复能力。

## 应用内更新

- 菜单栏新增“检查更新”入口，与应用菜单及通用设置使用同一套更新流程；安装准备失败时可重试。
- 官方发行版通过 Sparkle 检查、下载并在用户确认后安装签名更新；源码版继续与官方更新隔离。

## 源码升级与诊断（#62，部分修复）

- 仅在旧 Broker 的 launchd 任务与进程均已确认不存在时，允许清理残留服务注册，避免该残留状态继续阻塞源码升级。
- 升级错误区分参与者排空失败、旧服务迁移失败、超时及 CLI 被信号终止；不再一律提示用户结束活跃工作。
- 不将 XPC 超时或缺少 PID 视为安全退出证据，不强杀可能正在工作的服务，不改变签名信任策略。

## 已知限制

- #62 尚未完全解决：旧 Broker 任务仍加载但被系统拒绝启动时仍安全停止升级；#59 的 Launch Constraint 根因及报告环境中的 CLI SIGKILL 尚未确认。相关 issue 保持打开。
- 旧版本自身没有上述恢复逻辑；需要先正常退出旧 App 与 Helper，并确认旧任务已消失，才能走离线升级路径。不要通过替换单个二进制、清空数据或关闭系统安全保护绕过。
- 本版本为 Apple Silicon、macOS 14+ 的 Beta；源码版与官方发行版仍使用独立身份及更新通道。

## 安装脚本补充说明

- 命令行安装请使用仓库 `main` 最新的 `script/install.sh` 和配套文件。实装验证修正了 Gatekeeper 工具路径，以及 macOS 临时目录 `/var` 与 `/private/var` 的规范路径处理；Beta 16 标签内的旧安装脚本仍包含这些问题。
- 本次修正只涉及源码安装脚本，不改变已发布的签名 DMG、版本标签或校验值；也可直接下载安装 DMG。
