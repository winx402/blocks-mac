# Blocks 0.1.0-beta.8

Apple Silicon，macOS 14 或更新版本。

- #50：源码重装前检测残留 Broker 注册，阻止不安全覆盖；关闭总 CLI 集成先认证并等待安全注销，保留模块选择。连接失败不再一律误报“尚未开启集成”。无法认证的旧身份残留仍需原环境恢复，不会擅自强杀。
- #51：主 App 启动时尝试恢复已配对的可信助手；未配对、测试模式、密钥不可读时不自动拉起，不重置配对或请求权限。
- #52：修正拖动状态发布时读取旧值造成的关闭保护时序问题；列表按服务保持视图身份，旧拖动完成回调不能清掉新会话。
- #53：内置助手更名为 `blocksHelper`，复用主 App 图标；Bundle ID 与配对命名空间不变。
- #54：已分组或带自定义标签的剪贴板条目默认豁免自动清理，手动删除仍有效。
- #55：收藏只显示星形，不带方框底色与描边；保留点击和帮助提示。
- #56：CLI 导入、新建标签和设置页统一默认选色，已有标签颜色不变。

保留此前版本的诊断导出能力。macOS 27 的原间歇交互、旧 Broker 坏状态与 Helper 更名后权限保留不能仅凭单元测试算作已验收，相关 Issue 如实保留状态。
