# Blocks 0.1.0-beta.9

Apple Silicon，macOS 14 或更新版本。

## 源码升级编排（#57，关联 #50）

- 支持该协议的已安装源码版，可由 `script/dev.sh run/update` 自动请求安全暂停、退出，再换包并重启恢复；保留 CLI 集成意图和模块选择。
- 先验证新包，后准备旧 App；身份不匹配、仍有任务、连接中断或超时均拒绝危险覆盖，不强杀 Broker。换包失败保留备份并尝试恢复原安装。
- 独立管理通道仅存在于 LocalDevelopment，双向核验内核身份、代码签名和安装清单；不扩大日常 CLI 模块权限。正式发行包不启用该通道。
- 修正更新准备取消时的恢复任务与退出围栏，防止取消状态阻止 Broker 恢复。

beta.8 及更早源码安装缺少管理入口，首次迁移仍可能需要一次手动关闭 CLI/退出流程；后续支持协议的版本之间才自动编排。旧身份已经损坏的安装不在自动恢复承诺内。
