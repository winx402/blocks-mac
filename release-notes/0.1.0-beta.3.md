# Blocks 0.1.0-beta.3

面向 Apple Silicon，要求 macOS 14 或更新版本。

## 新增

- 官方剪贴板 CLI：导入、导出、查询、搜索、收藏、标签管理、分组创建/改名/移动以及预览确认删除（#43）。
- 导入采用版本化 JSON、严格批量校验、内容去重与事务回滚；导出不会覆盖已有文件。全文查看和导出需在 App 中逐次确认范围，摘要读取遵守设置开关。

## 修复

- 自定义标题纳入剪贴板搜索；已有记录通过增量索引重建获得支持，改标题后同步更新，保留隐私排除规则（#44）。
- 源码开发版支持没有 Team ID 的固定自签证书。信任仍绑定配置的精确证书指纹和原有代码要求，不以空 Team ID 放行，也不自动更换证书或退回 ad-hoc（#45）。

## 安装与边界

下载 DMG 后拖入“应用程序”；已有官方安装可选择 Beta 更新频道检查更新。源码版保持独立身份，不会被官方自动更新替换。

CLI 的导入格式不是第三方工具私有数据库读取器，也不是整库备份；不包含凭据、权限和原应用来源等数据。大批量内容应按文档分批操作。

本版本不自动重置 TCC、修改钥匙串访问权限或清空配对。首次录屏/辅助功能授权仍由系统管理；更换固定证书仍可能需要重新授权。
