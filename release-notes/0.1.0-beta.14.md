# Blocks 0.1.0-beta.14

Apple Silicon，macOS 14 或更新版本。

## 修复

- 修复 Helper 在连接已经失败/取消后未显式释放底层资源的问题，避免已关闭 TCP 句柄随健康检查持续累积（#51）。正常请求及响应仍遵守严格 FIN、错误及帧校验，不提前截断数据。
- 包含 Helper 有效响应被连接状态回调抢先判为失败的修复，改善安全升级与恢复。
- 剪贴板搜索支持中文、英文前缀及大小写不敏感；过滤后零命中时使用转义的子串兜底。支持中文中缀和驼峰中词，不重建索引（#61）。
- 修复 CLI 首装在文件不存在时创建文件书签导致失败的问题，保留真实目录授权、原子替换及恢复验证（#47）。
- 源码 CLI 取消入口接受统一的 `req_` 请求标识，不再误要求裸 UUID（#59）。

## 验证与边界

- 本机 146 项搜索、CLI、管理和授权定向测试通过；14 项真实网络测试通过，包含重复连接后的 FD 稳定性检查。
- 真实签名 Helper 连续 20 次健康检查后句柄仍为 11，只保留两个 TCP 监听连接，窗口可正常打开；旧版同类检查产生大量 CLOSED 句柄累积。
- 已验证合成图片导入、自定义标题搜索、12 组部分词查询、逐次导出授权与拒绝读取、命令自动首装和更新；结束后删除测试记录并恢复 CLI 开关。
- Beta 13 保持未发布草稿，其资源泄漏缺口已由本候选包补上；不覆盖既有标签或附件。
- 原 macOS 27/Xcode 27、双屏、无 OU 证书、旧 TCC 状态和历史损坏 Broker 注册等仍有未完成验收，不能把本版视为全部 issue 已关闭。旧 CoreUI 崩溃与资源耗尽的因果关联仍属推断，不等于已证明所有系统崩溃都由该泄漏引起。
