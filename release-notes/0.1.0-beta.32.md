# Blocks 0.1.0-beta.32

这是在已公开 beta.29 之后的新 Beta，包含未公开候选中的本地自动化和菜单栏修复。

- **菜单栏和主窗口（#81）**：隐藏 Blocks 菜单栏图标不会请求退出 App，「通用 → 显示菜单栏图标」可恢复。关闭主窗口后可从 Dock 或 Finder 重开；保留显式退出和登录启动设置。设置页不再重复覆盖系统控件和说明文字的无障碍标签，保留开关状态和快捷键播报。
- **本地自动化（#79）**：区分代理已登记和主 App 已就绪；确认实际握手后才显示可用。连接中断时有界重试，定期和唤醒后复查，旧回调不会覆盖新的连接。原四天驻留的特定现场与本机短时复验分开记录。
- **启动检查（#80）**：把 App 和 Broker 的签名检查，以及动作代理系统登记移到受控后台执行。保留签名验证、模块授权和升级排空。日志只记录阶段、线程、耗时与结果，不记录剪贴板正文或凭据。

Apple Silicon，macOS 14+；主 App 与内置 Helper 整包升级，不重置现有数据、权限或配对。
