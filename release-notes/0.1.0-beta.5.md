# Blocks 0.1.0-beta.5

面向 Apple Silicon，要求 macOS 14 或更新版本。

## CLI 模块与命令管理（#47）

- 截图、剪贴板、翻译源、插件分别授权，保留总开关。首次升级到此权限模型时四个模块均默认关闭，请在“本地自动化”明确开启所需模块；选择在后续升级中保留。
- `blocks list` 通过已认证服务列出当前允许的动作；关闭模块后返回 `module_disabled`，其他已开启模块不受影响。剪贴板全文仍需逐次确认。
- 开启模块时自动配置命令。开发版使用 `~/.local/bin/blocks-dev`；官方沙盒版首次需系统目录授权，之后自动更新自己管理的 `blocks`。不修改 shell 配置，不覆盖其他工具，可通过高级入口另选位置。
- 命令卸载与模块授权独立，卸载后不自动装回；遇到需要安全恢复的文件状态，会保留恢复材料并提示处理。
- 保留离线反馈和隐私命令原有能力与各自确认规则，不宣称它们受这四个服务模块开关控制。

## 稳定性

- 修复新动态动作列表在优化构建中可能直接退出的控制流问题，增加独立模块的优化编译回归。
- 自动命令管理纳入应用升级和退出协调，处理启动刷新与显式安装的并发、目录被删除后的恢复及权限取消。

## 边界

官方沙盒版无法未经授权写入 PATH 目录；首次目录选择是系统访问授权，不通过关闭沙盒绕过。GUI App 的 PATH 与终端可能不同，命令目录不在终端 PATH 时仍需用户自行配置。
