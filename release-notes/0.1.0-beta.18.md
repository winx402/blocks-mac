# Blocks 0.1.0-beta.18

## 后台启动快捷键（#65）

- 在应用启动完成后独立初始化全局快捷键，登录后台启动不再依赖主窗口先出现或激活。
- 区分“应用尚未就绪”和真实快捷键冲突；前者最多尝试 5 次，成功后不重复注册。
- 保留模块禁用、旧注册事件拒绝和更新暂停／恢复约束；补充启动、注册和面板调用阶段日志。

## 源码升级（#63）

- 修复僵尸进程仍占用 PID，却无法读取可执行路径和名称时误阻塞旧 Broker 迁移的问题。
- 仅在源码迁移扫描的无法分类分支，使用两次相同内核进程身份和僵尸状态证明排除已终止进程。
- 活进程、读取失败、PID 复用及旧／移动安装 Broker 继续阻止不安全替换；未扩大注销或强制退出行为。

## 自动粘贴诊断与源码版窗口识别（#64，部分处理）

- 已有辅助功能权限的非沙盒源码版可用焦点窗口位置和尺寸匹配同进程中的唯一可见窗口，减少辅助小窗口对列表首项的干扰；不读取输入正文，不按窗口面积猜测。
- 没有辅助功能信息时保留独立窗口列表路径；官方沙盒发行版也继续使用此基础路径。
- 目标窗口变化、原窗口无法确认和控件不可编辑分别提供具体恢复说明，保留“内容已复制”的事实。
- 发送前重新校验前台进程与剪贴板写入凭据；补充不含窗口标题、输入内容的窗口编号／层级／透明度／边界诊断。

## 验证与已知边界

- 包含真实未回收僵尸、活未知进程、移动 Broker、后台初始化、未就绪恢复、冲突、更新暂停和窗口路由的回归测试。
- 最终 127 项定向 XCTest 与源码安装、升级恢复、应用更新安全及发布失败路径自测通过。
- #64 的钉钉同窗口连续双击仍需原机实测，本次不将事件发送或模拟窗口测试作为输入成功的证明。
- #59 / #62 中仍加载但不可启动的旧 Broker 安全迁移限制保留；#63 不等于这两项全部解决。
- Apple Silicon，macOS 14+；源码版与官方发行版的身份、数据和更新通道继续独立。
