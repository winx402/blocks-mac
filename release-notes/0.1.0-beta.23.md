# Blocks 0.1.0-beta.23

## 权限恢复与安全重启

- 修复官方沙盒版在进程枚举阶段被系统拒绝，导致权限恢复重启无法继续的问题。
- 先结束权限恢复弹窗，再交接给现有重启器；防止重启准备期间因返回设置页等动作重新弹出窗口，阻塞退出。
- 后台短请求恰好出现在退出 Hook 后时，有界等待任务自然结束，再一次性暂停新任务；不取消已有工作，也不重复执行 Hook。
- 增加固定功能分类、活动计数和恢复阶段的低敏日志，不记录用户正文、路径、插件标识或凭据。

## 更新与旧 CLI 服务恢复

- 修正未配对助手的退出提示，使用与实际应用菜单一致的 `blocksHelper` 名称；无需为更新先配对。
- 区分 Broker 忙碌、身份拒绝、协议不兼容、失联、超时与恢复冲突，不再把未知错误统称为“请结束 CLI 任务”。
- 为能够认证且身份匹配的旧开发版 Broker 增加带持久化票据的安全迁移；取消、崩溃和普通退出时保留对应的恢复边界。
- 官方安装脚本在替换前检查所有包内进程及当前用户的两个 Broker 服务域；状态未知或仍有进程运行时拒绝替换，保留原安装。

## 安装与验证范围

Apple Silicon，macOS 14+。官方 DMG 由本机 Developer ID 签名、公证后发布。安装或手动升级前，
请正常退出主 App 和独立划词助手；无需清除历史、收藏、设置或配对。

权限恢复与生命周期补丁通过本地 197 项定向 XCTest；助手退出提示另通过更新协调器 27 项测试。
完整签名沙盒候选已验证辅助功能、屏幕录制和输入监控三条
恢复路径的正常退出、唯一新进程自动重开及对应结果回流；也实际命中后台请求忙碌后继续重启。
这些结果不代表系统已授予权限，最终授权仍由用户在系统设置中确认。

已经运行且无法认证的旧 Broker，不能由新代码直接修补其进程；原故障环境及真实跨版本更新的
剩余验证仍单独跟踪。现有未完成验收的 Issue 不因本次发包自动关闭。
