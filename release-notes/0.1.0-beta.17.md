# Blocks 0.1.0-beta.17

## 更新设置

- 通用设置提供并列的“自动检查更新”和“接收 Beta 更新”开关，沿用 macOS 风格的设置行。
- 自动检查只负责定期检查新版本，下载和安装仍需用户确认；关闭后仍可手动检查。
- Beta 开关沿用已有频道偏好，不重复保存一套配置。关闭后只检查稳定版，不自动降级，也不改变自动检查的开关状态。
- 更新会话或安装准备期间暂时禁用偏好修改，避免中途切换更新来源。
- 完善中、英、日文说明与辅助功能标识，不替用户默认开启开关。

## 官方安装脚本

- 修正 Gatekeeper 工具的固定路径为 `/usr/sbin/spctl`，继续避免通过可变 PATH 选择安全校验工具。
- 修正 macOS 临时目录 `/var` 与 `/private/var` 的别名导致挂载校验误报的问题，保留严格的挂载位置校验与失败回退。

## 验证与边界

- 更新设置受控构建、18 项更新协调器测试及应用更新安全自测通过。
- 安装脚本的路径和目录别名回归测试通过；修正后的脚本已用于上一版官方 DMG 的真实安装。
- 本版本为 Apple Silicon、macOS 14+ 的 Beta。源码版仍与官方发行版及更新通道隔离。
- #59 / #62 的剩余问题沿用 Beta 16 的已知限制，未以此次设置优化宣告关闭。
