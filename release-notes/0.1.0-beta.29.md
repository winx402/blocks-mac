# Blocks 0.1.0-beta.29

## 划词翻译读取与反馈

- 辅助功能的直接选区值为空或只有空白时，继续尝试当前候选的有效选区范围和文字标记；校验读取前后的一致性，保留密码字段、大小、取消和超时保护，不读取整篇文档或使用旧请求的缓存文本。
- 鼠标命中限定在本次目标应用内，避免翻译骨架面板覆盖鼠标点时错误命中 Blocks；返回元素仍必须属于目标进程。
- 明确发起划词却未读取到选区时，显示低干扰提示与手输／截图等下一步，不再静默呈现空原文；普通手动空白面板保持不受影响。
- 增加有界、无正文的 Helper 本机统一日志，帮助区分直接值、范围、标记和鼠标命中路径；不记录正文、坐标、范围位置或文字标记数据，不自动上传。这部分日志尚未加入常规诊断 JSON 导出。

## 官方内置助手连接

- 通过明确的连接操作自动关联当前整包内置的官方助手，正常路径不再要求抄写六位码；系统辅助功能授权仍需用户在系统设置确认。
- 双向校验同用户、官方签名、真实连接进程以及当前内置副本；不接受任意同 Team、旧进程或包外副本，不扩大沙盒权限。
- 已有关联沿用原材料；无法读取、损坏和保存失败不会被当作首次使用，也不会静默覆盖。显式断开后保持断开意图，后台刷新和重启不会自动重新关联。

## 验证边界

本地定向回归：主程序 287 项通过、零失败，14 项依赖专用权限宿主或已配对正式助手的测试跳过；Helper 71 项通过、零跳过；开发关联独立夹具 7 项通过。跳过项不计为通过。

部分应用的消息正文、代码块或首次划词可能使用不同的辅助功能路径。本版修补已确认的读取与反馈分支，不将一次恢复或模拟测试视为 #78 原现场的完整验收；另一台 Mac 的外屏剪贴板菜单故障仍由 #49 单独跟踪。

#77 的新增键盘焦点提示未能完成真实焦点验收，本版没有包含这项试验改动，仍继续跟踪。官方助手的正式签名生产关联及原应用划词现场也不据单元测试视为验收完成。

Apple Silicon，macOS 14+。主 App 与内置 Helper 整包升级；不自动修改系统授权、不重置数据库或既有配对。
