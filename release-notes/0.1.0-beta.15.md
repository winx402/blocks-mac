# Blocks 0.1.0-beta.15

Apple Silicon，macOS 14 或更新版本。

## 权限恢复修复

- 权限刷新重启不再把当前进程被重新激活误判为新进程已启动；交接成功后等待旧进程退出，再重新打开应用。
- 关闭或完成 Helper 授权引导、重新进入权限或翻译设置页时只刷新状态，不再重新拉起用户主动退出的 Helper。

## 设置页优化

- 所有侧栏一级分类统一显示大图标、标题和说明，包括快捷键、权限、AI 服务、本地自动化、插件、数据与审计及翻译收藏。
- macOS 26 使用系统原生侧栏背景，移除重复材质；设置专属图标采用更清晰的光学尺寸和克制的明暗轮廓。
- 修复冷启动时部分侧栏图标不显示，以及增强对比度下选中文字不清晰的问题。
- 普通表单最大宽度调整为640pt，清理无信息增量的重复标题；插件、收藏等内容页面保留宽布局。
- 快捷键以紧凑修饰键符号显示，辅助功能仍提供完整名称。注册统计与验收说明收进可展开区域，失败提示保持可见。
- 开发版不使用官方自动更新的说明改为中性信息；真实配置错误和运行失败仍保留警告。

## 验证与边界

- 设置精修33项定向测试通过；统一概览后21项导航与侧栏回归测试通过，设计系统静态门禁通过。
- 本机实测中英日文、深浅色、默认与窄窗口、增强对比度、降低透明度、冷启动和导航/滚动/搜索状态恢复；测试设置均已还原。
- Xcode 27.0（27A266a）下完整 CLI 显式 `-O` 构建与统一源码构建通过；23项执行边界测试及9个真实CLI dry-run通过，#46已关闭。
- macOS 27 安装版真实拼音合成、提交、取消及逐字删空通过，#42已关闭。
- 权限修复13项针对性测试通过；生产重启交接代码在非沙盒和App Sandbox独立测试App中均完成旧PID退出后新PID启动。旧TCC异常/实际缺权恢复的完整UI验收仍保留。
- 三段网络测试数据改为等价分段拼接，解决Xcode27类型检查超时，不改变网络实现或测试断言。
- 所有一级页概览在本机安装版检查；最终统一概览改动未重新穷举全部语言及辅助显示组合。
