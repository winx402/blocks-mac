# Blocks 0.1.0-beta.11

Apple Silicon，macOS 14 或更新版本。

## 设置界面与导航

- 统一侧栏与标题栏背景，调整图标、配色、分组间距与设置行排版。
- 统一后退、前进、右键历史菜单及 Command-[ / Command-]；恢复对应页面的滚动位置、焦点和非敏感草稿。
- 精简重复标题及正文返回入口，修正内容滚动侵入标题栏的问题。
- 侧栏显示／隐藏移到“显示”菜单，支持 Command-Option-S。
- 修复插件异步安装完成后覆盖用户较新导航，以及服务配置草稿被根页面退出覆盖的边界。

## 开发安装维护

- 日常 Run 入口统一使用固定位置的源码安装；成功提交安装事务后清理旧应用包，失败时保留必要恢复材料。
- 不清理用户历史、收藏、设置、凭据或配对。

## 验证与说明

- 已检查中英日文、窄窗口、深浅色、系统增强对比度及真实导航交互。
- Beta 10仅作为未公开草稿保留：CI发现一处测试仍断言旧设置尺寸，本版将断言同步到已确认的新设计，不改写原标签。
- 本版不改变截图、剪贴板或翻译浮窗业务，不把模态编辑器或业务操作加入导航历史。
- 旧源码版自动退出准备可能返回`preparation_failed`；本机通过正常退出App与Helper完成升级，本版不宣称该准备问题已修复。
